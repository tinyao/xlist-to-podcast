Panzi Weekly，2026 年 7 月 27 日。当比特币不再需要为自己辩护，它开始被重新定义。

今天这期节目，我们聊聊一个历史性的能源转折、一场只剩 14 个工作日的立法博弈，以及 Jack Dorsey 的开源帝国如何让 AI agent 学会花钱。

先从一个容易被忽略的数据说起。

剑桥大学另类金融中心上周在达拉斯的能源投资者论坛上发布了一份初步研究报告，结论相当有意思。报告估算，比特币挖矿的年化电力消耗在过去一年里增长了 38%，达到 190 TWh。但与此同时，低碳能源在矿工自报的能源结构中的占比达到了 59.4%。

这个数字本身可能不够直观，但配合另一条消息来看就有意思了。Bitcoin News 报道，水力发电已经正式超越天然气，成为比特币挖矿最主要的能源来源，占比达到 60%。

这是第一次。

坦白说，这个趋势其实酝酿了很久。中国 2021 年的挖矿禁令把大量算力赶到了北美和北欧，而这两个地区的能源结构天然就更清洁。再加上 ESG 压力和资本市场的偏好，矿工们有足够的动力去找便宜又不会被骂的电力。水力、伴生气、废弃煤矿瓦斯——这些以前没人要的能源，现在成了矿工眼里的香饽饽。

但数据也有另一面。190 TWh 是什么概念？差不多是波兰全国一年的用电量。即便清洁能源占比在提高，绝对消耗量也在快速攀升。这就引出了一个更本质的问题：我们到底怎么衡量比特币挖矿的“绿色程度”？是用清洁能源占比，还是用绝对排放量？如果占比提高只是因为总量涨得更快，那这个“绿色叙事”是不是有点自欺欺人？

剑桥报告里还有一个细节值得注意：只有 10% 的受访矿工实际把电力分配给了 AI 计算，尽管绝大多数都表示对多元化感兴趣。这说明矿工们嘴上说着要转型，身体还很诚实地留在比特币这边。

说到 AI 和比特币的关系，这周有一个更有意思的交叉点。

Jack Dorsey 的公司 Block 旗下的 Nostr 生态，这几天在 GitHub 上霸榜了。两个项目——Bitchat 和 Buzz——同时冲进 GitHub trending 前三。Bitchat 是一个去中心化的蓝牙 mesh 通讯应用，Buzz 则被描述为“开源版的 Slack”。

但真正让人眼前一亮的，是 Buzz 上线不到一天就出现了一个场景：AI agent 开始用比特币互相支付。

Documenting Bitcoin 发了一段视频，展示 agent 之间独立进行小额比特币转账。这不是 demo，不是概念验证，是上线第一天就自然涌现的行为。你让一群可以编程的实体接入一个无许可的支付网络，它们不会等你写说明书——它们直接开始交易。

这就回到了 Lightning Labs 上周发布的 Wavelength 平台。我们之前聊过，Wavelength 是一个 Ark 风格的比特币支付工具包，主打“让 AI agent 调用 API 就能支付”。Buzz 的出现等于给这个叙事提供了一个活生生的案例：agent 经济不需要人批准，它只需要一个开放的网络。

当然，开放也意味着摩擦。印度政府这周下令 GitHub 移除 BitChat 的仓库，理由是它支持去中心化、无服务器的通讯，可能被用来逃避合法监听和协调非法活动。这个逻辑我们并不陌生。任何真正去中心化的工具，在主权国家眼里都是一个潜在的威胁。

换一个方向，聊聊美国本土的立法博弈。

Clarity Act 这周进入了关键阶段，但进展并不顺利。根据 Eleanor Terrett 的报道，法案目前还没有排上参议院投票日程，也没有更新立法文本，而距离 8 月休会只剩 14 个工作日。

最大的障碍是伦理条款。白宫提出了一套方案，包括禁止联邦官员在职期间发行或赞助数字资产获利、要求把加密资产放入盲信托、赋予司法部民事执法权、以及披露超过 1000 美元的加密资产出售。但民主党不买账，他们要求州检察长也能共享执法权，还想要追究特朗普家族过去加密活动的责任。

Crypto Council 的执行董事 Patrick Witt 说得挺直白：民主党的反对分两派，一派觉得没有州级执法就等于没牙的老虎，另一派就是想借这个法案惩罚特朗普。Witt 说后者是违宪的，但政治博弈从来不讲合不合宪，只讲筹码够不够。

前众议院金融服务委员会主席 Patrick McHenry 倒是比较乐观，他说 Clarity Act 通过是“什么时候的问题，不是会不会的问题”。但参议员 Lummis 本人就没那么淡定了，她直接说“民主党想从特朗普身上割一磅肉”，这场仗会很艰难。

不管法案最终过不过，有一个条款已经写进了草案，而且很有意思。法案鼓励白帽黑客负责任地披露数字资产基础设施的安全漏洞，还会给奖励。前 CFTC 主席 Giancarlo 参与了这个条款的设计。这是一个务实的设计——与其等着黑产来打，不如让好人先帮你找漏洞。

说到安全，这周还有一个值得关注的联盟成立。

Strategy、BlackRock、Coinbase、Fidelity、Galaxy 等 15 家机构联合成立了比特币安全联盟，承诺三年内投入 1500 万美元支持比特币的长期安全研究，首期重点是量子计算威胁。协调人是 Brink 的执行董事 Mike Schmidt，以志愿者身份参与。联盟强调不指导开发方向，不推动特定协议变更，只提供资金和教育。

1500 万美元分三年、15 家机构分摊，平均每家每年不到 35 万。对于一个管理着数百亿甚至上千亿美元资产的机构来说，这点钱连合规部门一个月的咖啡预算都不够。你可以说这是诚意，也可以说这是姿态。但姿态本身也有意义——它意味着这些机构终于公开承认，比特币的安全不是别人的事，是他们自己的事。

Galaxy 单独还宣布了一个 500 万美元的量子安全开发者资助计划。加上联盟的 1500 万，短期内比特币生态在抗量子密码上的投入大概在 2000 万美元量级。对比量子计算威胁的潜在破坏力，这个数字可能还差两个零，但至少方向是对的。

矿商这边，这周的分化非常明显。

Hut 8 宣布签下了一个 15 年、价值 98 亿美元的 AI 数据中心租约，把德州 Beacon Point 园区的 IT 容量翻倍到 704 MW。加上现有合同，整个园区的总合同价值达到 196 亿美元，如果算上续约选项，可能超过 500 亿。Hut 8 现在全部 949 MW 的 AI 数据中心容量都租给了投资级客户，平均年净运营收入超过 17.5 亿美元。

另一边，曾经全球最大的比特币矿池 Poolin 申请了 Chapter 11 破产保护。Poolin 在 2019 年是比特币算力的霸主，但 2022 年冻结用户提款后一蹶不振，现在欠用户约 1.64 亿美元。公司计划卖掉德州的矿场资产，已经有一个 5200 万美元的底价竞标，不是重组，而是清算。

Documenting Bitcoin 的评论很精准：比特币历史上，主导矿池来了又走，但矿工可以换池，去中心化网络照常运行。Poolin 的倒下是一个商业失败，不是网络失败。

MARA 的 CEO Fred Thiel 在另一个场合说了一句话：AI 数据中心的单位电力收入已经超过了比特币挖矿。这解释了为什么 Hut 8 能签下百亿租约，也解释了为什么 Bitdeer 一边把自挖算力做到 73 EH/s，一边把 AI 云的年化经常性收入拉到 7600 万美元。矿商们不是在二选一，而是在两条赛道上同时下注。

快讯时间。

比特币安全联盟之外，Fidelity 公开呼吁参议院通过 Clarity Act，强调清晰监管对建立投资者信任和美国数字资产领导地位至关重要。这个表态本身就说明，传统金融巨头已经把监管确定性视为商业竞争的核心变量。

BitMEX 宣布 9 月 23 日永久关闭。这个由 Arthur Hayes 创办的交易所巅峰时期日交易量 160 亿美元，年交易量超过一万亿美元。但 2020 年 Hayes 和联合创始人被美国刑事起诉后，交易所就再也没恢复元气。关闭的时机也很微妙——BitMEX 账上有一个约 2.7 亿美元的保险基金，不属于客户，归公司所有。外界猜测，关停可能是释放这笔资金的唯一途径。

印度要求 GitHub 下架 BitChat 的同一天，马来西亚吊销了 Balaji 的 Network School 营业执照。Balaji 说项目已经签了 MOU，要在哈萨克斯坦开新校区。网络国家这个概念的物理迁徙，比想象中更频繁也更混乱。

肯尼亚总统鲁托的官网被黑客攻击，勒索 5 枚比特币，约 32 万美元。这个金额在国家级勒索里不算大，但选择比特币作为支付方式本身就说明，即便在非洲，比特币作为勒索货币的认知已经根深蒂固。

特斯拉 Q2 财报显示仍持有 11,509 枚 BTC，没有买卖，但按 FASB 新会计准则录得 1.12 亿美元未实现亏损。Elon Musk 对比特币的态度已经从狂热转向沉默，但特斯拉的仓位一直没动。

最后说一个细节。

Strategy 的 CEO Phong Le 在采访中说了一句话：“我们卖了大约两亿美元的比特币，但市场没有下跌，反而涨了。所以我们不会走。” 这句话的背景是，Strategy 已经超过一个月没有宣布新的比特币购买，反而卖掉了 3588 枚 BTC 来补充现金储备。市场上一直有人担心，一旦最大的买家停手，比特币就会崩。但事实是，BTC 价格稳住了。

这让我想起这周 Documenting Bitcoin 发的一条推文：“人们问比特币是由什么背书的。但这个问题本身就没有意义。比特币就是记录本身。需要背书的东西，是因为它们没有记录。”

过去十年，比特币的叙事一直在变：点对点电子现金、数字黄金、通胀对冲、非主权价值存储。但也许最准确的描述是：它是一个不需要任何人背书的全球账本。当机构们开始为它的安全掏钱，当 AI agent 开始用它互相支付，当矿工们用废弃能源给它提供算力——所有这些都不是在“投资比特币”，而是在使用那个账本。

比特币不需要辩护。它只需要继续出块。
