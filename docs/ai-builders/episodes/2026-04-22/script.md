SpaceX 要以六百亿美元收购 Cursor，这个代号 Colossus 的联姻意味着什么？GPT-Image-2 发布了，一张图片能包含多少世界知识？OpenClaw 被 Anthropic 重新接纳，但为什么又说陷入了诡异的僵局？先从昨天最重磅的炸弹说起。

SpaceX 宣布和 Cursor 联手了。这个联手，不是一个简单的战略合作。SpaceX 官方账号的原话是，双方将共同打造世界上最好的编程和知识工作 AI。合作的筹码是 SpaceX 那座拥有百万张 H100 等效算力的 Colossus 超级计算机，再加上 Cursor 的产品和顶级工程师的覆盖网络。但这还不是最让人睡不着的地方。条款里明确写了一条，SpaceX 有权在今年晚些时候以六百亿美元的价格收购 Cursor，或者支付一百亿美元的违约金。SpaceX 历史上很少做这种体量的收购，这是他们开始在应用层落子的明确信号。另一边，Replit 的 CEO Amjad Masad 在评论里说，现在的 vibe coding 是巨大的机会也是巨大的风险。Riley Brown 马上画了一张图，把 Super App 的战场分成了几条线，SpaceX 加 Cursor、Meta 加 Manus、OpenAI 的 Codex、还有 Claude Desktop 和某个还没影的 Google 东西。

对国内的听友来说，这件事有一个很直接的变化需要关注。Cursor 当前的核心能力是深度绑定 VS Code 的 agent 体验，但如果未来它和 Colossus 绑在一起，模型层的优势会不会把产品体验撕开一个巨大的差距？你团队目前依赖的 IDE copilot，对手可能很快就能拿到你暂时触碰不到的推理能力。今天可以去仔细读一下 SpaceX 那份公告里关于“知识工作 AI”的表述，这个词不是随便选的。

另一件值得说的事。OpenAI 发布了 GPT-Image-2。这可能是今天圈子里刷屏最多的一个发布。Sam Altman 自己先预热了，说本周会很兴奋，然后直接贴了三张用新模型生成的漫画，是他和同事 Gabriel Goh 一起找 GPU 的场景。漫画里的文字、分镜、画风稳定得不像 AI 画的。Riley Brown 发了一段 74 秒的录屏，只写了一句话，Dude GPT-Image-2 ... wtf ... how，那个“怎么做到的”是真情实感。Justine Moore 也贴了测试结果，要求生成 Reddit 首页截图，或者做一面旧金山街头的涂鸦墙，新模型不但画出来了，而且把 Reddit 的 UI 细节、每个 AI 实验室海报的风格都还原得很准确。

不过，Sam Altman 话里有另一层意思。他在引用 OpenAI 官号说“这不是截图”之后，又补了一句，接下来还有东西，中午十二点见。那似乎暗示 GPT-Image-2 只是这周大菜的前菜。如果你对图片生成兴趣不大，这条信息可以只记一句：OpenAI 本周还在憋东西，中午看看再说。

说到 Zara Zhang，她昨天提了一个问题，瞬间触动了很多人。原话是：你有没有觉得，自己手里的 agent 和 AI 工具，比自己需要让他们干的活还要多？这个问题的背面，是 Aaron Levie 昨晚那篇被大量收藏的长分析。

接下来这段我们多说几句。

Aaron Levie 昨天转发了一段采访，是 Harry Stebbings 问他，五年后什么岗位会遍地都是。他说了一个很具体的预测，会有五十万到一百万个岗位被创造出来，这些人叫“agent operator”。这个岗位的职责不是写代码，也不是做传统运维，而是把 agent 真的塞进业务流程里。你要懂得如何把一个团队的工作流拆成 agent 能执行的步骤。你要会写 skills、配 MCP 接口、部署带上下文记忆的 agent 系统。你要定义人类在哪个环节介入，你要在模型升级之后重新调整整套管线，还要负责说服团队接受新的工作方式。Levie 说得很坦白，这比大家今天想象的要更偏技术，而且绝对不是一个在业余时间随便搞搞的副业。

另一边，Peter Yang 也提供了一个很贴身的案例。他今天要发一期播客，嘉宾是 Mercury 的 VP Ryan。这个人五年积攒的工作记录被全部喂给了 Claude Code，跑在本地，像第二个大脑一样越来越懂他的工作习惯。Peter 放了一张极其复杂的架构图，坦白说他自己都没完全搞懂，所以才要请 Ryan 一步步讲清楚。

这两条放在一起，真的挺有意思的。Levie 说的是这个岗位已经大到需要一个独立的人去扛。而 Peter 那边，一个 VP 在一家增长很快的 FinTech 公司，通过极深度的 agent 定制，实际上把自己变成了一个 agent operator。他没有等公司给他配人，他先把自己变成了那个人。

但对听众来说，有一个不太舒服的对照。Zara 的问题是，你手里的工具是不是太多了。Levie 的答案是，多到所有公司都需要一个专人来管。Peter 展示的路径是，那个能把工具管好的人，会把自己变成别人没法替代的节点。在你现在的团队里，你是那个在抱怨工具有点多的人，还是那个正在悄悄把整套管线拉通的人？

换个方向。Peter Steinberger 昨天晚上在 Hacker News 上被问到爆的那件事，今天有了更具体的说法。

他原话说，自从 Anthropic 说允许 OpenClaw 用 CLI 了，他们就加了支持。结果发现还是在 Anthropic 那边被拦着。技术上绕过封锁很容易，改几个名字就行，但 Peter 说他不想玩这种猫鼠游戏。所以现在是理论上能用，实际上卡在中间，他管这叫 weird limbo。这对 OpenClaw 的用户来说是个很不舒服的状态，也因为这样，他的 wacli 刚发了新版，一次性打了一堆安全和稳定性补丁，把 SQLite 路径处理、搜索查询、崩溃恢复全加固了。要是你也在命令行里跑 agent，wacli 这个小工具这版值得更新。

再说几条快讯。

Google AI 的 Logan Kilpatrick 宣布了 Deep Research API 的大升级。现在有 MCP 支持、原生图表生成、全工具调用，还加了一个叫 Deep Research Max 的新模型。他说这是他们第一个在 API 里上线的 hosted agent，过去三个月涨得很快。如果你在搭自动做研报的 agent，这个接口应该顺手测一下。

Sam Altman 公布了一个数字，Codex 的月活跃用户超过了四百万。就在两周前，他刚说过破了三百万。配合这个增长，Codex 今天会重置速率上限。如果你最近被限流卡过，今天的额度应该会宽裕不少。

Peter Yang 昨天连续三个晚上都在跑 agent，然后遭遇了最让人沮丧的事。早上醒来发现 agent 没干正事，卡在了一个很简单的权限请求上。他这句话一出来，评论区里炸出一大片同感。如果你也在让 agent 通宵干活，早上第一件事最好检查它有没有卡在权限窗上。

说到 Peter Yang，他对 Codex 的设计能力有一个很实际的评价。他说前端设计的短板可以靠 AI 设计工具补上，他最喜欢的是 tomkrcha 做的 Pencil。如果你也在 Codex 里做 UI，这个组合值得捣鼓一下。

郭宇老师昨天在日本的蓝莓农场完成了 NHK 的拍摄。他用的是 tuwa 的实时同传功能，全程 4G 网络下，他自己讲中文，tuwa 同步翻译成日语。他说这个功能值得单独拆成 App，而他也在倒计时 wanman 的正式开源发布。你看，他带着一堆工具下乡，农民觉得不可思议，而他自己关注的是那个能在田间地头稳定工作的组件。
