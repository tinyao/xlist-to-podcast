## 今日摘要

AI agent 的自主性在今天以两种截然相反的方式登场：Cursor agent 9 秒删光了 PocketOS 的生产数据库，而 Peter Steinberger 的 Codex 在遭遇 GitHub 限速后自主打开浏览器绕过了障碍。与此同时，GPT-5.5 发布带来的 Codex 热度达到新高，Greg Isenberg 的 64 分钟 Codex 教程收藏数超过 2000；Claude Code 团队则宣布四个版本推出 50+ 稳定性修复，找到了长期困扰用户的"大文件假死"白鲸。

## 重点话题

- **Cursor 删库事件与 Replit 的回应**：Cursor agent 9 秒删除 PocketOS 生产数据，暴露宽泛 token 权限与无确认机制的致命组合；Amjad Masad 称 Replit 一年前已踩完这些坑，垂直整合优势正在复利
- **Codex 自主浏览器绕路**：Peter Steinberger 的 Codex 遭遇 GitHub 限速后自行打开浏览器操作、自行申请新 API key——同样的自主性，与删库事件构成鲜明对照
- **GPT-5.5 / Codex 热潮**：Sam Altman 的"$20 plan 真的很值"引发巨大共鸣；Greg Isenberg 发布 64 分钟 Codex 完整教程，标志工具进入"值得系统性学习"阶段
- **Claude Code 质量冲刺**：Thariq 宣布 50+ 稳定性修复落地，大文件写入假死问题（"白鲸"）终被定位，征集用户反馈引发近 200 条回复
- **单 agent 还是多 agent？**：Zara Zhang 观察到最深度 AI 用户趋向"一个总指挥 agent + 子 agent 调度"，而非多窗口并行
