ChatGPT Pro 推出了一个月一千美元的新档位，这意味着什么？Karpathy 怎么解释圈内圈外对 AI 能力的认知撕裂？Claude 刚发布的 Managed Agents 是不是企业 agent 的工程标准答案？先从最炸的那条消息说起。

ChatGPT Pro 今天正式公布了新的定价档位，每月 1000 美元。Sam Altman 本人宣布了这件事。他的原话是，看到 Codex 这么受喜爱，很高兴，顺势推出一个高价版的 ChatGPT Pro 来响应大量需求。这个档位的核心卖点其实很直接，就是给重度使用 OpenAI Codex 和其他前沿模型的用户，一个接近无上限的体验。Sam 没有展开讲权益细节，但结合他前阵子聊定价策略的风格，这很像在沿着「高算力、高价格、高自由度」的路子往深走。

另一件值得说的事。关于 AI 认知的撕裂，Karpathy 今天发了一条很长的分析，在圈子里传了一夜。他把人群分成了两拨。第一拨人还在用免费或旧版模型，看了些 viral 视频，觉得 AI 连「去洗车是开车还是走路」都答不清楚。第二拨人每个月花 200 美元，在编程或数学这类高难度技术场景里，天天看着 Codex 和 Claude Code 花一个小时重构整个代码库。两拨人根本说不通。他认为根源有两个，一是代码这类领域有明确的、可验证的奖励函数，比如单元测试通过与否，这天然适合强化学习。二是这些方向能给企业带来真金白银，所以大公司的主力团队全扑在这。

不过事情的另一面是，非技术人群其实也在赶上。Karpathy 特别提了一个观察，有人告诉他，为什么前阵子 OpenClaw 带来那么大震动？因为那是第一次有这么多非技术人员，不是通过 ChatGPT 网页，而是亲身体验到了最新的 agentic 模型到底能干什么。他把这群重度技术用户的震撼叫做「AI 心理错乱」，因为进展斜率实在太陡了。你在用前沿模型吗？你身边有没有同事还停留在去年的印象里？这个认知差接下来可能只会越来越大。

说完这个，接下来这段我们多说几句。今天值得展开聊的，是 Claude 发布的一套企业级 agent 方案。

起因是 Anthropic 正式把 Claude Managed Agents 推进了公开测试。Anthropic 的产品经理 Robert Bye 和 Box 的 CEO Aaron Levie 都发了很具体的演示。这不再是实验室里的概念。Managed Agents 把 agent 的 harness、编排、沙盒、工具调用、连接外部系统都打包在了一起。

Aaron Levie 给了一个很具体的例子。在 Box 里接入 Claude Managed Agents 后，几分钟就能搭出一个工作流：合同一进来，agent 自动阅读、评审，然后在 Linear 里创建一个任务，把合同的关键信息填进去。他说这是一个可以复用到几百万个场景里的模式，从客户入驻文件审核到发票处理，再到并购尽调。他特别强调了一个判断，未来最大的 IT 挑战不是建 agent，而是让 agent 拿到正确的上下文。谁解决 secure 且 governed 的数据访问，谁就抓住未来十年的机会。

而另一边，Lenny 今天贴出了 Anthropic 增长负责人 Amol Avasare 的一个分享。Claude 团队建了一个叫 CASH 的增长 agent，Claude Accelerates Sustainable Hypergrowth。它的工作是全流程跑增长实验，找机会、出 feature、跑 A/B、读结果。目前的胜利率和初级产品经理差不多，而且还在快速变强。这件事的暗示挺明显的，不仅对外卖 agent，Anthropic 自己也在用 agent 接管增长工作。

对于工程师和产品团队来说，这波信号很实际。你不需要再纠结「要不要上 agent」，而是该想想公司里哪些业务流程已经有大量文档和结构化数据，却没有被自动化跑起来。如果你是在 SaaS 公司做产品，从 workflows 切入 agent 的时机已经很快了。Aaron 说他所想象的 agent 最大用武之地，不是聊天式的来回对话，而是那些 24 小时挂在后台、被流程触发、在系统间搬移数据和处理文件的 agent。

说到 token 用量，我们再讲一条快讯。
Vercel 的 CEO Guillermo 今天官宣了一套叫 Agentic Infrastructure 的概念。数据挺猛的，过去三个月 Vercel 上每周部署量翻倍，其中 30% 是由 agent 触发的，半年增加了十倍。他的逻辑是基建本身必须 agentic 化。比如 coding agent 要的不再是给人设计的界面，而是能自己点击的 infra。又比如从部署静态网页扩展到部署 agent 长时运行的计算，以及让基础设施能自我修复、自我扩展。

再说几条快讯。
Claude Code 的 Boris Cherny 分享了文件 @-mention 性能的三倍提升。过程很有意思，他们直接让 Opus 把 Rust 写的文件索引器重写成了 TypeScript，而且要求必须跑过原来的测试套件，性能还得更快。P99 延迟直接快了三倍。另外他们还给超大代码库的用户放开了自定义索引接口，可以对接 SourceGraph 或者私有的代码索引。

Claude Code 团队还整了一个 Monitor 工具，简单来说就是让 agent 可以写脚本在后台盯着。比如启动开发服务器后，用脚本监测错误日志，出问题再唤醒 agent。Thariq 特别提醒这功能需要明确 prompt 才能触发，但省 token 的效果很好。

Google 那边，Gemini 的音乐模型 Lyria 3 今天全面开放了。不到 50 天的时间里，用户在 Gemini 里生成了超过一亿首歌。现在每天能生成五首完整版曲子，用完额度还可以接着做 30 秒的片段。Josh Woodward 的推文里有一句话挺说明问题，「你有想法，Gemini 有工具」。

还有一条和开发者工作流有关的。微软的 Markitdown 工具又被翻出来讨论了，一个能把任何文件转成干净 Markdown 给 LLM 吃的工具。但 Obsidian 的 kepano 吐槽说它现在已经变成一个巨大且混乱的项目。他反而希望微软官方能出高质量的库，把自家那些 .docx、.xlsx、.pptx 转成 Markdown。顺带提醒一句，如果你在用 Obsidian，他们有自家的 Web Clipper 做网页转换，还有 Importer 专门接 Notion、Apple Notes 这些笔记工具。

如果你在搭建 agent 产品，今天这几个发布都在指向同一个方向：让 agent 能安全地拿到数据、在后台长期活着、以及基建本身能接住这种规模。你怎么看 Pro 这个每月一千美元的定位，会长期成为新常态，还是个过渡定价？
