## 今日摘要
OpenAI 推出每月 1000 美元的 ChatGPT Pro 新档位，进一步瞄准重度技术用户。Karpathy 长文分析 AI 认知撕裂，指出编程等可量化领域进展巨大，与普通用户体验严重脱节。Claude 发布 Managed Agents 进入公开测试，Box CEO 演示企业工作流自动化，并预言 agent 获取上下文将是下个十年的核心 IT 挑战。Vercel 提出 Agentic Infrastructure 方向，强调基建必须本身 agent 化。

## 重点话题
- ChatGPT Pro 千美元档位：OpenAI 针对 Codex 等前沿模型的重度用户推出高定价、高算力方案。
- AI 认知撕裂：Karpathy 解释为何技术圈内感受与大众印象差距巨大，强化学习在可验证领域造成的能力极不平衡。
- Claude Managed Agents：一套集成 harness、沙箱和系统连接的企业级 agent 构建方案，已在 Box 等场景落地工作流自动化。
- Agentic Infrastructure：Vercel 披露 agent 已在触发其每周三成的部署，宣布基建需转向自我配置、自我修复的 agentic 形态。

## 快讯
- Claude Code 通过 Opus 重写索引器，@-mention 性能获三倍提升，开放自定义索引接口。
- Claude Code 推出 Monitor 工具，让 agent 可通过后台脚本监测错误并唤醒自己。
- Gemini 开放 Lyria 3 音乐模型，用户已生成超一亿首歌，现每天可制作五首完整歌曲。
- Microsoft Markitdown 项目被指过于杂乱，Obsidian 创始人呼吁官方提供高质量格式转换库。
