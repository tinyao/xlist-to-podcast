## 今日摘要
Claude Code 桌面版迎来彻底重构，从终端工具进化为多会话工作站。Cal.com 因 AI 安全威胁关闭核心代码库，引发开源社区对安全与透明度的激烈争论。Greg Isenberg 和 Guillermo Rauch 从不同角度探讨了 AI 时代开源的价值和未来。此外，Gemini 发布 3.1 Flash TTS 模型并推出 API 预付账单，Cursor 新增 /canvas 交互式画布功能，Allbirds 宣布转型 AI 算力的荒诞新闻成为圈内笑谈。

## 重点话题
- Claude Code 桌面版重构：支持多会话并行、侧边栏管理、git 状态查看，但跨设备连续性仍是短板
- Cal.com 关闭开源代码库：AI 让代码透明变成安全暴露，Peter Steinberger 回应称安全加固和公开公告是唯一出路
- 开源的身份危机：AI 写代码正在挤压"贡献-成长"的社区循环，复杂度不再是护城河
- Cognition 发布 SWE-check：用强化学习训练的 bug 检测模型，速度比前沿模型快 10 倍

## 快讯
- Gemini 3.1 Flash TTS 发布，支持 70 种语言和场景级控制，但 API 服务稳定性承压
- Cursor 推出 /canvas 功能，agent 可生成交互式仪表盘和自定义界面
- Windsurf 2.0 发布，swyx 称今年是"子 agent 之年"
- Allbirds 改名 NewBird AI，用 5000 万美元可转债买 GPU 转型 AI 算力
- Notion AI 团队在 Latent Space 播客首次完整讲述五次重构故事
