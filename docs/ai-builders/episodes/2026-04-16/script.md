Claude Code 桌面版重新设计了，这次不只是换个界面。Cal.com 为什么突然关闭了核心代码库？Allbirds 要转型做 AI 算力，这事到底有多离谱？先从最让人兴奋的那件事说起。

Claude Code 的桌面应用昨晚迎来了一次彻底重构，Anthropic 把它从一个终端工具变成了真正的多会话工作站。

Boris Cherny 和 cat 两位 Anthropic 团队成员都确认了这个发布。新版本的核心变化是：你可以在一个窗口里并行跑多个 Claude Code 会话，左侧有侧边栏统一管理。cat 提到，她已经几周没打开 IDE 或终端了，所有工作都在这个桌面应用里完成。具体功能包括实时查看 git 状态、固定活跃会话、拖拽布局同时看多个会话窗口。

Peter Yang 试用后提了一个很实际的问题：怎么在手机端继续同一个会话？他试了 /remote-control 命令，没成功。而他的观察是，用户不应该需要手动输入命令才能实现桌面和移动端的无缝切换。这暴露了一个产品断层——桌面端体验在快速进化，但跨设备连续性还没跟上。

如果你今天在用 Claude Code，这个桌面版值得立刻试一下。不过移动端的体验，可能还得再等几个版本。

另一件值得说的事。Cal.com 宣布关闭核心代码库，不再开源。CEO Bailey Pumfleet 的原话是，AI 彻底改变了安全格局——代码不再只是被人阅读，它被扫描、映射、以近乎零成本的方式利用。

OpenClaw 的创始人 Peter Steinberger 回应了这个决定。他承认感受到同样的压力，有几百个团队在尝试攻破 OpenClaw。但他的团队选择的是另一条路：快速迭代加代码加固，同时公开发布安全公告。他特别提醒，要警惕那些不做安全加固、不公布漏洞报告的开源项目。

Peter 还提到 GPT 5.4-Cyber 对闭源软件的反向工程能力，暗示未来的安全威胁只会更严重。Replit 的 CEO Amjad Masad 也插了一句：如果漏洞发现完全自动化了，GitHub 应该出一个新指标，显示一个开源包花了多少算力做安全加固，就像 star 数一样。

这件事对做开源工具的团队是个警钟。安全投入正在从可选项变成生存门槛。如果你在维护一个有用户基础的开源项目，现在就该考虑：你的安全公告页面更新了吗？

说到安全，Cognition 今天发布了 SWE-check，一个专门用来检测 bug 的模型。swyx 透露，这个模型是和 Applied Compute 合作、用强化学习训练的。它在内部评测上对标前沿模型，速度却快了 10 倍。

swyx 顺便分享了一个更通用的洞察：AI 工程的核心不是直接去突破模型能力边界，而是先"capabilitymaxx"——用各种模型和工具的排列组合去推高帕累托前沿，然后再做蒸馏。他说这在几乎所有场景下都有效。而 Applied Compute 正在给每个做这种事的 Agent Lab 提供武器。

换个方向。Gemini 今天有两件事。一是 Gemini 3.1 Flash TTS 语音合成模型发布，Logan Kilpatrick 说从 2.5 到 3.1 的进步非常强。这个模型支持场景指导、说话人级别控制、音频标签，覆盖 70 种语言。可以在 AI Studio 的新音频游乐场里体验。

二是 Gemini API 终于支持预付账单了，先从美国用户开始。Logan 说这对于开发者来说让使用 Gemini 变得更容易了，国际推广在未来几天内进行。不过 Hamel Husain 贴了一张截图，显示 Gemini 返回了 503 错误，提示模型当前需求过高。这让人想起 Peter Yang 的抱怨——他感觉 Claude 每隔一天就宕机一次。

两边的服务稳定性都在承压。如果你在生产环境依赖这些 API，现在可能不是把所有鸡蛋放在一个篮子里的好时机。

今天值得展开聊的，是开源这件事正在经历一场身份危机。

起因是两条平行发生的讨论。一边是 Cal.com 关闭核心代码库，一边是 Greg Isenberg 提了一个问题：当 AI 写了 100% 的代码，开源会变成什么样？

Greg 的观察很戳人。他说开源系统的整个文化是建立在人类贡献行为上的——你学习、你挣扎、你提交 PR、你收到反馈、你变得更强。这个循环培养了工程师，创造了社区，建立了归属感。但如果 AI 写 PR，谁拥有它？谁从中学到了东西？谁会在凌晨两点因为在乎而爬起来 debug？

Guillermo Rauch 从另一个角度回应了这个问题。他转发 basement.studio 团队用 Claude Code、Three.js、Next.js 和 Vercel 自建的 Shader Lab 工具，说这才是设计的未来——不是这个具体工具，而是每个团队现在都有能力建造自己的"设计工厂"。他提到 basement 内部部署了一整套自研工具，有些是为单个项目做的，有些是通用的。Guillermo 的结论是：现在生成软件、重组强大的构建块，比搜索和采购合适的 SaaS 更容易。

这两条线看起来方向相反，但指向同一个变化。开源曾经是"代码透明"的代名词，但 AI 让透明变成了暴露。同时，AI 也让"自己造工具"的成本降到了可以替代采购 SaaS 的程度。开源社区赖以运转的"贡献-成长"循环，正在被"AI 写代码-人类审核"的模式挤压。

对听众来说，这件事有一个很具体的对照点。如果你在做开发者工具或开源项目，现在需要想清楚三件事。第一，你的安全投入是否跟得上 AI 辅助攻击的速度。第二，你的社区价值到底在代码本身，还是在围绕代码的人和组织。第三，如果"自建"的成本继续下降，你的产品被替代的门槛有多低。

Nan Yu 今天说了一句话：复杂度不是护城河。它挡不住更快的竞争者，也挡不住 AI，因为 AI 会用 bitter lesson 的方式把它抹平。这句话放在今天的语境下，格外应景。

再说几条快讯。

Cursor 的设计师 Ryo Lu 展示了 Cursor 的新功能：输入 /canvas，可以让 agent 生成交互式画布来可视化信息，比如仪表盘和自定义界面。他说这是"未来的一瞥"。

郭宇今天有个挺有意思的 vibe 感想。他把知识工作分成三类：创意发散、分解执行、一致性确认对齐。三者循环一次就是一个 agentic loop。他之前做的 sandbox SDK 项目，现在相当于被集成进了 OpenAI 的 Agents SDK 里。不过他的实际体验是，自建的 boxlite cloud 比公共 sandbox 云服务快得多。

Windsurf 2.0 今天发布了。swyx 评论说，今年是"子 agent 之年"，但这更多是个优化问题。反向的问题——让 agent 能组合、让管理型 agent 能查询它们——是能力问题。他作为 Cognition 的顾问，参与了 Spaces 概念的设计。

Allbirds 宣布卖掉鞋业品牌，改名为 NewBird AI，用 5000 万美元的可转债买 GPU，转型做 AI 算力基础设施。Matt Turck 调侃说，这个激进转型一定是经过了大量的"sole searching"——sole 这个词既指鞋底，也指灵魂。Amjad Masad 也拿这事开玩笑，说以后有人问"你在哪里跑推理"，回答是"Allbirds"。

如果你最近在做 agent 相关的产品，Notion AI 团队在 Latent Space 播客上的深度访谈值得一听。Simon Last 和 Sarah Sachs 讲述了 Notion AI 五次重构的完整故事，包括他们如何评估 agent 的"有用性"而不只是正确性，以及为什么他们为"班级第一名"设计，而不是把 AI 变笨来适应所有人。

今天你打开 Claude Code 桌面版的时候，不妨留意一下：你是更在乎它跑了多少个会话，还是更在乎你能不能在任何设备上随时接上之前的工作？我们明天一早再见。拜拜。
