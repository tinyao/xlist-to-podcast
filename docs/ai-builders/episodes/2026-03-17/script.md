"我们需要一个比 vibe coding 更好的词。"

Thariq 发这条推文的时候，只附了一张截图——他让 Claude 做了一个把数学和苏菲主义融合在一起的 HTML 页面，顺手用 Gemini API 配上了生成的图。就这样。四千多个点赞。

他没有解释这个词哪里不够，只是展示了一个结果，让看到的人自己感受那个落差。

今天是 2026 年 3 月 17 日，欢迎收听 AI Builders Daily。今天 GPT-5.4 发布满一周，Sam Altman 公布了一组值得停下来算一遍的数字；Greg Isenberg 一条 46 秒的视频拿下了今天最高的收藏量，这件事我放在今天最重要的位置来展开；还有 Peter 和 NVIDIA 一起在做的两个新东西，指向一个大家一直绕着走的问题；Amjad 说出了一句很多人心里有但没有说出来的话。

开始。

---

先说 GPT-5.4 的第一周。

Greg Brockman 今天公布了 API 数据，Sam Altman 转发并加了几句话。核心数字是：发布后一周内，GPT-5.4 在 API 上达到了每天五万亿 token 的处理量。Brockman 说，这已经超过了一年前 OpenAI 整个 API 的总体量。净新增年化收入跑到了十亿美元。他用了一句话："ramp faster than any other model we've launched"。

这组数字之所以值得单独说，不只是因为绝对值大，而是因为有对照。同样的基础设施，一年前的全量，现在一个模型一周就追平了。这不是逐渐爬坡的曲线，而是斜率突然改变的那种增长。

但 Sam 那天回复的另一条推文，坦白说，更让我停下来想了一下。有人观察说，GPT-5.4 最突出的特质不是代码能力有多强，而是它的"humanity"——一种更有温度、更像人的气质。Sam 的回复是：他完全同意，"从 5.3 到 5.4 的升级，我自己感受很深"。

这个角度是新的。过去两年，代码、推理、数学基准，这些维度的竞争非常密集，也很量化。但现在，OpenAI 的创始人在公开场合主动强调的是体验的质感——一种很难量化但用过就感觉得到的东西。当纯能力指标越来越接近，这里正在成为下一个竞争的地方。这个方向 Anthropic 和 OpenAI 都在走，今天是 Sam 把它说出来了。

说到 Claude 做出"有美感的东西"，Thariq 那条推文是今天最好的注脚。

他是 Claude Code 团队的工程师，不是做 demo 给外部用户看的 PM，而是真正在写这个工具的人。给 Claude 的提示词很简单：灵感来自某位艺术家的风格，做一个"结合数学和苏菲主义"的 HTML 页面，配上 Gemini 生成的图，截图发出来，就触发了那四千多个点赞。

为什么这条推文触动了那么多人？在我看来，它准确说出了一件很多人在用 Claude 做东西时已经感受到、但还没有明确表达过的事：这不只是在调参，不只是在做 prompt 工程，有时候它会出现真正让你意外的东西。vibe coding 这个词，原本就带着一种轻飘飘的感觉——随意、探索性、试试看。但这个词已经装不下那些认真的、有美感的、超出预期的输出了。

同一天他还发了另一条，说自己可能"低估了百万 token 上下文"。"性能真的非常好，我现在基本上不清空上下文了。"

两件事放在一起：创作质量超过了工具创作者自己的预期，长上下文的实用价值比发布时宣传的还要高。这不是营销文案，是一个深度使用者对自己产品的重新评估。

下面这个话题，我先说一个数字：两千八百三十个收藏。

Greg Isenberg 发了一条 46 秒的短视频，演示把 Claude Code 和 Obsidian 接在一起、当作个人操作系统来用。两千零六十四个点赞，两千八百三十个收藏。在我跟踪这个圈子的这段时间里，实操类推文能达到这个收藏量，是不多见的。

收藏而不只是转发，意味着"我以后要用到这个"。两千多人存下了它。

方法本身说起来不复杂，但把各部分拼起来的方式值得认真看。

Obsidian 是本地的 markdown 笔记工具，你把日常想法、项目记录、会议内容、决策过程全部写进去，文件之间可以建链接，整个结构就是你思维方式的一个外化。装一个 CLI 插件之后，Claude Code 就可以读取你的整个 vault，包括文件和文件之间的关联关系，而不只是单个文件的内容。

管道接通之后，你可以建一套自定义命令。`/context` 加载你当前的完整工作状态，不需要每次开新 session 都重新给 Claude 交代背景；`/connect` 让 Claude 从你的笔记里找出两个你一直分开思考、但其实有关联的方向；`/trace` 看某个想法在过去几个月里是怎么演化的；`/graduate` 把日常的碎片提升为可以真正推进的项目资产。

Greg 特别强调的一条原则，在我看来是这套工作流最关键的地方：人写 vault，agent 读 vault、建议、执行。你的第一手经验、判断、洞察，全部由你来写进去；AI 来读、来连接、来执行任务。这条分工线如果保持清晰，时间越长，你的知识库越是独属于你的；如果这条线模糊了，你会发现笔记开始越来越像 AI 的泛化输出，没有味道，也没有护城河了。

这个方向已经有人探索很久了，不是 Greg 发明的。但那 46 秒做到了一件事：它把这个工作流变得可见，让你看到它真正跑起来的样子。门槛从"听起来复杂，以后再说"变成了"等等，我看一遍就懂了"。有时候，行动和永久搁置之间的全部距离，就是这 46 秒。他还配套做了一期完整的播客，里面有一个叫 internetvin 的用户案例，这个人把整套生命积累都接进了这个工作流。链接在 shownotes 里。

OpenClaw 今天两个进展，放在一起说。

CodexBar 0.18 发布了。这是 Peter 做的 menubar 小工具，用来可视化 Codex 和 Claude 的使用情况。新版本加了 Kilo、Ollama、OpenRouter 三个新 provider 支持，有了历史使用节奏的分析和风险预测，CPU 和内存消耗也压下来了。对于重度使用 coding agent 的人来说，这解决的是"我不知道自己在哪儿烧钱"这个问题——功能不华丽，但用过之后会反复去看。

另一个更值得关注。Peter 发推说，他和 NVIDIA AI 的团队一起开发了 OpenShell 和 NemoClaw，称之为"向可信安全 agent 迈出的巨大一步"。具体细节还没有披露，但方向很清楚：给 agent 运行的 shell 环境和 agent 本身，加上真正的安全边界和可信机制。

这个问题一直没被正面解决：agent 越来越能干，但"我怎么知道它不会做我不想让它做的事"，大多数时候靠的是信任和惯例，不是机制设计。OpenShell 和 NemoClaw 是朝机制层面解这道题的一次具体动作。

NVIDIA 在这里的角色也值得关注。上周是他们派工程师帮 OpenClaw 处理安全漏洞报告，这周是双方联合构建基础设施。这条合作线在加深，重量在升级。

Amjad Masad 今天说了一句话，简单，但准。

"AI 让工作变孤独了。"

以前，设计和写代码是发生在人之间的事，有讨论，有来回，有那种感觉。现在每个人盯着自己的 agent，速度上去了，但协作的质感消失了。

他的问题是：为什么不能一起 prompt？

Replit Agent 4 上了一个新功能，尝试给这个问题一个答案：多人可以同时对同一个 agent 发指令，谁先、怎么合并、冲突怎么处理，Agent 4 来解决。功能本身不大，但他把这个问题说出来这件事值得停一下想想：AI 工具在帮你个人加速的同时，有没有在悄悄侵蚀团队协作的质感？注意到这件事，是调整工作方式的起点。

快讯时间。

Aaron Levie 今天的一条推文，反的是一个非常流行的直觉判断。他说：AI 暴露度高的工作，不一定是威胁，可能反而是机会。逻辑很直接——以前一个项目需要五十个工程师，ROI 不够，不做；现在 AI agent 把需求降到十个人，ROI 突然成立，公司反而雇了十个人。AI 降低了每单位输出的成本，但同时激活了大量之前压根连启动都不值得的需求。需求弹性大的领域，AI 可能带来的是扩张，不是收缩。这个视角，值得在所有"AI 会让 X 消失"的讨论里先问一句。

Perplexity 宣布，Computer 现在可以接管本地的 Comet 浏览器，在本地跑一个完整的浏览器 agent，不需要 MCP，不需要 connector，直接访问已登录的所有网站。Denis Yarats 特别强调，整个过程完全在本地，cookies 不离开设备，用户对 agent 的行为有完整的可见性和控制权。这和 OpenClaw 之前做的 Chrome DevTools 接管是同一个方向，但 Perplexity 走的是自家客户端路线。

Google 的 Gemini API 这周降低了开发者的上手门槛：升级通道从三十天缩到三天，门槛消费从两百五十美元降到一百美元，支出上限和监控面板也上线了。Logan Kilpatrick 说还有更多更新在路上。API 能力再强，开发者上手的摩擦越大，实际采用就越慢。这些变化，影响是实际的。

Linear 的 Nan Yu 分享了一个教训：他们撤掉了一个精心设计的生成式 AI 功能，原因是用户太容易按那个按钮了，而不是真正把工作做完。他的反思是：给人一个偷懒按钮，大多数人会按。对于任何在产品里加 AI 功能的人，这个问题值得提前想清楚——我在帮用户做事，还是在帮用户绕过做事本身？

一个 17 岁高中生 Austin Way 用十万个模拟学生构建了一套 ML 反馈循环：Qwen 3 8B 扮演学生，学完课程参加 AP 考试，两周内平均分从 3 分迭代到 4.43 分，约在全国 80 百分位。整个过程，模型从来没被直接训练怎么解题，只学了基础知识，靠的是自动化反馈循环不断修正课程设计。他在 ClawCon 和 SXSW 都分享了这个项目。Peter Yang 转发这件事时说：这孩子明明应该在准备申请大学的年纪。

郭宇在东京办了读书会，主题是"最好的软件将不再由团队构建，而是由有远见的个体与 AI 共同创造"。同时他也在把已发布的产品全部接入自进化循环，让 agent 24 小时自动跑测试和迭代。他在推文里说，"连拼乐高都自动化了之后，vibe 就是纯享版的思维游戏了"，还提到自己快要结束 vibe 阶段了——后续往哪儿走，值得记一下。

---

绕回开头那句话。我们需要一个比 vibe coding 更好的词。

今天几件事放在一起，底下有同一根线：我们使用这些工具的方式，还没跟上工具本身已经能做到的事。Thariq 说 Claude 能创作出让他自己都惊喜的东西，但现有的词装不下。Greg 的工作流说，你的个人知识库如果设计得好，AI 会越来越在你的框架里工作，而不是替代你的判断。Aaron Levie 说，AI 降低成本的地方，可能正好是需求要爆发的地方。

到处都在追赶——词在追赶现实，方式在追赶工具，需求在追赶供给。

但追赶的人，才是在跑的人。
