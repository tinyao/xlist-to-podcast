## 今日摘要

GPT-5.4 发布满一周，Sam Altman 公布每天五万亿 token、年化十亿美元新增收入的数据，同时谈到"humanity"正在成为模型下一个竞争维度。Claude Code 团队的 Thariq 发出今日最高互动推文，说需要一个比"vibe coding"更好的词。Greg Isenberg 的 Claude Code 配 Obsidian 工作流视频拿下近三千收藏，是本期最值得实践的内容。Peter 联合 NVIDIA 推出 OpenShell 和 NemoClaw，朝 agent 可信安全迈出具体一步。

## 重点话题

- **GPT-5.4 首周数据**：每天五万亿 token，年化十亿美元净新增收入，Sam Altman 强调"humanity"正成为新的差异化维度
- **Thariq 的两条推文**：需要比"vibe coding"更好的词，同时表示低估了百万 token 上下文的实用价值
- **Claude Code 配 Obsidian**：Greg Isenberg 的 46 秒视频创下近三千收藏，核心是把本地知识库接入 Claude Code 的完整工作流，以及"人写 vault，agent 读执行"的分工原则
- **OpenShell + NemoClaw + CodexBar 0.18**：Peter 与 NVIDIA AI 联合构建可信 agent 安全基础设施；CodexBar 0.18 发布，新增多个 provider 支持
- **AI 让工作变孤独**：Amjad Masad 提出协作 prompting 的问题，Replit Agent 4 尝试用多人同时发指令来解决

## 快讯

- Aaron Levie 反驳线性消失论：AI 降低成本，有可能反而激活更多需求，AI 暴露度高的工作未必是威胁
- Perplexity Computer 接管本地 Comet 浏览器，完整浏览器 agent，cookies 不离开设备
- Gemini API 降低开发者门槛：升级从三十天缩到三天，门槛消费从 $250 降到 $100，支出上限上线
- Linear 的 Nan Yu：他们撤掉了一个 AI 功能，因为用户太容易按那个偷懒按钮了
- 17 岁高中生 Austin Way：十万模拟学生 + ML 反馈循环，两周内 AP 考试均分从 3 分迭代到 4.43 分（80 百分位）
- 郭宇东京读书会："最好的软件将不再由团队构建，而是由有远见的个体与 AI 共同创造"，并宣布快要结束 vibe 阶段
