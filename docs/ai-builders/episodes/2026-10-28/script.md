一个能实时生成互动世界的模型今天在 X 上刷屏了。Google DeepMind 的 Genie 4 首次对外展示，a16z 的 Justine Moore 和 Google 的 Logan Kilpatrick 都放出了视频。

Justine 说这是从单一提示生成的完整互动世界。角色和环境都可以用提示改变，而且支持原生音频。她用的词是“massive step forward”。

Logan 则透露，Genie 4 是 DeepMind 的新前沿世界模型，很快会通过 API 提供。这是世界模型首次对外开放。他还发布了一个 47 分钟的深度访谈，和团队聊技术进展。

视频里能看到类似 GTA 的驾驶场景，但所有画面都是 AI 实时渲染的。没有预置的 3D 资产，一切都是模型“想象”出来的。Justine 调侃说“We got GTA Waymo before GTA 6”。

世界模型这个赛道最近很热。OpenAI 有 Sora，Runway 有 Gen-3，但 Genie 4 的实时交互性让它更接近游戏引擎。Logan 在访谈里提到，未来方向是让模型理解物理规律，生成更一致的世界。

如果你在做游戏、模拟或交互式内容，这个方向值得盯紧。Genie 4 的 API 开放后，可以试试把实时生成的世界嵌进你的产品。不过目前还是早期预览，可控性和延迟还需要观察。

Replit 的代码库现在可以被自然语言直接修改了。CEO Amjad Masad 今天宣布了 Cloud Agents 功能。

具体来说，任何人在 Replit 上描述需求，Cloud Agent 就能生成代码并提交 PR。工程师负责审核合并。Amjad 说，他们自己的设计团队过去 6 个月用这种方式提交了超过 25 万行代码。

这相当于把“自驱动公司”的概念落地了。产品、设计、甚至运营都能直接参与代码库，不用等工程师排期。Replit 的 Cloud Agents 可以运行任何代码库，不只是 Replit 项目。

Amjad 在推文里说，以前回答“Replit 是用 Replit 构建的吗？”是“有点”，现在是“绝对”。这个转变背后，是 AI agent 真正融入了他们的开发流水线。

Replit 的这步棋，本质上是在降低软件开发的参与门槛。当非工程师也能安全地贡献代码，团队的创新速度可能成倍提升。不过，工程师的审核负担会加重，如何平衡是个新课题。

如果你在带一个跨职能团队，可以考虑引入这种协作方式。它可能帮你打破工程瓶颈，但前提是你的工程师愿意接受这种新的贡献模式。你会怎么说服团队尝试？

一位 CEO 今天宣布他不再用 Figma 了。他的首席设计工程师是一个 Grok bot。ADPList 的创始人 Felix Lee 分享了这背后的数据。

Felix 说，他给 Grok bot 设定了“首席设计工程师”的角色。它不直接 ship，但会做几乎所有的设计工作。他只需要在最后批准。

具体来说，这个 bot 每周会分析平台数据，找出 drop-off 并生成设计方案。它还会研究最好的应用，把想法写成 Linear 任务。当设计足够好时，它会提醒 Felix 别再打磨了。

结果如何？Felix 透露，自从用上这个 bot，平台 engagement 增长了 22%，流量增长了 10%。对于一个没有招聘设计师的团队来说，这个回报很惊人。

不过 Felix 也承认，有些设计挺一般的，他会直接告诉 bot。整个过程更像是有一个永不疲倦的设计伙伴。他之前还说过，设计师比工程师更适合做 founder，因为他们更关心用户和问题解决。

如果你是小团队 founder 或者独立开发者，这个案例值得琢磨。它可能让你重新思考“必须招设计师”这件事。但前提是你的 bot 能真正理解你的产品和用户。

Bun 的 AOT 编译器在实测中把性能提升了 2 到 3 倍。Peter Steinberger 周末做了测试，今天早上分享了结果。

他用 Bun.serve 的 HTTP 服务器跑测试，开启 AOT 编译后，性能直接翻倍以上，内存使用降到了原来的一半以下。在 macOS 上，编译出的二进制从 89MB 瘦身到 25MB。

这个瘦身得益于 AOT 编译的 --trim 选项，会自动删除未使用的代码。Peter 的评价是“amazing”。Bun 的 AOT 编译器之前由 Jarred Sumner 发布，但这次实测数据让收益更直观。

对于追求高性能和轻量部署的团队，这是个不小的诱惑。尤其配合容器化，更小的二进制和更低的内存占用能直接省钱。Bun 的 AOT 编译对 Node.js 生态也是个冲击。

如果你在用 Bun 做后端服务，可以试试 AOT 编译。不过记得先在测试环境跑通，AOT 编译可能对某些动态特性有影响。如果你还在用传统运行时，看到这个性能差距可能会心动。

Claude Duet 被一位重度用户公开放弃了。Riley Brown 今天发推说，他已经回到 Claude Code Projects。

Riley 是 agent 领域的活跃 builder，他之前就详细比较过 Duet 和 Projects。核心槽点在于：Duet 没有在所有请求中使用 Opus 5.5，模型降级后体验明显变差。而 Claude Code Projects 可以自选模型，还能指定是否在本地运行 Claude Code 会话。

他说，一旦用过 Opus 5.5，任何差一点的模型都难以忍受。有趣的是，Riley 今天把自己的多个 Projects 合并成一个，直接命名为 Duet，有点嘲讽的意思。

另一边，Anthropic 的 Gabe Mulley 在回复中坚称他们只用 Opus 5.5，并承诺很快会支持本地 Mac 访问。这场公开对话在圈子里传了一夜。

swyx 今天也掺和进来，自嘲错过了 Claude Code 的早期投资机会。他说自己 2019 年就提过类似 idea，但没做。这从侧面印证了 Claude Code 的价值。

如果你在用 Claude 的产品，可能需要重新评估一下 Duet 和 Projects 的选择。我们接下来把这件事展开聊聊。

今天值得展开聊的，是这件事。

Riley Brown 的吐槽不是第一次了。他之前就详细对比过 Duet 和 Claude Code Projects。核心结论是：Projects 更灵活，模型可控，还能并行跑任务。

而 Duet 虽然 UI 更友好，但模型降级的问题让他无法忍受。他今天正式宣布“churn”，回到 Projects。为了表达态度，他把自己的多个 Projects 合并成一个，直接命名为 Duet。

Riley 还分享过他的梦想 agent 工具清单。这个清单很长，包括始终用 Opus 5.5 级别模型、能同时控制云端和本地电脑、有实时语音交互、能生成高质量文档和设计、支持 webhook 和插件。

他说，Duet 显然没达到这个标准。尤其是在模型一致性上，一旦你习惯了 Opus 5.5，任何降级都像在用一个“lite”版。他还补充说，希望 VM 浏览器不被网站屏蔽，现在的屏蔽率太高了。

Riley 之前也表达过一个观点：AI 是放大器，能从中获益最多的人，是那些没有 AI 也能完成工作的人。所以他建议先学技能，再用 AI。这个思路放在 agent 工具上同样适用——你得先懂设计或编程，才能判断 agent 的输出质量。

另一边，Anthropic 的 Gabe Mulley 在回复中坚称他们只用 Opus 5.5。这暗示 Riley 的体验可能是个例，或者与特定任务有关。同时他承诺很快会支持本地 Mac 访问。

这说明 Duet 团队在快速迭代。但用户的感知是真实的——当 agent 的表现忽高忽低，信任就会打折。这可能是 Anthropic 产品线的一个尴尬：Claude Code 太硬核，Duet 想简化却牺牲了智能。

swyx 今天也来凑热闹。他自嘲说，当年错过 Claude Code 的早期投资，估计损失了 5 亿美元。他还在 2019 年就提出过类似 Claude Code 的想法——一个自适应的、基于意图的 CLI 状态机。

但他没做，眼睁睁看着别人做成了。这侧面说明，Claude Code 这个产品形态确实踩中了市场需求，而且技术时机到了。

Thariq 的视角更技术。他是 Claude Code 的前成员，现在做了一个 AI-native 的 macOS dock。这个 dock 能根据你的活动自动切换模式，比如写作模式、编程模式。

他用 agent 实时分类通知并自动操作，甚至可以让 agent 自定义 dock 的行为。这可能是 agent 与 OS 深度整合的雏形。Thariq 还提出，需要一种新的开源软件分发方式，让 agent 能自动修改代码并合并上游。

从 Claude Code 到这类实验，能看出 agent 工具正在从命令行往系统层渗透。未来的 agent 可能直接住在你的操作系统里。

整件事给我们的启发是：在 agent 工具里，智能的一致性比 UI 的流畅更重要。用户一旦尝过最强模型的能力，任何降级都会导致流失。

如果你在构建 agent 产品，或许应该让用户自己控制模型选择，哪怕这意味着界面复杂一些。另外，要警惕“为易用性牺牲智能”的陷阱。用户对 agent 的期待是一个可靠的同事，不是一个时好时坏的实习生。

对于用户来说，选择 agent 工具时，建议先明确你的需求。是需要灵活性和控制力，还是开箱即用？然后实际测试模型在不同任务上的表现是否一致。别只看宣传，看它在你最在意的场景里会不会偷偷降级。

你的工作流里，有哪些环节已经交给 agent 了？它有没有让你失望过？
