## 今日摘要
Codex 发布 /pet 和 /hatch 新功能，Sam Altman 亲自下场说它比看起来更有用。Aaron Levie 连发三条长帖，深入分析 agent 时代的软件定价模型变迁，从 seat 到 consumption model 的过渡路径。Stripe 正式推出 Link wallet for agents，agent 经济开始从"干活"走向"花钱"。Peter Steinberger 开源了 Crabbox 远程测试工具，郭宇的 wanman agent 完成自动部署能力升级。

## 重点话题
- **Codex 的 pets 和 hatch 功能**：虚拟宠物互动和 sprite sheet 自动生成，Sam Altman 称"比看起来更有用"
- **Aaron Levie 论 agent 时代的软件定价**：人的 seat 不会消失但必须带 API 额度，agent 可能有自己的 seat 但定价完全不同，consumption model 会成为主导
