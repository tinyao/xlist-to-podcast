## 今日摘要
Vercel 发布 agent 框架 eve 及一整套 agent 基础设施，Guillermo 将其定位为"Next.js for agents"。智谱 GLM-5.2 开源模型跑分超过 Opus 4.8，同时推出像素级复刻 Codex 的桌面应用 ZCode。Replit Vibecon 开幕，宣布语音输入和 Claude Design 集成。多位设计领域人物讨论了设计师角色向终端迁移的趋势。Anthropic 的 Fable 5 仍被美国政府限制，WIRED 做了正式报道。

## 重点话题
- Vercel eve 框架与 agent 基础设施发布：eve 以文件系统为核心，一个 agent 就是一个目录，对标 Next.js 在 web 应用中的角色。同时发布 Vercel Connect 和 24 小时沙箱。
- GLM-5.2 与开源模型追赶：MIT 许可、1M 上下文、跑分超 Opus 4.8，中国公司同时推出 Codex 复刻版 ZCode，引发对开源与闭源差距的讨论。
- 设计师角色迁移：从 Peter Yang 的匿名设计师案例，到 Cursor 设计师 Ryo Lu 的实践，再到 Linear 产品负责人 Nan Yu 对"taste"定义的区分，设计师的工作界面正在从画布转向终端。

## 快讯
- Unreal Engine 5.8 实验性支持 MCP 协议，游戏引擎可接入 agent 工作流。
- ADPList 发布 MCP 服务器，可在 Claude 内直接预约真人导师。
- Google Stitch 案例：设计公司 24 小时内交付可交互原型。
- Lenny 公布播客嘉宾阵容，涵盖 Jeff Dean、Codex 负责人、Claude Code 负责人等关键人物。
