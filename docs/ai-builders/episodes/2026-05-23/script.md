Riley Brown 昨晚发了一段 15 分钟的视频，演示了一个堪称疯狂的流程。
你在 iMessage 里给 agent 发一张截图，或者一段文字描述。
agent 直接生成一个原生的 Swift 应用。
然后你把应用下载到手机主屏幕上，像普通 App 一样打开使用。
他甚至一次生成了 8 个应用，组成了一个“个人应用商店”。

这件事之所以值得认真看，不在于它现在有多完美。
而在于它把“AI 构建原生移动应用”这件事，从 playground 推到了真实设备上。
Riley 说这个能力不限于某个特定 agent。
Codex、Claude Code、Hermes、Cursor、Replit，任何一个 agent 都能用。
他把对应的 skill 和 CLI 包都开源了。

这个演示背后有一个更深的信号。
三个月前，苹果刚刚禁止了“vibecoding”类应用上架 App Store。
而现在，开发者绕过了审核，直接把应用装到了用户手机上。
Riley 的原话是：“App Store 死了。”
这话当然有夸张成分，但它指出了一个事实：分发渠道正在从中心化商店，变成 agent 到用户的直接管道。

同一时间，Aaron Levie 对 AI 成本问题做了一段非常重要的分析。
事情的起因是微软本周取消了内部的 Claude Code 许可证。
原因很直接：token 计费让成本变得不可接受。
Uber 的 CTO 也发了一份内部备忘录，说公司在四个月内花光了 2026 年全年的 AI 预算。
美国 AI 软件价格在过去一段时间上涨了 20% 到 37%。

Aaron 说，问题的根源在于我们从一个世界跳到了另一个世界。
以前是 AI 聊天工具，上下文窗口小，成本相对便宜。
现在是 AI agent，上下文窗口巨大，能追踪长时间运行的任务，推理成本高了一个数量级。
这个转变的速度，比大多数人意识到的要快得多。

他画出了接下来的路线图。
前沿用例，比如编程、科研、金融、咨询，会继续用最贵的模型。
而其他任务会逐渐剥离到成本更低、能力够用的模型上。
AI 的成本不会收敛到单一的低价，反而会按任务类型出现明显的分层。
企业需要建立新的财务团队和技术方案来管理这一切。
那些能帮客户做成本优化的平台，会处于最有利的位置。

Justine Moore 昨天发了一篇长文，讲 AI 创业公司怎么跟创作者合作。
她在 Google I/O 期间跟几十位头部创作者聊过，总结了五条经验。
第一条就很有意思：创作者正在取代传统媒体，成为产品发布的主要分发渠道。
去年 Google 请了大约 25 位创作者和几百家媒体。
今年基本反过来了，几百位创作者，传统媒体很少。
原因是创作者能带来更多的曝光和转化。

第二条，Instagram 在 AI 分发上被严重低估了。
几乎所有创作者都在重仓 Instagram，有些人甚至把 AI 内容优先发在那里。
原因是变现好、受众广、负面情绪比别的平台少。
Justine 说，AI 创业公司应该比现在更认真地对待 Instagram。

第三条和第四条讲的是怎么跟创作者沟通。
创作者被千篇一律的 AI 创业公司 pitch 淹没了。
大多数 outreach 把创作者当成一个分发槽位，而不是一个需要理解产品差异化的人。
技术类创作者尤其反感代理机构的套话，他们想直接从创始人或工程师那里听到产品到底能做什么。

第五条是关于创作者指标。
播放量和评论数可以很好看，但实际转化可能很低。
Justine 列了几个在付费之前应该跟创作者要的指标：美国加拿大观众占比、平均观看时长、链接点击量、受众画像、过往真实转化案例。

Logan Kilpatrick 昨天连续发了几条关于 Gemini 3.5 Flash 的数据。
在多模态理解基准测试上，Flash 已经超过了上一代的 Pro 模型。
同时推理速度快了大约 6 倍。
另一个叫 GDPval 的评测也显示，Flash 正在逼近前沿模型的能力边界。
Logan 还宣布 Antigravity 的配额再次翻了三倍，这次是周配额。
他说希望开发者在构建时能一直保持心流状态，不要被限额打断。

今天值得展开聊的，是这件事。

Aaron Levie 那条关于 AI 成本的分析，和 Riley Brown 那个从 iMessage 构建 iOS 应用的演示，放在一起看，能看到一条正在成型的逻辑线。

Aaron 说，AI 的成本不会降到单一的低价，反而会按任务分层。
前沿任务用贵模型，普通任务用便宜模型。
这个分层不只是技术问题，它会变成企业财务结构的一部分。

Riley 的演示则展示了另一面。
当 agent 能直接从聊天界面生成原生应用，并且绕过商店直接分发。
“构建一个应用”这件事的成本，正在从“一个团队几个月”变成“一条 prompt 几分钟”。
这个成本下降的幅度，比 token 价格上涨的幅度大得多。

把这两件事放在一起，结论不是“AI 变贵了”或者“AI 变便宜了”。
而是成本结构在被彻底打散重组。
一部分东西，比如前沿推理，在变贵。
另一部分东西，比如应用构建和分发，在变得几乎免费。

Hamel Husain 昨天转发了一篇关于 agent 做定性分析的实验文章，提供了一个佐证角度。
文章的作者 Shreya Shankar 做了几个实验，让 agent 辅助做推文定性分析。
结论是：所有实验都挺失败的。
agent 容易太快收敛到浅层解读，很难适应多轮对话中逐渐浮现的偏好。
Hamel 的评论是，这个行业在评估工具上还处于非常早期的阶段。

这跟成本分层是同一个问题。
有些任务 agent 能做得极好，成本极低。
另一些任务，尤其是需要主观判断、多轮校准的工作，agent 目前还做不好。
而做不好的那部分，反而会消耗大量 token，变成成本黑洞。

Aaron 的预测是，企业需要专门的团队和工具来管理这种分层。
Hamel 和 Shreya 的发现则说明，那套管理工具本身还没被造出来。
对于正在做 AI 产品的听众来说，有一个很直接的对照问题。
你现在用 agent 做的那些任务，哪些是真的省了成本，哪些只是把成本从人力转移到了 token 账单上？
如果你的答案是“不确定”，那可能值得花一个下午，把 token 消耗按任务类型拆开看一眼。
