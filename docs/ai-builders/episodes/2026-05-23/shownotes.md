## 今日摘要
Riley Brown 演示了从 iMessage 直接生成原生 iOS 应用并下载到主屏幕的完整流程，引发了对 App Store 分发模式的讨论。Aaron Levie 深入分析了 AI 成本从聊天工具到 agent 的剧变，指出微软取消内部 Claude Code 许可证背后的结构性原因。Justine Moore 分享了 AI 创业公司与创作者合作的五条实战经验。Logan Kilpatrick 公布了 Gemini 3.5 Flash 的最新性能数据。

## 重点话题
- **iOS 应用构建革命**：Riley Brown 展示了从 iMessage 用 agent 生成原生 Swift 应用并绕过 App Store 分发的完整流程，三个月前苹果刚禁止 vibecoding 类应用上架
- **AI 成本结构剧变**：Aaron Levie 分析微软砍掉 Claude Code 内部许可证事件，指出 agent 时代推理成本比聊天工具高一个数量级，成本将按任务类型分层而非收敛到单一低价
- **创作者分发实战手册**：Justine Moore 在 Google I/O 后总结五条经验，包括创作者正在取代传统媒体、Instagram 被严重低估、技术创作者需要直接跟产品团队沟通
