## 今日摘要
Anthropic 紧急启动 Project Glasswing，用最强漏洞挖掘模型 Mythos Preview 加固关键软件安全，该模型暂不对外公开。同时 Anthropic 被曝 ARR 已飙升至 300 亿美元，一个月暴增 110 亿美元。此外，OpenAI 发布学术论文审阅工具 Paper Review，独立开发者推出超百种语言的 AI 实时电话翻译网络 tuwa，Box CEO 展示了长链路 agent 独立处理 RFP 的全过程。深聊部分围绕 Anthropic 的增长方法论展开，探讨“成功灾难”、内部自动化工具及增长飞轮。

## 重点话题
- Project Glasswing 与 Mythos Preview：Anthropic 选择将具备恐怖漏洞挖掘能力的新模型仅开放给网络防御者，以防止其被恶意利用。
- Anthropic 增长奇迹：ARR 在一个月内从 190 亿美元飙升至 300 亿美元，Lenny Rachitsky 深度对话其增长负责人，揭示其利用 AI 驱动增长的内部机制。
- OpenAI Prism 论文审阅：新功能 Paper Review 可对学术论文进行数学推导、结构一致性等严谨技术审查，并直接生成可编辑的 LaTeX 文件。
- tuwa 电话网络：一个支持 100 多种语言实时翻译的 AI 电话服务，允许 agent 自主拨打电话，打通物理通信边界。
- Box 长线 Agent 实践：Box CEO 演示了 agent 如何独立使用工具链处理耗时数小时的复杂知识工作，指出模型能力的跃升使之成为可能。
