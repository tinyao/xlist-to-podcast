Claude 又把 Fable 5 的体验期延长了一周，这背后是什么样的竞争压力？Sam Altman 公开悬赏征集 GPT 5.6 Sol 的最佳作品，他想看到什么？当 AI 广告在戛纳拿下传统类别的银狮奖，创意行业的规则是不是真的被改写了？先从最让开发者兴奋的那件事开始。

Claude Fable 5 的限时体验被再次延长，一直到 7 月 19 日。同时，Claude Code 每周的速率限制也保持提高 50% 不变。这个消息昨天由 Claude 官方账号发布，随后 Anthropic 的产品经理 Robert Bye 和工程师 cat 都转发了，希望大家继续玩起来。

坦白说，这个节奏挺有意思的。Fable 5 作为 Anthropic 目前最强的模型，原本的限时开放已经延长过一次。现在再延一周，圈子里普遍觉得，这既是给开发者的福利，也反映出前沿模型竞争的激烈程度。毕竟 OpenAI 那边刚把 Codex 和 ChatGPT 合并，推出了 GPT 5.6 Sol，而且 Sam Altman 正在悬赏征集作品。Anthropic 这边显然不想让开发者的注意力被完全吸走。

教育博主 Riley Brown 甚至调侃说，Claude 应该每周都这么搞一次，纯赚印象分。而另一位科技博主 Peter Yang 直接喊话，问能不能干脆永久延长算了。

不过，另一边的 Sam Altman 动作也很快。他昨天在 X 上发了一条公开悬赏，说想看看大家用 5.6 Sol 做出了什么有意思的东西。他会给做得最酷的那个人送一份 OpenAI 档案室里的特别礼物。

这不是简单的社区互动。往前翻几天，OpenAI 刚刚完成了 ChatGPT 和 Codex 的合并，把最强的编码能力和对话体验整合到了一起。Sam 现在要的不是 benchmark 跑分，而是真实的、有创造力的使用案例。他想看到模型在真实用户手里能催生出什么意想不到的东西。如果你这几天就在用 5.6 Sol 折腾项目，这确实是一个值得冲一下的机会。

说到模型能力，Google 的 Logan Kilpatrick 昨天发了一条观察，在圈子里传了一夜。他说，他很惊讶有那么多人似乎不理解，真正好的模型是用极高质量的、精心筛选过的数据训练出来的。找到创造这种数据的新方法，是一个巨大的竞争优势。

Logan 现在是 Google 的成员，负责 Gemini 和 AI Studio。他这条推文没有指向任何具体产品，但在这个时间点，它像是一个含蓄的提醒。当各家模型在架构和算力上的差距逐渐缩小，数据质量和数据获取的独特性，正在成为更深的护城河。这对创业公司来说尤其关键——你手里有没有别人拿不到的高质量数据？这可能是比模型选择本身更值得花时间的问题。

另一件值得说的事，发生在企业级 AI 的讨论里。Vercel 的 CEO Guillermo Rauch 昨天转发 Satya Nadella 的内容时，写下了一句很重的话：让模型成为你拥有的机器里的一个齿轮。

他列了一个清晰的堆栈：AI SDK 对应开放的模型 API，Eve.dev 对应开放的 Agent API，AI Gateway 对应开放的零数据驻留推理。他的核心观点是，创业公司和大型企业都必须拥有自己的数据、评估体系、模型选择和软件层。原话是——不要外包你的大脑。

Box 的 CEO Aaron Levie 几乎在同一时间发表了呼应。他说，21 世纪商业的关键架构问题之一，是如何在 AI 模型里封装了如此多智能的世界里，最大化你自己的企业 IP。这包括决策、洞察、工作流模式和最佳实践。Levie 进一步指出，正因为任何公司都能接触到前沿智能，如何独特地利用它才成为真正的分水岭。他特别强调了评估体系、模型路由和可追溯的工作流痕迹——这些东西会让你的信息价值随着 AI 进步而复合增长。

这两条放在一起看，信号很清楚。模型本身在商品化，但围绕模型构建的企业专属工作流、评估和数据飞轮，才是下一个战场。

接下来这段我们多说几句。

过去一天里，一个老话题被几条重磅推文重新点燃了：AI 到底是在消灭工作，还是在创造更多工作？而且这次的讨论，出现了一些反直觉的数据。

起因是 swyx 在引用 Sam Altman 之前的一条推文。Sam 当时说，到目前为止，他相当确定 AI 是净创造了工作岗位，这个结果连他自己都没想到。swyx 接着展开了他的观点，他认为很多人对杰文斯悖论的理解还停留在软件需求层面，没有完全内化它在 agent 工程时代的冲击。

他的逻辑是这样的：当编码 agent 被善用它们的人类掌握，并且这些 agent 开始突破编程的边界，进入所有知识工作时，整个知识工作的单位成本都在下降。结果是，对总工作量和更好知识的需求反而上升了。他有一句很 swyx 式的总结：编程领域发生的不是例外，是前兆。

Aaron Levie 用更具体的数字做了佐证。他引用 Marc Andreessen 的观点指出，软件行业的职位发布数量正在超过其他领域。原因很简单：软件的单位生产成本大幅降低，人们想要更多的软件，于是启动了比以前更多的软件项目。但这份工作本身并没有被完全自动化，而且在可预见的未来也不会。你仍然需要人来维护代码、决定建什么、长期运营和更新系统。Levie 的结论是，agent 带来的更多是丰裕，而不是替代。

这些话听起来可能有点反直觉，毕竟我们每天都能看到某个工作流被自动化掉的例子。但他们的核心论证值得认真对待：降低生产成本在工业时代反复导致需求激增，现在这个规律终于开始在知识工作领域显现了。

对听众来说，这里有一个可以对照的启发。如果你的日常工作只是执行明确的、可被标准化的任务，危险确实在靠近。但如果你的工作变成了——决定该建什么、如何组合 agent、如何评估产出质量、如何把多个 agent 的流程串成业务闭环——那你实际上正在进入一个需求快速膨胀的地带。Levie 提到的评估体系、模型路由和痕迹捕获，这些都不是模型自己能做的事，是需要人来设计的。

换个角度想想，你最近有没有感受到这种“活变多了，但类型变了”的拉扯？

再说几条快讯。

戛纳广告节今年的结果让创意行业震了一下。两部完全用 Kling AI 制作的广告片，在传统电影类目里拿了奖，而不是 AI 专属类目。一部是 The RealReal 的愚人节广告，拿了电影类银奖和电影工艺铜奖。另一部是 GUT 和 Purga Studio 做的 Lorem Ipsum，拿了电影类铜奖。这意味着它们是在和传统拍摄的作品同台竞技后胜出的。AI 视频工具在专业创意领域，已经跨过了一个重要的认可门槛。

Cognition 的 Builder in Residence Jared Zoneraich 在 Peter Yang 的播客里分享了一个数据点：现在更多的 Devin 会话是由其他 Devin 启动的，而不是直接来自人类。他同时提出了一个激进预测，认为鼠标和键盘是过时的，未来桌面上只需要一个按钮和一个语音输入工具。这个访谈的完整版值得去看一下。

Zara Zhang，一位独立开发者，分享了一个挺实用的工作流：把会议录音直接丢给 Codex，当作产品需求文档来用。她说，会议本身就是 prompt，Codex 会按照讨论的内容直接构建原型。这个方法对于快速把讨论变成可测试的 MVP 特别有效。

Replit 的 CEO Amjad Masad 在做一个他称为 Vibe Research 的实验。他在 Replit 上微调一个 Qwen-8b 模型来下棋，同时跑三条并行实验分支。他说，模型做机器学习的能力比以前强太多了，现在一个有良好直觉的人，即使从没做过 ML，也能引导出有趣的成果。如果你一直想做点 ML 实验但被门槛劝退，现在可能是时候再试试了。

最后，Lenny 昨天发布了他和 Noam Segal 关于科技从业者情绪调查的深度访谈。一个值得注意的发现是，科技圈最大的恐惧不是被 AI 取代，而是“做更多的活，拿一样的钱”的挤压感。职业倦怠指数一年跳升了 11 个点。如果你正在经历这种“微笑疲惫”，这期播客可能会让你觉得被看见了。
