Paul Conyngham 用 ChatGPT 和 AlphaFold 为爱犬 Rosie 设计了个性化 mRNA 癌症疫苗，Sam Altman 亲自分享并说"这应该成为一家公司"，是昨日互动量最高的故事。Guillermo Rauch 的一条推文引发热议：在 agent 时代 CLI 正回归中心地位。Zara Zhang 描述了 AI 诱发的注意力碎片化问题，并总结出一句精准的话："瓶颈不是 AI 的上下文窗口，是人的。" OpenAI Codex 开放 plugins 接入企业工具链，Stripe 进入 agent 基础设施领域，Gemini 推出跨平台记忆迁移功能。

- **Codex 接企业工具链**：OpenAI Codex 上线 plugins 支持，接入 Slack/Figma/Notion/Gmail/Box，Aaron Levie 演示了企业内容 + 编码 agent 的知识工作自动化场景
