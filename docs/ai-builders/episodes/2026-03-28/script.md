2026 年 3 月 28 日，AI Builders Daily。今天的故事从一只叫 Rosie 的狗开始，然后是 CLI 的一次复辟，以及一句话你今天可能就需要想一想。

---

先把这个故事说完整，因为它值得。

Paul Conyngham 的狗 Rosie 得了癌症。他本人没有医学学位，没有实验室，没有科研机构支持，没有任何传统意义上做这件事需要的资源。他有的是 ChatGPT、AlphaFold，以及一种不愿意接受"没有办法"的态度。

接下来他做的事，正常情况下需要一个完整的生物医学研究团队才能完成：他用 ChatGPT 系统梳理文献，做治疗方案规划，分析合规要求，再把 Rosie 的基因组数据转化成 mRNA 疫苗方案，最后设计围绕这个方案的完整治疗协议。

Paul 自己的话值得完整引用一遍："聊天机器人让我以一个个体的身份，拥有了一个研究机构的能力——规划、教育、答疑、合规，以及真正的科学设计工作，包括把基因组数据转化成疫苗处方。但它们在每一步都配合着人类专家一起工作。正是这种结合让它变成可能。"

人机结合，不是人被替换，也不是 AI 单独完成。这个描述精准定义了目前 AI 辅助科学最真实的状态。

Sam Altman 昨天分享了和 Paul 的会面，发完立刻说："这应该成为一家公司。" OpenAI 的 Kevin Weil 跟着转发，说这是一个窥见未来的时刻——AI 加速个性化医疗，我们需要让更多人能做到这件事，不只是对狗，还要对人。

这条推文的互动量在昨天所有内容里遥遥领先，四千六百多个点赞，超过一千六百个书签。受关注不是因为有什么新的技术论文或产品发布——是因为它太具体、太真实了，而且结果是真的。

我们聊过不少 AI 辅助科学：大模型在学术推理上的评分，AlphaFold 的结构预测，月初 Anthropic 博客上那位哈佛物理学家说 Claude 把他的研究速度提高了十倍。这些信息都是真的，但有点抽象。Paul 和 Rosie 的故事质感完全不同：一个人，一只狗，一个真实的紧迫问题，手边有什么用什么。不需要想象力，它就在这里。

同一天，Sam 还发了密歇根 Stargate 数据中心工地的施工视频，第一批钢梁已经竖起来了，跟 Oracle 和 Related Digital 一起建的。基础设施在加速，应用也在加速——只是叙事的温度完全不一样。一个冰冷的钢梁，一只叫 Rosie 的狗，都在同一天。

---

然后我们聊一件反差鲜明的事，关于界面。

Guillermo Rauch 昨天发了一条推文，两千五百多个点赞，将近两百人转发：

"1961: We should ship a CLI / 2026: We should ship a CLI"

配的是两张截图——1961 年的计算机操作界面，和某个 2026 年的 terminal 界面，长得几乎一模一样。

Zara Zhang 接住了这个球，补了六个字："CLI → GUI → CLI。" 计算机历史浓缩版。

这不是情怀，是工程逻辑。GUI 是为鼠标和手指设计的，是人机协作的产物。CLI 是为程序设计的——可组合、可脚本化、结构清晰，没有多余的视觉层。当 agent 开始大量使用软件，程序最好用的接口恰好就是程序原生的接口。Vercel 官方在重新投入资源打磨 CLI，Claude Code 本身就是 terminal 原生产品。当软件的主要用户从人变成 agent，软件的界面设计逻辑就得跟着变。

但在 CLI 回归的同时，Zara 这两天也在经历另一面。

她昨天发的那条帖子，快速涨到一百五十多个收藏，将近两百条回复：

"我现在最大的单点问题：AI 诱发的注意力缺陷。同时跑五个 Claude Code 会话，十个终端 tab，五十个浏览器 tab，书签里一百篇没读的文章。多个 AI 给你干活，你在任务之间不停切换；等 AI 输出的时候，你忍不住去刷别的；因为以前很难的事现在太容易了，你总想做更多更多更多。把这些加起来，你活在一种持续的分心和混乱里，专注和深度工作比以前难多了。有人解决了这个问题吗，教教我。"

评论区没有特别好的答案。她自己在跟帖里给出了最好的总结："Turns out the bottleneck is the human's context window, not the AI's。"

这句话说出了一件我们还没认真讨论过的事。我们花很多时间在谈 AI 的上下文窗口有多大、并行处理能力有多强。但在这些工具中间工作的人，注意力带宽是固定的。agent 越多，信息来源越多，可能反而让人更忙、更焦虑，更难保持深度专注。

swyx 昨天分享了一个相对务实的反例。他换了台新 Mac，把旧机器传给孩子，然后把自己过去四年写的 MacBook 配置博客全部丢给 Claude，让它把所有技术栈偏好一次性转成 bash 脚本——自己走开，在手机上偶尔检查进度。他说：有多年积累的文档可以直接喂给 AI，这是平时坚持写东西的人最大的意外红利之一。

这是一种把人的注意力消耗降到最低的策略——清晰委托、批量执行、偶尔确认。和 Zara 描述的那种五个会话同时开、持续在切换的状态相比，是两种截然不同的 agent 使用姿势。

工具层面也有几件事值得一起讲。

Greg Isenberg 昨天发了一条被广泛截图流传的话："创建一家公司的边际成本正在趋近于零。当创建一件事的成本趋近于零，被创建出来的东西数量就趋近于无穷大。这只是数学。接下来十年，我们将看到前所未有的公司数量爆炸。"

逻辑没问题。但值得多想一步的是：公司数量爆炸，不等于好公司变多了。当"创建"本身不再是门槛，真正稀缺的是选择做什么，以及让人持续留下来的能力。筛选的问题变得更尖锐，不是更简单。

OpenAI 昨天宣布 Codex 开放 plugins 支持，现在可以直接接 Slack、Figma、Notion、Gmail、Box 等主流企业工具。Box 的 CEO Aaron Levie 第一时间发了 demo：把企业内容库里的财报电话录音喂给 Codex，提取结构化数据，再管道输出到其他系统。他的判断是：coding agent 会成为知识工作自动化的骨干，企业内容是提供上下文的关键原料，这在金融、法律、医疗等任何内容密集型行业都成立。

这是 Codex 从开发者工具向企业工作流延伸的明确动作。上周 Figma 开放了 MCP，现在 Codex 又直接接了 Figma plugin，两边都在往中间走。

然后是一条挺直接的话，来自 Vibecode 的联合创始人 Riley Brown："我实在想不到有什么理由用 Cursor 而不用 Claude Code，它就是能力差一些。" 评论区热了很久，有人赞同，有人说响应速度和界面体验不一样，有人说各有适用场景。不是下定论的时候，但一个 coding 平台创始人愿意公开说这句话，说明 Claude Code 对现有工具格局的冲击已经到了需要认真对待的程度。

几条快讯。

Gemini 上线了从其他聊天机器人导入记忆和对话记录的功能。进设置找 "Import memory to Gemini"，可以把在 ChatGPT 或 Claude 里积累的个人上下文一键搬过来。Google 的逻辑很清楚：如果你积累的 AI 记忆越来越多，迁移成本就越来越高，他们主动把这个摩擦消掉。

Stripe 进入 agent 基础设施领域，推出了面向 agent 自部署的支付和结算方案，域名叫 projects.dev。agent 开始有了自己独立的支付能力，这条基础设施的线值得持续跟进。

还有一条是传言：有信源称 Anthropic 正在内部测试代号 "Mythos" 的新模型，属于叫做 "Capybara" 的系列，据说在编码、推理和网络安全方向有大幅提升，体量比 Opus 更大，目前尚未准备好公开发布。Anthropic 没有官方确认，但如果消息属实，下一轮模型竞争的入场券已经在准备了。

Justine Moore 接受了《华尔街日报》的采访，聊 AI 原生内容的崛起。她提到一个叫 "Fruit Love Island" 的 AI 生成真人秀是目前增长最快的节目之一，然后她很坦率地说：真人秀本来就多半是垃圾，不管是拍的还是 AI 生成的，但人们就是爱看。这个判断比大多数关于 AI 内容的预测都要诚实。

Lenny 在他持续更新的就业市场系列里加了一个新数据点：科技行业的招聘岗位需求几乎回到了 2022 年的峰值水平，而招聘人员自身的招聘量通常是整体热度的领先指标。方向是在回暖，不是在收缩。

---

今天这几件事，看起来分散：一只狗的 mRNA 疫苗，CLI 的复辟，Zara 的注意力碎片，Codex 的企业野心，Stripe 进场搭基础设施。

但有一条线可以把它们串起来：能力已经不是最难的部分了。

Paul 有了给 Rosie 设计疫苗方案的能力。Zara 有了同时运行五个 AI 会话的能力。CLI 在 1961 年就有了，agent 把它带回中心。工具越来越多，能力越来越触手可及。

但瓶颈正在转移。不是模型的上下文窗口，是人的注意力。不是技术能不能做，是你能不能从无穷多个可以做的事里，选出真正值得做的那几件。

Zara 那句话可能是今天最值得带走的：瓶颈不是 AI 的上下文窗口，是你的。

觉得有收获，分享给一个你觉得需要的人。下期见。
