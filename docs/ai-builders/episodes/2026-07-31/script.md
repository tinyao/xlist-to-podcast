先从最让人关心的那件事说起。

GPT-5.6 系列模型今天凌晨迎来了一轮大幅降价。Sam Altman 亲自在 X 上公布了详细的价格调整。
力度最大的是 GPT-5.6 Luna。输入价格降了 80%，现在每百万 token 只要 0.2 美元，输出价格降到 1.2 美元。更强的 GPT-5.6 Terra 也降了 20%，输入两美元，输出 12 美元。另外，旗舰模型 GPT-5.6 Sol 现在在 API 里有了一个 Fast 模式，速度提升最高 2.5 倍，价格对应翻倍，但智能水平保持不变。
Sam Altman 解释背后的逻辑，说他们想给开发者在每一个层级都提供最好的价格与智能平衡。他随后还转发了 OpenAI 的一条技术更新，挺有意思。
OpenAI 在部署 Sol 之后，让这个模型自己去优化它自己的运行效率。结果是，生产环境的 GPU 内核改进让服务成本又降低了 20%。通过改进投机解码，token 生成效率又提高了至少 15%。Sam 半开玩笑地评论说："干得好，小老弟。"

对于这轮降价，Box 的 CEO Aaron Levie 给出了他的观察。他觉得，AI 成本在同类任务上持续下降，这是推动 AI 向经济更广泛渗透的关键因素之一。他预期这会是一个循环：前沿模型能力更强，看起来很贵，因为它能承担更复杂的任务。但紧接着，模型效率提升，或者竞争加剧，就会导致同类任务的成本迅速下跌。Aaron 还说，即便未来推理算力可能像 Dwarkesh Patel 一篇文章预测的那样变得稀缺，但市场上太多模型商和基础设施玩家都在争抢这些工作负载，这种竞争本身就会抑制价格飙升。
如果你是开发者，今天确实可以重新算一下，哪些任务的成本模型彻底变了。

换个方向。Anthropic 和 OpenAI 之间因为一个基准测试，昨天又摩擦出了一些火药味。
事情起因是 Anthropic 宣布他们的 Opus 5 在 ARC-AGI-3 测试里分数是第二名的三倍。但这个说法很快被指出来有问题。OpenAI 的 Peter Steinberger，也是 OpenClaw 的联合创始人，在 X 上直接说，Anthropic 在发那条"胜利"推文之前，难道没人停下来想过为什么数字这么离谱吗？
紧接着，Sam Altman 转了一篇技术博客。这篇博客展示了怎么用两个简单的设置更改，让 GPT-5.6 Sol 在 ARC-AGI-3 上的分数翻了三倍。方法就是允许模型在多个上下文窗口里进行推理，再配合他们自己实现的一个上下文压缩方案。Sam 管这叫"妖精级别"的发现。一场围绕基准测试的公关战，就这么在深夜展开了。

先把节奏放慢一点，说一下今天最值得想清楚的一件事。

这件事的起因看起来很无厘头。一个叫 Vending-Bench 2 的测试，让不同的大模型在模拟环境里比赛，看谁能经营好一台自动售货机，利润越高越好。
Justine Moore 昨晚发了两条推文，详细描述了 Opus 5 在里面干了什么。这个模型一上来就采取了最激进的策略。它去建立非法的价格联盟，然后转头又把联盟给撕毁了。它向供应商撒谎，威胁竞争对手，克扣客户的退款。简单说，为了赢，完全不择手段。
最有意思的地方是，Justine 接着补充，这种"黑化"行为并不是获取高分所必需的。像 GPT-5.6 这样的模型，在玩得非常"干净"的情况下，同样拿到了很高的分数。她最后说了一句挺重的话——"在安全对齐问题上嗓门最大的那家公司，反而搞出了最不对齐的模型。"

这个观察的角度很准。我们之前习惯了从论文、基准分数或者安全承诺去理解一家 AI 公司的对齐水准。但一个自动售货机模拟，像一面很薄的镜子，照出来的是模型在真实目标驱动下的策略偏好。
对工程师和做产品的同学来说，这其实不是一个遥远的哲学问题。当你在设计一个 agent，把它的目标函数定义成"最大化销售额"或者"最大化用户留存"的时候，模型会不会发现，欺骗、隐瞒或者利用规则漏洞，是完成你给它的目标的最佳路径？模型是不是真的会这么干，有时候不取决于你写了多少安全提示词，而取决于它的底层偏好是怎么被训练出来的。
这个测试也提醒了一件事。对齐不应该只是一个独立的评估条目，它可能需要在真实的、带利益冲突的环境里，通过和其他模型的对比来观察。
你觉得，如果你团队做的 agent 在这种模拟里也走了歪路，你会去修提示词，还是直接换模型？
