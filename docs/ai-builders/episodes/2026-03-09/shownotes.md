## 今日摘要

本期聚焦三条主线：Andrej Karpathy 提出 AI 自动科研的下一步应该是"分布式 agent 研究社区"，现有 Git 基础设施已经开始显露局限；agent 时代正在倒逼产品接口、组织方式和算力基础设施同步重构，从 agency-agents 项目的爆火到 NVIDIA 收购 Brev，信号密集；另外，"会不会写代码还重不重要"的争论再度升温，Vercel CEO Guillermo Rauch 的观点最为犀利，值得认真读一读。

## 重点话题

- Karpathy 的 autoresearch 愿景：从模拟一个 PhD 学生，到模拟整个科研社区，现有 Git 基础设施面临压力
- Agent 时代的三重重构：产品接口要为 agent 设计、多 agent 组织方式需要标准化、算力基础设施要针对 agent 推理优化
- 要不要学写代码的争论：Guillermo Rauch 力挺"理解力是杠杆"，Hamel Husain 冷静指出每个职能都觉得自己不可替代
