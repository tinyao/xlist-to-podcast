OpenAI 确认 Noam Shazeer 正式加入。Sam Altman 在 X 上连发两条推文欢迎，他说等这一天等了十年。Noam Shazeer 此前在谷歌领导 Gemini 项目，是 Transformer 架构的核心作者之一。谷歌为了把他留在团队里，两年前据说花了 27 亿美元。因此他的离职被视为谷歌在人才争夺战上的又一次重大损失。OpenAI 研究员 Noam Brown 也发推说，OpenAI 的 Noam 人数又增加了。Sam Altman 引用他的话说，OpenAI 不解释为什么叫 Noam 的人都擅长 AI，他们把一切归因于神恩。

Claude Code 上线 Artifacts 功能。现在你可以把终端里的一次分析、一段架构图，甚至一个交互页面，变成一个可分享的私有链接，直接发给团队成员看。Anthropic 的 Boris Cherny 说他已经在用它做系统图、数据看板和动画预览。另一位团队成员 cat 说，他们内部已经把这个功能用成了沟通新架构和数据分析的默认格式。目前这个功能在 Team 和 Enterprise 方案里开放测试。Pro 和 Max 用户还要稍等。

另一边，Linear 也发了一个值得注意的更新——agent 辅助写项目周报。他们的产品负责人 Nan Yu 分享了一个细节。团队一开始想让 agent 一键生成周报，结果发现效果很差，因为用户会直接把脑子关掉，产出的东西全是水。后来他们改了交互模式，改成多轮对话，agent 会反过来问你要强调什么、缺什么上下文。Nan Yu 说这是一个典型的例子，证明有时候增加一点摩擦反而能带来更好的结果。

说到 agent 的操作边界。另一款名为 Cua 的工具把它在 Linux 下的驱动能力开放了出来。现在不论是 Claude Code 还是 Codex，都可以通过 MCP 协议在真实的 Linux 桌面应用里操作鼠标和键盘，而你的桌面仍然可以正常使用。退休后一直在环游世界的早期创业者郭宇评论说，再加一层 Kasm，你就能看到 agent 怎么自动操作服务器上的虚拟机了。这种把 agent 放到真实桌面环境里跑的做法，对于需要跨多款企业软件才能完成任务的场景来说，确实是一个挺值得关注的进展。

今天值得展开聊的，是这件事。
Midjourney 昨晚正式宣布成立独立部门 Midjourney Medical，要做全身体扫描。现场参加发布会的 swyx 发了一篇详细笔记，里面有几个信息点很硬核。
第一，他把这个发布比作当年 iPhone 和特斯拉发布。第二，他提到 Midjourney 目前的年度研究预算只有大约一千万美元，但在扫描仪这个产品上，他们追求的不是好 10% 或好两倍，而是在每一个维度上都好 40 到 100 倍。
另外几个细节也很有意思。swyx 说 Midjourney 今年还有另外 7 个 side project 要发布。这次医疗扫描只是第一个。a16z 合伙人 Justine Moore 直接转发说太酷了，她要成为一号病人。前 Facebook 产品设计副总裁 Julie Zhuo 也说，她喜欢这种野心——AI 让学习变快，想法的构建成本变低，小公司梦想进入更多领域变得可行。
不过，swyx 笔记里最后提了一个问题：为什么这种级别的创新和野心，来自一个年预算一千万美元的小团队，而不是那些手握巨额研发预算的大公司？他这问得挺直接。坦白说，这个问题没有标准答案。但如果你是创业者或产品经理，今天可能值得想想的是，当算力和模型持续趋近商品化时，你的护城河到底建立在什么地方。是模型本身，还是对某个垂直场景的不可替代的集成深度。

Lenny 转发了一条关于 Snap CEO Evan Spiegel 的深度访谈，里面一个核心观点是，AI 让写软件越来越容易，以后硬件可能是仅剩的持久护城河。而另一边，美股收盘后，关于 Snap 是否被低估的讨论也很激烈。一位叫 Greg Isenberg 的创业者发长文说，Snap 日活 4.74 亿用户，市值不到 80 亿美元，用户价值只有 Meta 的八分之一，他觉得这个资产可能被错配了。
最后提一个挺现实的用法。最近在分享 Codex 用法很活跃的 Peter Yang 自己也踩了一个坑。他让 Codex 跑了一个 /goal 任务，两小时后发现 agent 产生了很多错误假设，他得不停地盯着。他问是不是应该先让 agent 出一份详细计划。如果你也在用长任务模式的 agent，这个顺序可能真的挺关键。
