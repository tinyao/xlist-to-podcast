今天有三件事值得你认真听完：GPT-5.4 正式发布、Google Workspace CLI 引爆 Agent 工具链讨论，还有 Claude Code 在爆炸式增长下悄悄做的那些取舍。我们开始吧。


先说今天最大的新闻。

OpenAI 正式发布了 GPT-5.4，同时推出了 GPT-5.4 Thinking 和 GPT-5.4 Pro 两个版本，已经在 ChatGPT、API 和 Codex 上开始滚动上线。

OpenAI 科学副总裁 Kevin Weil 在推特上说，GPT-5.4 是他们有史以来能力最强的模型，尤其是 Pro 版本，在科学家和数学家的早期测试中表现"令人震惊"。

那实际用起来怎么样？我觉得比较有参考价值的是来自 Peter Steinberger 的评价。他现在在 OpenAI 工作，每天泡在这些工具里，他说：GPT-5.4 的编程能力提升幅度大概和当年 5.0 到 5.1 的跨度相当，但更重要的是，它现在是一个统一的模型，在文档写作、通用 Agent 任务、整体使用体验上都更好了，"更令人愉快"是他的原话。

Box 也做了一个比较扎实的测评，他们拿企业文档处理场景来跑，整体准确率从 GPT-5.2 的 72% 提升到了 78%，提升了 6 个百分点。拆开来看，政府统计报告这类结构复杂的文档提升最大，足足涨了 10 个点。Box CEO Aaron Levie 的评价是，模型进步"持续没有停歇"，这 6 个点的提升对于自动化工作流来说是上游的关键改进。

说到这里，我想稍微展开一下我自己的观察。

GPT-5.4 的发布节奏其实挺有意思的。OpenAI 现在基本上是在用小版本号快速迭代，而不是等一个大版本一次性震撼市场。这种节奏对开发者来说意味着什么？意味着你的 Prompt、你的 Eval、你的产品体验，可能每隔几周就需要重新校准一次。

这不是坏事，但确实需要一种新的工程心态——不是"把模型当成固定基础设施"，而是"把模型当成一个还在成长的队友"。

另外值得注意的是，GPT-5.4 同时进入了 Codex，这个时间点很有意思，我们待会儿会讲到 Codex 的用户增长数据，放在一起看会更有感觉。


好，我们来聊今天第二个大话题：Google Workspace CLI 的发布，以及它背后更大的那个信号。

昨晚，Vercel CEO Guillermo Rauch 发了一条推文，迅速成为今天转发量最高的内容之一。他说：Google 发布了一个 Google Workspace 的命令行工具，支持 Drive、Gmail、Calendar、Sheets、Docs，用 Rust 写的，可以通过 npm 安装，还可以直接作为 Claude Code 的 Skill 接入使用。他最后加了一句："2026 是 Skills 和 CLI 的年份。"

这条推文的互动数据相当惊人，接近六千个点赞，四百多次转发，五千八百个书签。在科技推特上，书签数往往比点赞更能说明问题，因为书签意味着"我要回来用这个"。

为什么这件事这么重要？

我觉得 Aaron Levie 说了一句很关键的话，他说：Agent 将会是软件最大的用户群体。它们需要自己的计算机、自己的身份、自己的文件系统和工具。因此，软件会越来越走向 API 优先，既服务人类，也服务 Agent。

Google 这次发布的 Workspace CLI，正是这个趋势的一个具体体现。你可以让 Claude Code 直接帮你查明天的日程、把文件上传到 Drive、读取 Gmail 里的信息。这不是未来，这是现在已经可以做到的事情。

Peter Steinberger 的反应也很有意思。他自己之前做了一个叫 gog 的工具，专门用来在终端里操作 Google 服务，正是因为当时"没有好的现成选项"。现在 Google 官方出手了，他说他要跑一些 Eval 看看哪个对 Agent 更友好。这种开发者之间的良性竞争，其实挺健康的。

Claude Code 的 Anthropic 工程师 Thariq 也转发了这个工具，说做这个的团队"是英雄，是爱国者"，用词相当夸张，但也说明了一线开发者对这类工具的真实需求有多强烈。

Guillermo Rauch 还补充说，他仔细看了这个 CLI 的实现，评价非常高：动态注册命令、设计上考虑了让浏览器里的 Agent 自动完成配置步骤、还能启动 MCP 守护进程。他说，这是一个"为 AI Agent 重写 CLI"的典范。

说到这里，我想引申一个更大的问题：我们正在进入一个"工具层"重构的时代。

过去十年，我们把工具做得对人类友好——好看的界面、流畅的交互、精心设计的 UX。接下来的十年，我们需要把工具做得对 Agent 友好——清晰的 API、可组合的命令、机器可读的文档。这两件事不是互斥的，但优先级正在发生变化。Vercel 和 Stripe 的集成、Google Workspace CLI、各种 Skills 生态，都是这个方向上的早期信号。

如果你是一个开发者或者产品经理，现在是时候问自己一个问题：你的工具，Agent 能用吗？


我们来说第三个话题：Claude Code 的爆炸式增长，以及 Anthropic 在增长压力下做的那些取舍。

Anthropic 工程师 Thariq 这两天发了一个系列更新，说 Claude 和 Claude Code 这周的流量增长"是真的很难预测"，感谢大家的耐心。

然后他列出了一系列为了应对流量压力而做的调整：

第一，把 Effort 默认值改成了 medium。这是随 Opus 4.5 一起推出的新参数，让模型自己判断一个任务需要"想多努力"。数据显示，对大多数用户来说，medium 是延迟、智能和用量限制之间最好的平衡点。如果你觉得不够用，可以在 /model 里切换到 high，或者用 ultrathink 让它在单次对话里想得更深。

第二，暂时下线了 Opus 4、Opus 4.1 和 Sonnet 4.5 在 Claude Code 上的访问。原因是只有一小部分用户在用这些模型，但 Claude Code 的底层 harness 已经不再为它们优化，继续保留反而是在浪费容量。

第三，暂时关闭了 Prompt 建议功能。如果你想保留，可以设置一个环境变量手动开启。

这些调整放在一起，传递出一个很清晰的信号：Anthropic 在优先保障整体服务质量，而不是维持所有功能同时在线。这种取舍在快速增长期其实挺正常，但对于依赖特定模型版本的重度用户来说，确实会有摩擦。

说到增长，swyx 挖出了一个很有意思的数据点。他说今天 OpenAI 融资新闻里有一条被埋掉的信息：OpenAI Codex 的用户数增长非常猛。1月1日到现在，周活跃用户数翻了三倍多。2月4日 Sam Altman 说突破了一百万，2月27日就到了一百六十万，最新的数据是两百万以上，而且还在以每周25%的速度增长。

swyx 的评论是："+40万，两周，哈哈哈"。

这个增长曲线配合 GPT-5.4 进入 Codex，以及 Windows 版 App 的上线，很难说接下来会停在哪里。

我想在这里加一个观察：Claude Code 和 OpenAI Codex 同时在高速增长，说明 AI 编程工具这个市场还远没有饱和。两个产品都在抢用户，但增长来源不同——Codex 更多是消费端的增量用户，Claude Code 更多是工程师和开发者的专业使用。这两个市场会在某个地方交汇，但现在还没有。

这也是 swyx 说的那句话的背景：他说"现在既是 GPT wrapper 的夏天，也是 GPU wrapper 的夏天，这是产品人的代际机会"。我觉得这句话说得挺准的。模型能力在快速提升，工具链在快速成熟，现在入场做产品，时机窗口是真实存在的。


快讯时间，我们快速过几条今天值得知道的信息。

首先是 Cursor 发布了一个叫 Automations 的新功能，可以构建"永远在线"的 Agent，让 Agent 在你思考、休息、睡觉的时候继续工作。这个方向很多工具都在走，但 Cursor 作为目前最主流的 AI 编程工具之一，这个功能的落地值得关注。

另外，NotebookLM 新增了视频生成功能。a16z 的 Justine Moore 测试了一下，她让它做一个迪士尼乐园的历史介绍，NotebookLM 自动做了深度搜索、拉取了58个来源、写了脚本、生成了5分钟的视频，混合了真实素材和 AI 生成的画面。Google 的 Josh Woodward 也分享了一个罗马历史的视频，效果挺震撼的。NotebookLM 正在从"智能笔记本"进化成"内容生产工具"，这个转变值得持续关注。

顺带一提，Netflix 收购了 Ben Affleck 创办的 AI 工具初创公司 interpositive，这家公司的技术是用 AI 从拍摄素材里构建模型，辅助后期的调色、重新打光和特效处理，同时保持导演在创作中心。Justine Moore 对这件事的评价是：AI 不是在杀死好莱坞，而是在降低讲故事的门槛，让更多故事有机会被拍出来。

还有一条关于假模型 API 的研究，中文科技圈的陈成分享了一篇论文，研究人员审计了17个第三方 LLM 代理 API，发现近46%的端点指纹测试不通过——声称是 GPT-5 或 Gemini-2.5，后台偷偷换成了 GLM-4，医疗基准准确率从83%暴跌到37%。更麻烦的是，这些假 API 被引用进了187篇学术论文。郭宇评论说："原来中转便宜是这么个便宜法。"如果你在用第三方 API 转发服务，这个研究值得认真看一眼。

最后快速说一条，Vercel 和 Stripe 的集成正式 GA 了，现在可以直接在 v0 或者 Vercel CLI 里一行命令接入 Stripe 支付。Guillermo Rauch 的评论很有意思，他说："你现在可以直接让 Agent '帮我建一个月收入五万美元的创业公司，别出错'了。"这当然是个玩笑，但玩笑背后的意思是真实的：基础设施的集成门槛在快速降低。


好，今天就到这里。

今天最大的一个感受是：工具层正在发生一次安静但深刻的重构。GPT-5.4、Google Workspace CLI、Cursor Automations、Vercel Stripe 集成……这些单独看都是产品更新，但放在一起看，是整个 Agent 基础设施在快速成形。

如果你是在这个时代做产品或者写代码的人，现在是认真想清楚"我的工具 Agent 能用吗"这个问题的时候了。
