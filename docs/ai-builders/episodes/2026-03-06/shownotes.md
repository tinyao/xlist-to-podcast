## 今日摘要

2026年3月6日，AI 工具层迎来密集更新。OpenAI 正式发布 GPT-5.4，带来编程、推理和 Agent 能力的全面提升；Google 发布 Workspace CLI，引发 Agent 工具链的广泛讨论；Claude Code 面对爆炸式增长，悄悄做了一系列服务质量取舍。三件事放在一起，描绘出 Agent 基础设施正在快速成形的清晰轮廓。

## 重点话题

- GPT-5.4 正式发布：统一模型、编程能力提升、Box 测试文档处理准确率提升6个百分点，同步进入 Codex 与 API
- Google Workspace CLI：用 Rust 写的官方命令行工具，支持 Drive/Gmail/Calendar 等，可直接作为 Claude Code Skill 接入，标志着"为 Agent 重写工具层"时代来临
- Claude Code 增长与取舍：流量爆炸难以预测，Anthropic 下线部分模型版本、调整 Effort 默认值，同期 OpenAI Codex 周活用户突破200万，同比年初增长超3倍

## 快讯

- Cursor 发布 Automations 功能：支持构建"永远在线"的 Agent，让代码在你休息时继续跑
- NotebookLM 新增视频生成：自动搜索、写脚本、生成混合素材视频，正从笔记工具进化为内容生产平台
- Netflix 收购 Ben Affleck 的 AI 影视工具公司 interpositive：专注调色、打光、VFX 后期辅助
- 第三方 LLM 代理 API 假模型研究：17个服务中近46%指纹测试不通过，声称 GPT-5 实为 GLM-4，已被引用进187篇学术论文
- Vercel x Stripe 集成正式 GA：一行命令接入支付，Agent 商业化基础设施门槛持续降低
