## 今日摘要
本期节目聚焦了 Agent 安全基础设施的升级、Meta 以开源权重加入模型竞赛，以及 Cursor 人才负责人 Adam Ward 独家分享的顶尖团队搭建心法。此外，Claude 的文字水印机制正式上线，OpenAI 发布了为高阶网络安全任务优化的新模型。在快讯中，Replit CEO 推出了 Agent 间的公共情报网，Cloudflare 则开始允许对 AI Agent 收费。

## 重点话题
- Vercel 沙箱防火墙免费：因 OpenAI 零日漏洞事件，Vercel 将 Egress Firewall 向全量用户开放，强化 Agent 的网络边界隔离。
