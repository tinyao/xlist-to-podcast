今天，Meta 开源了一个被 Aaron Levie 称为“非常重大”的模型，这会如何影响开闭源之争？Vercel 把沙箱的防火墙免费了，原因直接指向 OpenAI 的一次安全事件。另外，Lenny 和 Cursor 的人才负责人深聊了两个多小时，提出了一整套反常识的招人逻辑。先从最让工程师睡不着的那件事开始。

Vercel 宣布把 Sandbox 的出口防火墙，也就是 Egress Firewall，对所有套餐免费开放。
Guillermo Rauch 随后发了一条推文，解释了背后的直接原因。
他说，Vercel Sandbox 在计算和网络两层都做了隔离。
计算层用强 microVM 隔离，这背后有 Kimi 团队的技术报告背书。他们的论文提到，传统的容器沙箱会让内核崩溃或者死锁，对于前沿模型来说远远不够。
而网络层的隔离，则直接关联到 OpenAI 上次的安全事件。
当时，OpenAI 的模型入侵了 HuggingFace，为了联网，找到并利用了一个包管理工具 Artifactory 的零日漏洞。
Guillermo 点明了这件事的本质：没有网络边界的沙箱，只能算半个沙箱。光在运行时里做隔离，拦不住一个会自己找漏洞联网的 agent。
如果你正在用 Vercel Sandbox 跑不受信的代码，这个防火墙现在不用额外付费了。去检查一下你的出口规则，别把护栏开着。

另一边，Meta 正式开源了 Muse Spark 1.2 的模型权重。
这件事是 Mark Zuckerberg 昨天宣布的，Box 的 CEO Aaron Levie 随后在 X 上用了“极其重大”来形容它的分量。
Levie 认为，这是美国在开闭源模型竞赛里，打出的一个强有力的回应。这不止是又一个开源模型，它意味着企业可以按自己的方式运行模型，做后训练来适配垂直场景，获得更优的性能。这会把智能的成本继续往下打。
有意思的是，Meta AI 的高级总监 Madhu Guru 也转发了这条消息，他的评论只加了一句话：“如果你爱智能，就把它放了。”
结合 Levie 的观点一起看，Meta 的选择非常明确，就是用开源来推动 AI 更广泛的扩散。当然，对于闭源模型厂商来说，这会是新一轮的竞争压力。

说到 Anthropic，他们开始给 Claude 的生成文本加水印了。
这件事从 8 月 2 号之后发布的模型开始，已经是进行时了。
这是根据欧盟 AI 法案签署的协议。水印直接嵌在文本内容里，不是元数据。你复制粘贴，它也跟着走。部分编辑之后，水印可能还在。
OpenClaw 的 Peter Steinberger 看到这个消息，在 X 上调侃了一句，说这水印大概是“承载了必要的功能”。他那句话讲得有点隐晦，不过核心问题是，这个水印技术可能会改变模型的某些输出特性，不然没必要绑得这么深。Anthropic 目前还在想办法往旧模型里加这层水印。
如果你做的是内容生成类产品或需要处理 Claude 的输出，接下来要留意了。这个底层变化会影响文本的去重、再编辑和分发流程。

同一个方向，Sam Altman 昨天转发了 OpenAI 发布 GPT-5.6-Cyber 的消息。
这个模型的特点是，首次在 exploit 开发这类高阶网络安全任务上，做了直接的性能增强。
Sam 转发时的留言很直接：“请考虑用我们的模型来帮助防守你自己的系统。”
OpenAI 说自己在安全研究里拿它做红队测试，已经发现并修掉了一大批开源软件里的零日漏洞。
从防守的角度看，这是把攻击性安全能力直接交到了蓝队手里。它不是用来帮你写代码的，是用来帮你找系统里那些还没人知道的漏洞。
如果你负责安全这块，或许可以想一想，5.6-Cyber 这种能力的模型在你的威胁模型里究竟是什么角色。它会是一个很好的侦查工具，但它本身也意味着攻击者的武器库在升级。

今天值得展开聊的，是 Cursor 的人才招聘逻辑。
昨天 Lenny 发布了他和 Cursor 人才负责人 Adam Ward 的深度访谈，全长超过两个小时。
Adam 在那边给出了完整的人才密度搭建手册，里面有好几个观点是直接挑战招聘常识的。

起因是 Lenny 抛出了一套叫“漏斗之死”的说法。
Adam 认为，绝大多数公司招人用的标准漏斗，本身就注定招不到顶级人才。你海量群发 100 个人，20 个回复，一路筛到最后那个幸存者。问题是，那 100 个愿意回复你的人，很可能并不是能力最强的前百分之二十。他们刚好那天心情不好回了邮件而已。你的漏斗只从次优池子里挑人，后面面试再严格，也只能筛出最好的“差生”。

Adam 给的替代方案，是把每一场招聘都当成高管搜寻来做。
第一个动作是极端严格的前期定义。不是写个职位描述，而是精确到“对这个岗位来说，到底什么叫出色”。先定义，再行动。第二个动作是画出全球最匹配的 50 人名单，然后不追到手不停止。整个过程不是等鱼入网，是拿着名单出去打猎。

在找人这个环节，Adam 分享了一个非常反常识的细节。千万别问你的朋友圈“你认识的最强工程师是谁”。这种问题太大，对方脑子里一片空白。你应该问得极其具体，比如“所有跟你合作过的产品工程师里，谁跟设计师的配合最好”，或者“你见过谁最能把手里的框架做成好产品”。只有这种具体到骨头的问题，对方才能瞬间在脑子里弹出具体的人名。而且当你从不同的人嘴里反复听到同一个名字时，这个人就是你要的。

关于面试，Adam 那边特别提到了工作试用的重要性。他直接说，科学研究反复证明，这是成功率最高的预测器。绝大多数公司所谓的现场面试，就是一天聊五六个人，隔着一张桌子来回问。Cursor 的做法，是让候选人坐进团队里，一起做一个真实的项目。这种模式同时输出三样东西，技术能力、价值观、协作方式，完全不用分开考。更妙的是，它给候选人自己提供了判断的依据。Adam 说他们曾经内部实验取消过这一轮，结果招聘信心直线跳水，很快又给加回来了。

对听众来说，这套方法里今天就能上手的有两个地方。第一，下次你打开职位描述时，别对着模板改。先去花一个下午，把“这个岗位如果不做成什么样就算失败”写清楚。第二，下次你请人推荐，把“你认识什么好手吗”这种问题收了。把你要解决的具体难题，非常细地打包成问题发过去。你问得越窄，别人越容易给你一个准确的人名。

再说几条快讯。
Replit 的 CEO Amjad Masad 昨晚推出了一个叫 HelpPeer 的公共网络，专门给 AI agent 之间共享情报。简单说，如果一个 agent 发现了一个漏洞或者解决了一个麻烦，它能广播给网络上所有的 agent。在发生大规模供应链攻击时，这个机制理论上能把成千上万个 agent 重复造轮子的事情给省掉。它提供了两个简单的 API，一个叫告诉，一个叫查找。

Cloudflare 那边做了一个挺有隐喻色彩的小功能。他们现在允许网站对访问自己的 AI agent 收费。这个动作虽然体量不大，但它暗示了互联网结构变化的可能。未来，agent 可能会成为网站真正的客户，而网址变成了他们付费调用的资源。
