Salesforce 把原本需要 231 天的工程迁移压到了 13 天，他们是怎么做到的？好莱坞对 AI 的真实态度，和网上说的完全不一样？当 Greg Isenberg 说 Opus 4.8 不值得他花一小时做节目，这背后是什么信号？先从最让工程师睡不着的那件事开始。

Salesforce 内部一次原本被估算为 231 天的工程迁移，实际只用了 13 天就上线了。
Claude Code 团队的 Boris Cherny 昨天引用了 Salesforce 刚发布的详细案例报告。
其中一个 PR 交付了 21 个端点，测试覆盖率直接拉到了 100%。
更关键的是，产量上去的同时，质量也没掉。总事故数反而下降了 5%。

他们把安全护栏和质量标准直接嵌进了 agent 工作流里。以前大家总说效率和质量得二选一，Salesforce 这次把两个都拿了。
Boris 特别强调了一点：真正从 AI 上获得最大收益的团队，不是在加速原来做的事情，而是彻底改了工作方式。比如砍掉某些步骤、取消某些交接环节、让 agent 端到端地拥有一整个任务。
如果你团队里还在用老流程跑 AI，这份 Salesforce 的完整报告值得翻一翻。链接放在 shownotes 里。

同一时间，Google 的 Gemini App 配额问题有了明确回应。
Google Labs VP Josh Woodward 发了一长串更新，核心几条是这样的：之前一个 bug 导致一两个 Omni 视频生成就能把某些用户的配额烧光，这个 bug 已修复。Ultra 用户的 Omni 视频额度直接翻倍，即刻生效。
现在复杂 3.1 Pro 的提示如果附加了大文件，单次消耗会有上限封顶。Flash-Lite 的提示免费，不占配额。模型选择偏好会跨 session 记住，不会自动跳回默认。Woodward 最后说，请继续提反馈。这条线程的整体调性很务实，没有打太极。

Justine Moore 昨天在好莱坞泡了一整天，跟电影人、制片厂高管和工作室聊了一圈。她的结论和网上喊得最响的声音完全相反。
网上最主流的论调是好莱坞恨 AI。但 Justine 看到的现场氛围是：我们已经到了一个临界点，AI 真的被用在正经项目里了。
她写了一篇长文讲整个行业为什么在转向，从实际使用者的角度，而不是围观者的想象。如果你在内容创作或媒体行业，这篇文章值得看。

Greg Isenberg 发了一条在圈子里传了一夜的推文。他说他没在自己的播客里讲 Claude Opus 4.8，因为他觉得它并没有比 GPT 5.5 好多少。
他的核心观点是：模型发布正在变得像 iPhone 发布。以前每次都是真跳变，现在变成了稍微好一点的摄像头，你几乎感觉不到差别。
4.6、4.7、4.8，每个都有一点不同，但没人说得清到底好不好。评测一个数，体感另一个数。
真正改变格局的东西在模型外面。比如这周 Claude Code 的动态工作流，Codex 的桌面应用，这些都是让一个人能建造更多东西的发布。模型本身正在变得可互换。
他估计再 6 个月，没人会在乎用哪个模型，就像没人会在乎 Uber 的发动机是什么牌子的。你只是想从 A 点到 B 点。
Riley Brown 昨晚也表达了类似的方向，他说除非模型有重大突破，否则他现在更兴奋的是超级应用的更新，Claude Desktop 还有很大的追赶空间。

先把节奏放慢一点，说一下今天最值得想清楚的一件事。

昨天 Zara Zhang 问了一个问题，她说很多人半开玩笑地用"AI 精神病"这个词。但她真的很想看一些关于重度使用 AI 对人类心理影响的研究。
她问：在多个 agent session 之间不停地切换上下文，会不会缩短你的注意力？你有没有感觉自从用了 AI，注意力变差了？
这个问题问得很巧。因为这周我们其实看到了好几个相关的讨论点。

Justine Moore 调侃说教皇显然没在凌晨一点被 Claude 温柔地育儿过。她是在回应教皇前一天关于 AI 没有道德意识的声明。Linear 的产品负责人 Nan Yu 只回了一个词：yet。
而就在同一天，程序员圈子里也在讨论类似的问题。郭宇说他早上 vibe 了一会儿，午饭后困了，在沙发上眯到五点，醒来头晕得跟天塌了一样。他怕自己过两天又会滑回深夜通宵写代码的节奏，问大家有没有好的解决办法。
Riley Brown 也在琢磨，Codex 的电脑操作动画很酷，但有没有可能很快 agent 的操作速度会快到我们根本看不懂了。

这些碎片拼在一起，指向同一个问题：工具在加速，但人的硬件没变。
Zara 问的是注意力，郭宇担心的是作息，Riley 观察的是认知跟不上 agent 的速度。而 Justine 和 Nan Yu 的调侃背后，是人在深夜和 AI 对话时那种奇异的亲近感和依赖。
这不是一个遥远的趋势。就在过去 24 小时里，这几个人的推文下面都有大量回复。
如果你最近也发现自己坐在电脑前，开了一堆 agent session，做了一下午但说不上来到底做了什么——也许可以把 Riley 的建议当真试一下：每次开始用 agent 之前，拿张纸手写出今天要完成的事，做完一条划掉一条。他说笔和纸会让事情变真实。另外，诚实问自己，你是在加速做成事情，还是在加速制造噪音。
