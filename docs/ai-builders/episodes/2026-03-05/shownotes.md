## 今日摘要
本期聚焦三个核心话题：SWE-Bench Verified 正式退役，benchmark 污染问题被彻底摆上台面；Claude Code 负责人的一句"每个人都是 PM、每个人都写代码"引发广泛讨论，多家 AI-native 公司分享了落地实践；RevenueCat 直接招聘 AI Agent 担任 Developer Advocate 职位，月薪一万美元，面试对象是 Agent 本身。此外还有 NotebookLM 新功能、Cursor 进入 JetBrains 生态等产品快讯。

## 重点话题
- SWE-Bench 的落幕：OpenAI 主动退役这一主流编程 benchmark，原因是模型污染和题目质量问题，揭示了 AI 评估体系的系统性困境
- 每个人都是 PM，每个人都写代码：Claude Code 负责人的预言 + 三家 AI-native 公司的落地实践，展示了 AI 重塑工作角色的真实路径
- RevenueCat 招聘 AI Agent：月薪一万美元、直接面试 Agent，这个案例折射出 AI Agent 承担真实工作职能的趋势正在加速

## 快讯
- NotebookLM 推出 Cinematic Video Overviews，支持从资料生成视频摘要，Ultra 用户可用
- Cursor 通过 Agent Client Protocol 接入 JetBrains IDE，覆盖更多开发者生态
- OpenAI Prism（LaTeX 编辑器）集成 Codex，并新增版本管理功能
- Replit 发布纪录片《21 Days to Launch》，记录 AI-native 团队的真实构建过程
- OpenAI 发布博客 Harness Engineering，探讨如何在 agent-first 世界中有效使用 Codex，收藏量破 1900
- Matt Turck 用一句冷笑话点出 AI 创业公司的结构性成本困境：VC 的钱最终都流向了模型提供商
