## 今日摘要
Vercel 开源了多 agent 并行安全审查工具 deepsec，能在几分钟内发现人工团队数月才能找到的漏洞。Greg Isenberg 分享了一套收购死 SaaS、用 agent 重建的详细操作手册，成本低至数千美元。Greg Isenberg 还邀请到操盘手 Andrew Wilkinson，讲述他如何用 agent 独自运营 40 多家公司——真实体验是 50% debug、30% 改进、20% 产出，但产出强到停不下来。此外，AI 微短剧在中国上月激增 5 万部，Factory 推出中间价位计划，哈佛研究显示 LLM 在急诊分诊中准确率已超真人医生。

## 重点话题
- **Vercel 开源 deepsec**：基于 Vercel Sandbox 的 CLI 安全审查 harness，可并行调度数千个 agent 审查代码库，现已公开可用。
- **Agent 单人运营真实全景**：Andrew Wilkinson 展示如何用 Claude Code、OpenClaw 等工具零员工跑 SaaS，收入两万美元/月，同时坦诚 50% 时间在 debug。
- **死 SaaS 收购转型 agent 公司策略**：Greg Isenberg 给出 10 步可执行清单，从扫描到谈判到产品重建，以及用旧数据获取新用户的打法。
- **AI 微短剧海外前夜**：抖音上月上传 5 万部 AI 短剧，Justine Moore 认为类似内容将很快席卷海外短视频平台。
- **Gemini API 支持 Webhooks**：Google AI Studio 为长时间运行任务提供异步通知能力，错误消息也更可读，改善 agent 开发体验。
