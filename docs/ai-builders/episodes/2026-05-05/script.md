欢迎收听 AI Builders Daily。每天 10 分钟，看 X 上 AI 圈最值得关注的信号。

Vercel 开源了一个能把上千个 agent 同时丢进代码库找漏洞的工具，Guillermo Rauch 说这比人工审计快了好几个量级。Greg Isenberg 放了一份收购死 SaaS、用 agent 重做一遍的详细清单。一个管理着 40 多家公司的操盘手，把所有业务都交给 agent，凌晨 3 点爬起来 debug——这种体验到底什么样？先从最让工程师睡不着的那件事开始。

Vercel 把内部用了好几个月的安全审查工具 deepsec 开源了。Guillermo Rauch 昨天亲自宣布，这是一套专门给 coding agent 用的 CLI 安全 harness，底层跑在 Vercel Sandbox 上，可以并行扩展。按照他的说法，几千个 agent 同时审查一个代码库，几分钟就能揪出人类团队几个月才能发现的漏洞，甚至有些漏洞人根本注意不到。他们已经用 deepsec 跑过好几个大型开源项目，效果足够好，才决定放出来。如果你在维护开源项目，Guillermo 说了，他的 DM 开着，愿意赞助一次扫描。如果你手里有私有代码库，现在就能用 npx deepsec 试跑一下。

Greg Isenberg 昨晚扔了一份收购死 SaaS、用 agent 重建的操作手册，一共十步。思路是这样的：先让 agent 自动扫描 Product Hunt 和 Acquire 这类平台，找出 2019 到 2024 年间上线、有过真实客户然后沉寂的产品。直接联系创始人，花五千到三万美元买下来。接着把数据库导出来，把每一张支持工单都喂给模型。这些工单就是金矿——两百个陌生人已经告诉上一位创始人他们需要什么，前任没能交货，现在你可以。最后用 agent 把原有功能重做成真正自动执行的工作流，而不是再给人一个手动操作的 dashboard。旧邮件列表还可以用来做相似受众，跑几十美元一天的广告做验证。Greg 特别强调，这不是理论，未来五年这会是一批安静赚钱的人。另一条推文里他还介绍了一个叫 Harbor 的工具，可以在一屏里管理多个 agent 的状态、知识库和数据库。如果你正在琢磨 side project，这份清单很实操。

Gemini API 昨天上线了 Webhooks，同时改进了错误消息。Google AI Studio 的 Logan Kilpatrick 说，这是朝着改善长运行任务开发体验迈的一大步——批处理、agent、生成媒体这些场景，不用再靠轮询等结果。错误信息也重新做了一遍，让人和 agent 都能更容易读懂。如果你在用 Gemini 构建 agent 管线，异步通知这个能力值得马上接起来。

今天值得展开聊的，是这件事。

先把节奏放慢一点。Greg Isenberg 昨天邀请了一位不太爱抛头露面的操盘手 Andrew Wilkinson，聊他到底怎么用 agent 管四十多家公司。Andrew 的描述非常具体。他说去年十二月某天晚上，突然开窍了，凌晨三点爬起来，终端里同时开着十个 Claude Code 标签页。他把这种感觉叫做 chasing the dragon，追龙，从那天开始就没停过。

他手头有一个叫 Deep Personality 的 SaaS 产品，做一个四十分钟的人格测试，生成一百页报告，用 Robert Greene 式的文风写给你。这个产品的整个团队是零个人类员工，月收入两万美元。支持 agent 会读取工单，要么自己处理，要么丢给研发 agent。如果碰到紧要的 bug，研发 agent 会自己修掉、合完 PR，然后给客户回邮件——全程在他睡醒之前完成。营销 agent 连着 PostHog，管 Meta 和 Reddit 广告，自己生成创意、跑多变量测试、定预算。他下一步打算给这个 agent 一个月十万美金的广告预算，看它能干成什么样。

但故事的另一面，Andrew 也很诚实。他说自己的时间分配，大约一半在 debug，三成在改进设置，只有两成能真正产出。这就是一台跑步机，停不下来。跟这个形成对照的，是昨天 Riley Brown 和 Peter Yang 的吐槽。Riley 说 OpenClaw 刚开始很好玩，几周之后各种问题就来了：网关掉线、定时任务不触发、技能有时候用有时候不用、内存衰减、集成反复要重绑、往外写文件放错位置。Peter 甚至发了一条自嘲——为什么放着正事不干，在 OpenClaw、Hermes 和 Perplexity Computer 之间反复搬迁。

两个画面放在一起，就很有意思。一方面，一个人已经在用 agent 独立运营几十家公司，结果实实在在地进账。另一方面，即使是一线工具的深度用户，也没有一个人的体验是完全顺滑的。到头来 Max Schoening 在跟 Lenny 聊的时候那句判断就很准：当 AI 填平技能缺口，剩下的真正分水岭就是 agency ——你是不是那种把世界当成可以改动的东西、然后真的上手去改的人。Andrew 就是这种人，debug 到凌晨三点也认了，因为那 20% 的产出足够让他觉得值。

如果你在考虑把自己的某些流程 agent 化，可以先花一周做一个小试点，看看实际的时间分配是不是 50% debug。如果那 20% 的结果让你不想停下来，那就是追龙第一次追上你的时候。

AI 微短剧在中国已经铺开了。Justine Moore 引用纽约时报的报道，上个月光抖音就上传了五万部 AI 生成的短剧，正在占领短视频 feed。她判断这类内容很快会在海外爆发——因为角色和布景本来就有限，观众对制作精度的宽容度很高。顺带说一句，这也给内容创作者提了个醒：低成本叙事型 AI 视频这个方向，空间还很大。

Factory 推出一个每月一百美元的 Plus 计划，正好卡在二十和两百之间。CEO Matan Grinberg 说这是用户呼声最高的功能——不是某个功能点，而是一个中间的定价档位。Plus 的用量是 Pro 的大约五倍，还能接入远程 Droid Computers 跑任务。

Peter Steinberger 把 RepoBar 升到了 0.4.0。这个菜单栏小工具现在有了持久化缓存、可见的 API 限制、更好的 Issue 和 PR 加载，越用越顺手。如果你每天都在 GitHub 上来回切，值得装一下。

还有一个快讯，哈佛附属 Beth Israel 医院给 o1 和真人医生同样的 76 个急诊分诊病例。模型的准确率是 67%，真人医生平均只有 50% 到 55%。Greg Isenberg 点出了那个尴尬：准 67% 的 AI 被叫危险，准 55% 的医生叫持证上岗。目前医院没有问责框架，有救命能力的工具，法务不敢让用。
