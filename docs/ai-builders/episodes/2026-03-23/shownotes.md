## 今日摘要

Vercel CEO Guillermo Rauch 发出了一个鲜明的判断：代码是输出，不是输入，工程师的注意力应该从"代码写得漂不漂亮"转移到需求、反馈和生产环境信号上。与此同时，Peter Steinberger 指出 AI coding 的速度瓶颈已经从 token 速度转移到算力，Karpathy 用 OpenClaw 控制家里设备的视频让这个趋势更加具体。Aaron Levie 用云计算的历史数据说明，我们现在大约在"AI 的 2010 年"。Claude Code 的 `/init` 命令也迎来了重要更新，开始主动帮助用户完成项目配置。

## 重点话题

- **代码是输出**：Guillermo Rauch 认为随着 coding agent 普及，代码从"技艺"变成"副产品"，工程师注意力应转向需求、反馈和生产环境信号
- **算力成为新瓶颈**：Peter Steinberger 指出速度制约已从 token 速度转移到算力，Karpathy 用 OpenClaw 以自然语言控制家居设备印证了 agent 向物理世界蔓延的趋势
- **AI 的 2010 年**：Aaron Levie 以云计算从 5 亿到 2200 亿美元的历史对比说明，coding agent 目前的位置只是整个市场爆发的起点
- **Claude Code /init 更新**：新版本将主动"采访"用户并完成 CLAUDE.md、hooks、skills 等配置，告别手动填写空白文件的摩擦
