Jeff Dean 拉上谷歌三巨头创立了新公司，要自动化机器学习本身。Meta 的 Muse Code 来了，一个终端里的编码 agent。还有，为什么普通人到现在还没用上 AI agents？这个追问在圈子里吵了一夜。先从最让工程师睡不着的那件事开始。

Jeff Dean、Sanjay Ghemawat、Oriol Vinyals 和 Quoc Le 联合创立了 Discovery Loop。这是一家公益公司，使命是自动化机器学习、科学和工程，加速发现。Jeff Dean 昨天亲自宣布了这个消息。四个人共事了 14 到 30 年，打造过全球使用最广的产品、基础设施和 AI 模型。现在他们要把这些经验用来让 AI 自己搞科研。

swyx 调侃了一句，说连全世界最强创始团队也逃不过湾区办公室的物理限制。不过玩笑归玩笑，Discovery Loop 的起点非常高。如果你在做 AutoML 或 ML infra，这家公司接下来的一举一动都值得盯紧。

Meta 发布了 Muse Code，一个终端编码 agent。它基于 Muse Spark 1.2 模型，能接管大型仓库里的完整软件工程任务。从规划改动、写代码到验证结果，全流程自己跑。扎克伯格亲自宣布，现在是 beta 阶段。

Riley Brown 马上开了直播演示。如果你在考虑给团队配编码 agent，现在又多了一个来自 Meta 的选项。不过目前还是早期版本，具体能覆盖多少语言和框架，还得看后续反馈。

阿里发布了 Qwen3.8-Max，一个 2.4T 参数的模型。它号称能连续 10 天自主编码，从空文件夹直接做出可交付的项目。下周会开源权重，同时还会放出 Qwen3.8-27B。API 价格是输入每百万 token 两美元，输出六美元。

Meta 的 AI 高级总监 Madhu Guru 给了一个很实用的策略。他说先用最贵的模型做原型验证体验，六到八周后等开源权重追上，再把生产切过去。你的模型选型策略是什么？先贵后便宜，还是一步到位？

白宫的新 AI 框架豁免了开源权重模型的安全测试。Axios 昨天报道了这个消息。FactoryAI 的 CEO Matan Grinberg 说，这是开源模型的巨大胜利。闭源模型将面临更重的监管负担，而开源模型等于拿到了一张自由通行证。

如果你在开源社区或依赖开源模型做产品，今天可以稍微松一口气。但政策落地的细节还没出来，保持关注。

Vercel 把沙箱配额直接拉到了五到十倍。现在支持一万个并发沙箱，每分钟五千个 vCPU，而且还能申请更高。Guillermo Rauch 说这是“无限 agent 算力”。

同一时间，Next.js 16.3 也发布了。在 Vercel 上跑的 Next.js 应用，预取请求减少 45%，静态资源减少 17%，路径元数据服务快了两倍。如果你用 Vercel 跑 agent 或 Next.js 应用，现在有更多算力余量，还能直接降成本。

先把节奏放慢一点，说一下今天最值得想清楚的一件事。

Josh Miller 昨天发了一条长推，问了一个让很多人坐不住的问题。他说，AI agents 的技术明明已经到位了，模型和工具链都很强，但普通人还是不用。大家只是把 ChatGPT 当高级搜索和语法检查。这跟当年 Instagram、Uber 那种爆发式扩散完全不一样。他最后说，谁能想明白为什么，谁就能在 2027 年赚到大钱。

这条推文被反复引用。Madhu Guru 的回应很直接。他说问题出在我们要求用户理解太多术语。一上来就是空白输入框，要选模型、决定用不用 agent，还得懂什么上下文窗口、MCP、记忆、技能。普通人根本不关心这些，他们只想要把事做完。

Zara Zhang 从另一个角度切入。她引用技术扩散理论，说采纳新技术是个社交过程，不是纯效率决策。人们会因为看到同类人用了之后变得更酷、更有钱、更受尊重，才跟着用。或者觉得周围人都在用，自己不用就会被落下。她补了一句，现在 AI 圈充满从众思维，很多公司失去了自己的愿景，开始追着别人跑。

Box 的 CEO Aaron Levie 从企业视角给了一组观察。他说现在问十个 IT 负责人他们的编码 agent 策略，至少能听到五种不同答案。有的统一用 ChatGPT 或 Claude，有的让员工自选，有的自己搭编排层。模型选型、数据访问、权限控制，全都还在试探阶段。这意味着市场远未定型，机会还很多。

把这些拼在一起，信号很清楚。如果你在做 AI 产品，别只强调效率。展示谁在用、用完之后得到了什么，比说“10 倍效率”有效得多。另外，把产品做得像自来水一样简单，别让用户选模型、配参数。你最近有没有试着让完全不懂技术的朋友用一下你的产品？他们卡在哪一步了？

再说几条快讯。
HappyRobot 完成 1.5 亿美元 C 轮融资，估值 12 亿。他们做企业电话和邮件的 AI agent，客户包括 DHL、Uber 和 Repsol，收入比上一轮涨了五倍多。

Obsidian 推出了免费工具，能把整个 Airtable 工作区转成 Markdown 文件。kepano 半开玩笑地说，万一 Bending Spoons 把 Airtable 的 API 砍了或者收费，至少数据还在你自己手里。如果你在用 Airtable，这个备份工具值得装一下。

Peter Yang 开源了 /human-review，一个可视化编辑器。你可以在里面直接改 AI 生成的 HTML 和 Markdown，还能像 Google Doc 一样留批注，最后点一下就把修改发回给 agent。整个流程跑在本地，数据不上传。

Google 的实验产品 Dreambeans 扩大了试用范围。除了 AI Ultra 用户，美国的 AI Pro 订阅者现在也能用了。它会每天推送个性化的深度内容集合，从你的 Google 应用里捞出你可能错过的信息。
