Vercel 今天把 AI SDK 升级到了一个全新的抽象层，叫 HarnessAgent。
Guillermo Rauch 昨天亲自宣布了这件事。
这层抽象让你能用统一的接口编排 Claude Code、Codex、Pi 这些 agent 的大脑，带着沙箱会话和 AI SDK 兼容的流。
Guillermo 说，它同时帮你摆脱模型和 agent 的锁定。
而更妙的是，它不只是为了可移植性，用起来也相当顺手。
已经在 canary 频道上线了，npm i ai@canary 就能试。
如果你现在正纠结 agent 基础设施选型，这条命令值得跑一下。

OpenAI 在昨天确认收购了一家叫 Ona 的公司。
它的安全云端执行技术会被整合进 Codex 团队。
这意味着，很快你的 Codex agent 就能在笔记本电脑关闭后继续干活了。
对需要跑长程任务的人来说，这改变挺大的。
中文圈的独立开发者郭宇看到消息后感叹，通用云端 agent matrix 这下可以不用自己做了。
如果你在用 Codex 做数据爬取或者批量重构，请盯紧更新——关掉屏幕让 agent 自己跑的感觉，很快就能体验到了。

Figma 发布了一个 Chrome 扩展，现在你可以把任意网页一键复制成可编辑的 Figma 文件。
昨天 Justine Moore 试了一下，说必须自己亲眼看才敢相信。
郭宇也转发了这个消息，只打了四个字：“哇这个好！”
对产品经理和设计师来说，竞品分析和灵感采集的速度可能会被彻底改写。
你平时怎么把灵感快速转化成设计稿？这个功能会不会彻底改变你的流程？

Box 的 CEO Aaron Levie 今天分享了一份覆盖 1640 名 IT 领导者的调查数据。
结论有点反直觉：AI 采用最多的公司，恰恰是招聘人数增加最多的。
Levie 解释，公司越用 AI 越高效，就越想雇更多人做更多业务，而不是裁人。
换句话说，AI 并没有让工作岗位消失，它让公司想把以前不敢做的工程和销售都提上日程。
如果你团队里有人担心 AI 会吃掉所有岗位，或许可以把这个数据发给他看看。

接下来这段我们多说几句。
昨天，一条推文在圈子里传得飞快——AI 教育者 Riley Brown 转发了一位用户的感慨：Fable 的 API 每小时 600 美元。
Brown 补了一刀：如果按 40 小时工作周算，年薪相当于 124.8 万美元。
这个数字当场就炸了。

不过，成本这件事没这么简单。
OpenClaw 的创始人 Peter Steinberger 引用了 Thorsten Ball 的真实对比测试。
同一个复杂功能，Fable 花了 350 美元，OpenAI 的 deep^2 只要 20 美元就搞定了，追加提示后总成本也就 40 美元。
Steinberger 特别提醒，GPT 的成本效益要高出 10 到 20 倍，这一点大家讨论得还不够多。

而另一边，Replit 的 CEO Amjad Masad 的感受完全相反。
他说在用 Fable 的时候零挫折，一直处于心流状态，因为几乎不犯错误。
Replit 内部还专门优化了 Fable 的成本，让总花费反而更可控。
Masad 打了一个比方：没有返工，最终反而更省钱。

Anthropic 的研究员 Alex Albert 也参与了讨论。
他分享了一个 prompt 技巧，能让 Fable 写得更通俗，去掉术语。
同时他还放出了官方提示工程指南的链接，里面有不少类似的操作方法。

你看，这些声音其实在讲同一件事：价格标签只是表面。
真正的问题是你项目的容错率和返工成本。
如果一次过能省掉几个小时的 debug，贵可能反而便宜。
但如果你能精细拆分任务，用便宜模型多试几次，性价比一样能打。
下次选模型的时候，你会为“一次过”付费到什么程度，又在什么情况下愿意多试几次？
