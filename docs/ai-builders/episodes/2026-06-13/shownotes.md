## 今日摘要
Vercel 发布了 HarnessAgent，一个统一编排多种 agent 的抽象层，试图解决锁定问题。OpenAI 收购 Ona，将云端执行能力带给 Codex。Figma 的新扩展让用户把任意网站一键转为可编辑图层。Fable 的 API 定价被算出年薪超百万美元，引发关于“昂贵模型是否更划算”的大辩论。Box 的调查显示 AI 采用越多的公司越倾向于增加人力，反驳了 AI 全面取代工作的说法。

## 重点话题
- **Fable 的成本与价值之辩**：API 时薪 600 美元 vs OpenAI 的 20 美元，Peter Steinberger、Amjad Masad、Alex Albert 从错误率、返工成本和 prompt 技巧等角度提供了不同视角。
