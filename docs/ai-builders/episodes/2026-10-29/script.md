谷歌两周内连发两个前沿模型，Carbon 的发布节奏意味着什么？Vercel 一天之内扔出三颗炸弹，CI、虚拟模型和 Docker 部署一起上线。而前 Anthropic 员工的观察，为什么让工程师和非工程师同时感到不安？先从最让工程师睡不着的那件事开始。

谷歌今天发布了 Gemini 4 Carbon。距离 Argon 发布，只过了两周。

Logan Kilpatrick 和 Josh Woodward 同时确认，Carbon 在 Artificial Analysis v5.0 指数上排第一，得分 59。它在长周期任务上明显优于 Argon，在安全基准上也拿了三个高分：漏洞发现 88.2%、漏洞利用 54.8%、漏洞修补 71.0%。

Josh Woodward 是 Google Labs 的 VP。他的原话是"内部对这个模型的反馈很好"。Carbon 会先开放给网络安全领域的可信防御者，然后通过 Fairwind 项目逐步扩大。更广泛的上线时间还没公布。

如果你两周前刚把 Argon 接进工作流，现在 Carbon 又来了。模型迭代已经缩短到以周为单位，选型策略得跟着变。

说到模型选型，Vercel 今天扔出了一颗解决"决策瘫痪"的炸弹。

AI Gateway 上线了虚拟模型功能。Guillermo 打了个比方：这就像模型的 DNS。你给 agent 配一个虚拟模型 ID，它在后端解析到真正的模型。团队不用再纠结该用哪个版本——你可以集中管理模型字符串和配置，随时切到新模型，还能强制开启零数据留存。

同一天，Vercel 还发布了 Vercel CI。Guillermo 把它定位成解决"AI 编码瓶颈"的方案。核心三件事：更快更稳的基础设施、Turborepo 集成自动跳过和缓存已有工作、以及 agentic CI。

agentic CI 这部分值得注意。通过 CLI，agent 现在可以检查、中止、触发、重放 CI 任务。Vercel Agent 还能帮你优化流程。Guillermo 说这只是开始，后续会加更多 hook，让 CI 学会工程师的判断——比如"那些测试真的值得跑吗？"

Vercel 内部已经处理了近八百万个任务，CI 比之前快了两到六倍。目前所有套餐都能用 beta 版。

另一件值得说的事，来自 Anthropic。

Claude 团队的 Boris Cherny 分享了一组数据：犹他州在 10 个州政府机构里，给 34 名开发者配了 Claude Code。80% 的人在 30 分钟内搭建好了工作环境。四周试点结束时，71% 的人报告节省了 20 小时以上。

Anthropic 同时宣布和美国总务管理局扩大合作，通过 OneGov 协议，把 Claude 以六折价格带给联邦、州、地方和部落政府。

这是政府场景里比较扎实的落地数据。34 人、四周、20 小时——不是概念验证，是可以用计算器按一遍的数字。

个人 AI 助手的基准测试也出了新结果。

Claire Vo 做了一个"个人 AI 助手基准测试"，用 9 个任务测了 4 个产品。Lenny 转发了结果，只写了一句话：Grok Bot 赢了，而且赢很多。第二名是 Muse，ChatGPT Dot 和 Claude Duet 排在后面。

Claire 把完整评测放在 YouTube 上了。如果你在选个人助手，这个横向对比值得看一下。

另外，Replit 的 CEO Amjad 今天分享了一个有意思的架构思路。

他把 AI agent 比作降落到地球的外星物种：极其聪明，擅长软件和计算机，想帮人类做事。但不可预测——一次小误解就可能造成巨大伤害。怎么在释放生产力的同时控制风险？

Replit 的答案是"Agent Habitat"——给 agent 建一个有边界的栖息地。他们今天公开了这套安全架构的蓝图，目标是让企业能放心地把 agent 集成进工作流。

同时，Replit 还发布了 ViBench 2.0，一个长周期软件构建基准。agent 从空项目开始，逐功能构建完整产品，看不到后续步骤。目前最强模型——GPT-6.1 Sol、GPT-6 Astra、Opus 5.5——在所有检查点上的通过率只有 49% 到 65%。

先把节奏放慢一点，说一下今天最值得想清楚的一件事。

前 Anthropic Claude Code 团队的 Thariq 发了一条观察，说现在出现了一个很奇怪的现象：技术背景的人感到沮丧，觉得自己的技能没用了。而非技术背景的人，正拼命想让自己更懂技术，好把 agent 用得更好。

这条推文在圈子里传了一夜。

Box 的 CEO Aaron Levie 从另一个角度呼应了这件事。他引用 Sarah Guo 的观点，说企业工作流自动化目前还处在"自动补全和早期 Claude Code"阶段。他的判断是：企业经济里真正部署了 agent 的比例，不到 1%。

Levie 认为原因有两层。一是企业技术采用本来就慢。但更主要的是 AI 能力本身还不够。现在有了计算机使用、长周期运行的 agent、harness 改进和周边基础设施，才真正到了可以把 agent 用在复杂工作流上的节点。

他特别提到一个关键转变：未来的重点不是终端用户去提示 agent 完成某个具体任务，而是组织重新设计底层工作流，让 agent 嵌入流程本身。金融、生命科学、医疗这些信息密集型领域会最先感受到冲击。

Peter Yang 则从招聘角度切了进来。他引用 Felix Rieseberg 在 Anthropic 取消编程面试的决定，列了一串他认为需要改变的招聘习惯：按工作年限或公司名筛人、重简历轻实际项目、把管理人数当成绩单、无休止的面试轮次而不是短期工作试用。

Thariq 还发了另一句话，只有七个词：勇气比天才更稀缺。

这几条放在一起看，有意思的地方在于——技术价值没有被抹掉，但它的承载形式在变。能快速理解业务、设计工作流、判断 agent 的边界，这些能力正在变得比纯写代码更稀缺。而招聘流程还没跟上这个变化。

如果你正在带团队，可能值得问一个问题：现在筛人的标准，是在找五年前需要的人，还是未来两年需要的人？

再说几条快讯。

OpenClaw 的 web UI 现在支持离线工作了。Peter Steinberger 说他在飞往维也纳的航班上，靠着不稳定的机上 WiFi 也完成了不少工作。新的 websocket 压缩和重连逻辑让断线重连不再丢进度。

ADPList 的 CEO Felix Lee 分享了一个实操案例：他用 Grok Bot 当"首席设计工程师"，把两周的设计流程压缩到了 24 小时。从问题陈述到设计方案，第二天早上就能看到结果。他跑了 100 个设计实验，平台参与度涨了 22%。

Lenny 今天发了两份招聘清单。高薪技术岗里，Anthropic 的多 agent 扩展研究员年薪 50 到 85 万美元。非技术岗那边，从 OpenAI 的活动管理总监到 Anthropic 的播客媒体经理，薪资范围也很透明。如果你在找机会，Shownotes 里有链接。

Claude Duet 即将支持本地 Mac 访问。Riley Brown 从 Gabe Mulley 那里确认了这个消息，而且 Duet 只用 Opus 5.5，不会降级到更弱的模型。
