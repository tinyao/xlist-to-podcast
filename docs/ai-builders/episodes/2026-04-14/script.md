谷歌把 AI 的自动补全做到了终端里，这会改变 vibe coding 的效率吗？Lenny 和硅谷大佬 Keith Rabois 深聊了两个小时，对 PM 这个岗位的判词有多直白？个人开发者用一个全新的 Claude Code 加 MCP 工作流，能在一次对话里跑通从创意到 A/B 测试的全流程吗？先从最让工程师兴奋的一件事说起。

Claude Code 上线了一种全新的终端渲染模式，名字叫 NO_FLICKER。这直接解决了过去 CLI 工具高频刷新带来的屏幕闪烁问题。这个特性是由 Anthropic 的工程师 Boris Cherny 在昨天公布的。它启用了一个实验性的新渲染器，甚至让终端原生支持了鼠标事件。Claude Code 团队的 Thariq 随后放出了完整文档。启用方式简单到只有一行环境变量。坦白说，虽然官方标注为实验性质，但内部绝大多数用户在使用后，已经不再想切回旧版渲染器了。在同一时间，Hamel Husain 挖出了 OpenAI Codex 的一个隐藏命令。他在 X 上贴出了具体指令。如果你在命令行输入 codex feature list，可以看到 Codex 正在开发中的功能清单。其中出现了 remote_control 和 codex_superapp 这些代号。这正好呼应了最近圈内盛传的 OpenAI 正在憋一个代号为 Scratchpad 的新实验性功能。

换个方向，Vibe coding 的基础设施昨天也有两个值得关注的小迭代。谷歌 AI Studio 的负责人 Logan Kilpatrick 宣布，他们在 vibe coding 体验里上线了名为 Tab Tab Tab 的提示词自动补全引擎。当你在 Studio 里刚有模糊想法时，Gemini 会直接帮你把指令补全。在移动端，这个功能改名叫 Tap Tap Tap。另一边，Replit 的 CEO Amjad Masad 确认，平台现在支持用户自主配置应用托管的全球区域。新开放了欧洲、亚洲、南美和澳大利亚节点。对企业团队来说，可以直接执行全组织的区域合规策略，计算和存储在部署时自动同区靠近。

说到开发工具，Greg Isenberg 昨天公开了一套被他自己称为“别人不知道的套利”的完整工作流。他详细拆解了如何在一个会话里，用 Claude Code 串联 3 个 MCP 工具和 2 款 AI 产品。流程是这样的：先通过 IdeaBrowser 的 MCP 读完项目上下文和增长策略。接着直接在终端里生成落地页并完成可视化设计，不去碰 Figma。然后一键部署，接入 Humblitics 打点分析。最后，从命令行直接给线上页面发起无代码的 A/B 实验。Greg 形容这种感觉，像当年 5 美分的 Facebook 广告红利又回来了。如果你正在做独立开发或小型 SaaS，这套可以闭环跑数据的终端工作流值得回去试一下。

先把节奏放慢一点，说一下今天最值得想清楚的一件事。

昨天 Lenny 播客的嘉宾是 Keith Rabois。如果你对这个名字有点模糊，他是前 Square 的 COO，PayPal 黑帮的核心成员，早期参与了 Stripe、Airbnb 和 DoorDash 的投资。在这期两个小时的对谈里，Lenny 数次想反驳 Keith，都没怎么成功。冲突最激烈的地方围绕着产品经理。

Keith 的判断很干脆：PM 这个角色，可能活不过 AI 时代。他的逻辑是，当 AI 让工程能力每周都在变，那种收集需求、排一年路线图、然后再去协调设计和工程的串联模式，在结构上已经不成立了。他给出的解法是，活下来的必须是具备商业敏感度的人。不论你现在叫 PM、设计师还是工程师，最本质的技能变成了读懂公司的生意公式，并直接决定下一步该做什么。这个观点和昨天 Peter Yang 跟 Figma CEO Dylan Field 的对谈，形成了某种呼应。Dylan 说得更形象一些，设计就是新代码。60% 的 Figma 设计现在是非设计师做的，画布正在接管需求文档的功能。

这里面真正反常识的一点是，Keith 把这种变化推到了极致。他认为对消费级产品而言，访谈用户不是没用，而是有害。理由很简单，消费决策是潜意识的。他举例，你去问保时捷车主为什么买这车，所有人都会给你一个理由，唯独不是真实的那一个。一旦错误的用户反馈进了组织，就像病毒一样锁进每个人的脑子里，污染后续的所有判断。这和当下很多团队试图用 AI 大规模做用户调研的思路，几乎是迎头相撞。

对听众来说，这期对谈最直接的启发其实是关于人的。Keith 分享了他坚持了二十多年的用人原则：找桶，不要找弹药。桶，指的是那种给一个点子就能独立从零干到产出的人，在整个公司里通常只有极少数。而弹药，是那些需要大量指导和手把手协调的人。他观察到一个残酷的事实，如果你不断增加弹药，而不增加桶，公司产出不会上升，只会增加协调成本和阻力。反过来看，大模型现在变成了一种极其廉价的弹药。这意味着谁能当那个桶，谁能利用 AI 这种近乎无限的弹药去独立闭环，这个人的价值在被极速放大。顺便说一个有趣的数据点，Keith 透露在他最看好的几家 portfolio 公司里，消耗 AI Token 最多的一号位，不是工程师，而是首席营销官。这些 CMO 正在用 AI 直接跑分析、出内容和拿洞察，不再依赖过去一整个副手团队。
