OpenAI 的 Codex 向所有企业用户开放了 Sites 功能，这意味着什么？微软 Build 大会第一天，OpenClaw 和 Windows 生态的深度整合会怎么改变企业级 agent？过去一年的 AI 编程狂潮里，Windsurf 这个品牌为什么突然消失了？先从最让工程师睡不着的那件事开始。

OpenAI 的 Codex 正式推出了 Sites 功能，可以让团队把工作流、数据和想法一键变成交互式网站或内部工具。
这项发布由 OpenAI 昨天官宣，Riley Brown 在 X 上第一时间做了演示。Sites 功能先面向 Business 和 Enterprise 用户开放，后续会扩展到更多计划。
Riley 提到，他用自己的 Codex 工作空间搭建了个人网站，配合周五自动部署和更新的工作流，已经完全不需要手动维护。这背后是 Codex 越来越强的自动化能力。用他的人话说，“Codex 的自动化加上 Sites 功能，对内部工具和个人页面会是巨大的组合拳。”
而 OpenAI 自己的数据也佐证了这股趋势。Zara Zhang 引述了最新 Codex 报告里的两组数字。一个是知识工作者占 Codex 用户的比例已经达到 20%，增长率是开发者的三倍。另一个是他们增长最快的任务类型，分别是数据分析、研究和知识工件。其中数据分析周环比增长高达 110%。
如果你正在用 Codex 做内部数据看板或团队协作页，现在可以直接在里面用 Sites 把结果发布成可分享的链接。这步棋让 Codex 从一个个人 agent 工具，开始长出团队协作的形态。

微软 Build 大会昨天开幕，最重磅的消息是 OpenClaw 正式进入微软企业生态。
这件事由 OpenClaw 和微软的 Omar Shahine 联合宣布。微软的 CVP Omar 刚上任 57 天，就推出了 Scout，这是微软第一个面向前线客户的 autopilot agent。而它的安全底座就是 OpenClaw 的企业级 claws。
Peter Steinberger 在 X 上跟进说，他和 Omar 合作的重点，是把可观测性和可验证的工作空间带进 OpenClaw。这解决了企业部署 agent 时最头疼的隐私和合规问题。Guillermo Rauch 也转发了 Warp 的案例。这个开发工具网站有千万级年访问量，团队从无代码编辑器切回代码，只用了三周，SEO 反而提升了。他的评论是：agents 已经把“代码很贵”这个前提彻底改写。
另一边，swyx 透露了另一个细节。微软 AI 负责人 Mustafa Suleyman 在访谈里可能意外透露了 Mythos 模型的 FLOP 规模。swyx 的原话是，“Mustafa 在两年内，在微软内部建了一个完整的 neo lab，从芯片到模型到 harness 全链路打通。”这背后是微软完全自研、接近 SOTA 的全线模型阵列。
如果你在跑企业内部 agent 试点，Scout 和 OpenClaw 的组合可能会是你下季度 POC 绕不开的选项。

Windsurf 这个品牌正式说再见了，整个团队和产品线并入 Devin 体系。
这个消息来自 Windsurf CEO Jeff Wang 的公开信，昨天下午在圈子里传得很广。Jeff 回顾说，Windsurf 这个品牌存在了不到一年半，而在此之前，公司的名字叫 Codeium，也只存活了差不多时间。他在信里写了一句挺扎心的话——“在 AI 时代，大多数产品的寿命只有一年，之后你就需要彻底改变它。”
即日起，Devin 将统一覆盖所有产品形态，包括云端 agent、IDE 式指挥中心、命令行、代码审查等。Jeff 本人会转任 Cognition 的新企业业务总裁，负责开疆拓土。
Peter Yang 在转发时给团队送了肯定，说很多 AI native 的 builders 现在都非常喜欢 Devin，他自己也打算找时间深度试试。
值得注意的是，Devin 在公告里特意强调它会通过 ACP 协议兼容其他 agent，把自己定位成 agent 时代的“瑞士”。这一步在群雄割据的 AI 编程工具市场里，赌的是互操作性和中立性。如果你在选型 IDE 或 agent 平台，现在 Devin 这个产品线值得重新审视。

先把节奏放慢一点，说一下今天最值得想清楚的一件事。

过去一两天，关于 AI 工程师和 FDE 的讨论突然多了起来。起因是 Andrew Ng 在 The Batch 里长文分析了 FDE 这个岗位的现状和局限。他提到一个关键矛盾：企业既需要深度定制化的 agent 服务，又担心被某个 FDE 绑死在一家供应商上。
郭宇随后发了一系列很有火花的推文。他说自己“Vibe 了五个多月”，不站 SOTA 模型公司会吃掉所有软件的阵营，也不站用 FDE 模式改造旧企业赚快钱的阵营。他押的是另一条路，就是 AI Native 公司会替代所有旧组织。他的原话是：“企业永远不会建立自己的软件团队，它们会被更有竞争力的组织替代。”
郭宇还拉了一个非常中国的参照系。他回忆 15 年前，支付宝把工程师派驻到银行网点，按今天的命名就是最早的 FDE。但最终，银行自己的 IT 并没有因此繁荣。真正的赢家是支付宝和微信支付这些新物种。
另一边，Box 的 CEO Aaron Levie 也加入了讨论。他引用了一个具体案例。顶级律所 Kirkland 计划四年花 5 亿美元自研 AI 法律工具。Aaron 的判断是，像 Harvey 和 Legora 这样的垂直 agent 公司会赢，因为律所根本不懂怎么做软件工程，也留不住顶尖工程师。他总结说，AI 让很多行业正在从“垂直一体化”变成“解绑”，一部分智能流向模型实验室，另一部分流向新冒出来的垂直服务商。
对你的启发是什么？一个是如果公司派你去谈 FDE 项目，你得问清楚，这个项目的核心护城河到底是模型参数，还是你们自己的独特数据和流程。Aaron 的原话是，“企业的竞争优势在于如何把内部的机构知识、数据资产和领域特定工作流，与 AI 连接起来。”另一个是如果你在创业，Greg Isenberg 今天凌晨的播客提供了一个很具体的框架。他说未来十年真正的大机会，是把所有 SaaS 工具都重建成 agent-native 的版本。举例来说，不是让 agent 去用 Notion，而是给 agent 造一个它的原生日志和协作工具。不是让 agent 填报销单，而是造一个 agent 的原生支付层。
无论你是工程师还是创业者，都需要做个选择。是在现有组织里把 AI 当一层皮贴上去，还是直接奔着一个 AI Native 的原生结构去。
