## 今日摘要
中国AI公司月之暗面发布开源模型Kimi K3，在Frontend Code Arena评测中从第18名跳至第1名，超越Claude Fable 5。1Password与Anthropic合作推出agent安全登录方案，密码不再暴露给模型。Vercel CEO宣布React和GraphQL的两位创始人加入公司，分别负责Next.js和agent开发体验。Boris Cherny提出"自动化基础设施"概念，认为团队应该把领域知识编码为agent可用的规则和文档。

- Kimi K3登顶Frontend Code Arena：2.8万亿参数开源模型，7个前端领域6项第一，权重将于7月27日开放
