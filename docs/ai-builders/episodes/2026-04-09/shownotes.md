## 今日摘要
Google Gemini 上线 Notebooks 功能，将 NotebookLM 的核心能力直接整合进聊天界面。Claude Managed Agents 进入公测，提供了从原型到百万级用户的 agent 部署方案。Vercel AI Gateway 发布团队级零数据保留功能，一键解决多模型合规难题。OpenClaw 发布新版本强化本地模型支持，社区也热烈讨论 agent 构建中“技能设计比模型能力更重要”的实操经验。

## 重点话题
- **Claude Managed Agents 深度解读**：Anthropic 的新 agent 云服务同时兼顾了快速原型和规模化部署，但社区提醒真正拉开差距的是你如何组织上下文和技能文件的信息密度。
- **Agent 构建方法论**：Greg Isenberg 与 Ross Mike 的实践经验指出，用 skill.md 而非 agent.md，可以大幅减少 token 消耗并提升 agent 表现稳定性。
