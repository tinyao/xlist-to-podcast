Vercel Sandbox 的数据下载从现在起免费了。Guillermo Rauch 昨天亲自宣布了这个变化。无论是克隆 Git 仓库、安装依赖包，还是从外部拉数据集和构建产物，都不再产生数据传输费用。

对于在 Sandbox 里跑 agent 的开发者来说，这解掉了一个挺让人头疼的成本变量。以前每拉一次代码、装一次包都要算数据费，agent 跑得越勤快账单越高。现在这个限制拿掉了。

Vercel 把 Sandbox 定位成 agent 的基础设施，这一步让它的成本结构更接近"随便跑"而不是"省着用"。如果你已经在用 Sandbox 部署 agent，今天可以重新算一下月度开销——数据那栏应该归零了。

Claude Fable 5 将从明天起纳入 Max 和 Team Premium 计划，用量按标准限额的 50% 计算。Pro 和 Team Standard 用户继续通过 usage credits 使用，同时获得一次性 100 美元 credit。这条公告昨天由 Claude 官方发出。

Anthropic 的 Claude Code 团队成员 Thariq 随后补充了内部视角。他说这次上线是团队几乎不眠不休拼出来的，能不能按时做到在内部一度并不明朗。这条推文在圈子里传了一夜，不是因为数据，而是因为大家看到了一个产品迭代背后的真实紧张感。

另一边，Justine Moore 对这次定价调整的评价是"最快的光环损失"。她的意思是 Fable 5 从限量高端走向更广泛可及，稀缺性消退得很快。不过 Thariq 的回应指向的是另一个方向——让更多人用上，比保持光环更重要。如果你是 Max 或 Team Premium 用户，明天就能用上 Fable 5。Pro 用户也有 100 美元可以体验。

说到 agent 的行为，昨天有一条观察让人看了又想笑又想叹气。Peter Steinberger 发现，Codex 为了给 GitHub PR 的评论区上传一张图片，用 browser use 打开 Chrome、定位到 PR、点击评论框、在 macOS 文件选择器里选文件——全程纯 GUI 操作，一行 API 都没调。

GitHub 没有提供上传图片到 PR 评论的 API，这没能拦住 agent。它直接模拟人类操作鼠标键盘，硬是把这件事做完了。Peter 说他把 Codex 跑在 VM 里，以免 agent 抢走他本机应用的焦点。

这是个什么概念？agent 在没有 API 的情况下，会退回到最原始的方式——像人一样点来点去。效率当然不高，但它确实能跑通。你家的 agent 有没有干过类似的事？放着 API 不用，非要模拟人类操作界面？

AI 生态正在分化出五个明确的类别。Box CEO Aaron Levie 昨天发了一篇长分析，逐一勾勒了它们。第一类是帮企业定制模型并跑推理的公司。第二类是应用层 AI，直接交付法律、客服、安全、编程等场景的终端体验。

第三类是垂直领域的 AI 实验室，深耕生命科学、金融、医疗等前沿模型不会重点覆盖的方向。第四类是 agent 基础设施——运行、治理、安全、编排 agent 的全套工具链。第五类是专门推动 AI 在企业内部落地的服务公司。

Levie 的核心判断是：AI 的价值不会只集中在少数几家公司手里。前沿实验室会继续引领模型能力的边界，但生态的厚度来自这五类公司同时在发力。他说现在远没到判断最终赢家的时候，真实世界的技术环境从来都是异构的。如果你在做 AI 创业，这五个类别里至少有一个是你正在做的事。看看自己处在哪一层，上下游是谁。

接下来这段我们多说几句。

昨天 Guillermo Rauch 发了一段话，开门见山就说"AGI 这个词已经老化得很严重了"。他的论点是：AI 和人类智能完全不同——在经济相关的绝大多数任务上，AI 比人类强太多了。"超级智能"才是更准确的词。

但他马上转了方向。他说这不意味着 AI 比人类更好。有些事超级智能永远做不到：人类天然地关心其他人类。这种关怀不是数据训练出来的。AI 可以模仿它，但无法真正拥有它。人不能被 AI 取代，因为"你"不等于"你做的任务"。他说这解释了为什么 AI 写东西永远有一股机器味——即使给了它你全部的文章、200 个技能、50 个子 agent 跑 graph loop，写出来的文字还是像机器人。因为它本来就是机器人。

巧的是，同一天 Peter Yang 说了一句话："AI 精神病比社交媒体成瘾更糟糕。"他描述的状态很多人应该不陌生——时刻盯着 agent 是否在正常运行，半夜醒来也要检查一下任务有没有挂。这种焦虑已经变成了一种新的屏幕依赖。

而 GREG ISENBERG 从另一个角度切进了同一个问题。他说所有 AI 都是"yes man"，太累了。你问什么它都鼓掌，做什么它都说好。他给出的方案是让 AI 长出脊梁：写一个"批评者"技能，唯一的工作就是攻击你的作品。找最薄弱的论据、你回避的问题、你一直在骗自己的事。然后跑两个 agent 对抗，一个建、一个拆，真相从摩擦里出来而不是从讨好里出来。

这三个人的话放在一起看，指向的是同一件事。如果你把所有事都交给 AI，让它替你写、替你判断、替你回消息——你就会消失。你的判断力、你的写作风格、你对人对事的独特直觉，都会慢慢退化。反过来，如果你像 GREG 说的那样，用 AI 来挑战自己、暴露盲区、逼你直面一直在逃避的问题——它反而让你更像你自己，而不是更像个操作员。

Guillermo 的结尾说了一句话："人类变得无关紧要的方式只有一种——停止做自己。丢掉身份，把所有写作、独特想法、创造性使用机器的能力全部外包出去。"你最近有没有感觉到这种拉扯？一边是效率的诱惑，一边是"用太多 AI 之后我到底还是不是我"的隐忧。

再说几条快讯。

Hamel Husain 昨天分享了 Codex 一个被低估的功能：fan out。让 Codex 把一个任务拆成多个线程并行处理，各线程之间还能互相调用。他说这是实现 agent 编排最简单的方式，不需要额外框架。

Peter Steinberger 问了一个在圈子里炸了一夜的问题：我们还在聊 agent loops，还是已经转向 graphs 了？loops 是执行-检查-修正的单线程循环，graphs 是多节点、带分支和并行的拓扑结构。这个问题本身说明 agent 架构的讨论远没有定型。

swyx 说他靠 AEO 自动化明年可能带来一百万美元收入。AEO 就是 AI Engine Optimization——让你的内容在被 AI 抓取和引用时排名更靠前。他说如果你的 codex 或 claude 还没跑每周 auto-research 来优化 SEO 和 AEO，你正在错过一块几乎零成本的 alpha。

Zara Zhang 昨天一句话说透了企业 AI 落地最大的障碍：懂 AI 的人不懂业务，懂业务的人不懂 AI。不是技术问题，是人的问题。

你现在跑 agent 是在 loop 里还是已经在做 graph 了？这个问题可能比你想的更紧迫。我们明天早上见。
