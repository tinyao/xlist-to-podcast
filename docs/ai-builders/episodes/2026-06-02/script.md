Perplexity 昨天推出了一套全新的搜索架构，叫 Search as Code。
它不再让 AI 模型像过去那样，一步一步调用搜索接口。
而是直接生成 Python 代码来驱动整个搜索栈。
Perplexity 的 CTO Denis Yarats 解释了这么做的原因。
他说，用户的研究任务越来越复杂，需要高度定制的搜索流程。
把搜索栈拆成可组合的低级原语，再用代码来编排，是让大模型驱动搜索最自然的方式。

这套方案带来了两个直接的好处。
第一是灵活性剧增。从模型生成的 Python 里，你可以直接构建自定义的排序管道。
也可以跑大规模、宽范围的网格搜索。
甚至能在搜索索引上直接做 map-reduce 操作。
第二，是 token 效率的大幅提升。代码生成把很多 agent 步骤压缩进了一个程序里。
这样一来，跟模型的来回对话轮次就少了很多。
Denis 的说法是，他们正在超越传统的工具调用和 MCP 协议。如果你正在做需要深度研究的 AI 应用，这种直接用代码操纵底层能力的思路，挺值得认真看看。

说完这个，我们把节奏放慢一点。今天值得展开聊的，是软件开发的成本趋近于零之后，什么才是真正重要的。
这个话题的起点是一句话。Sequoia 的 Mike Vernal 说：“当编写软件的成本降至零，我发现自己开始前所未有地看重 ambition。那种不合理的、不屈不挠的野心。”
Lenny 转发了这句话，说他和合伙人 Rohan 识别顶尖 1% 初创公司时，也得出了完全相同的结论。
另一边，Greg Isenberg 列了一个清单，盘点了过去两年 AI 圈里彻底翻转的 14 个流行观点。其中第一条就是：“GPT 套壳毫无价值”这个说法，现在被颠倒了。大家看到的是，真正的价值正在向应用层聚集。

这跟 Lenny 和 Benedict Evans 对谈里的核心判断，撞在了一起。
Benedict 的观点非常直接：基础模型公司不会有持久的定价权。价值最终会沿着技术栈向上游堆积。
他的逻辑是，模型之间看起来没有网络效应。当三到六家基础模型提供商展开无休止竞争，而且模型在用户眼中变得像无差别的大宗商品时，谁还能拥有定价权呢？
他举了一个数字，现在有些公司一个月在推理上烧掉 150 万美元。但他认为这是一种暂时的失衡，就像 2010 年有人收到了一张 5 万美元的手机流量账单。稳态会完全不同。

而恰恰是在这种“软件变成免费”的环境里，Benedict 提出了一个反直觉的观察：分发能力正在成为更有价值的护城河，而且这个事实有利于大公司。
道理很简单，当构建软件变得越来越便宜、越来越快，市场里的噪音就会爆炸式增长。
更多的产品会在更短时间内涌现，抢占注意力变得比以前更难。
所以，谁能把产品推到客户面前，谁能让客户真的用起来，谁就赢了。Aaron Levie 从企业市场的角度，也说了几乎一模一样的话。
他说，AI agent 们就像一群天才，但对你的公司一无所知。谁能把散落在人脑里、错误系统里的上下文，整理出来喂给 agent，谁就抓住了最大的杠杆。你看，从消费端到企业端，分发的定义在变，但分发的重要性反而被加倍放大了。

那这件事对你的具体启发是什么？
如果你在创业，或许可以问问自己：我的 ambition 到底够不够大？在工具让一切变得太容易的时候，选择做什么，比知道怎么做的价值高出十倍。这需要品味、需要领域知识、需要跟客户泡在一起的时间。
如果你在大公司里做事，那分发和上下文正是你手里最大的两张牌。检查一下你团队里，哪些数据孤岛还没打通？哪些流程上的“部落知识”还没被数字化？
别光盯着模型跑分，重新审视一下你自己的数据基础设施，可能是眼下最划算的一笔投资。
