Anthropic 突然限制第三方工具，OpenClaw 的开发者怎么说？Karpathy 分享了用 agent 构建个人知识库的完整工作流，还顺带抛出一个新概念。而 Arena 上出现了三款神秘的新型图像模型，它们的世界知识强得有点离谱。先从最让工程师炸锅的那件事开始。

Claude 的订阅计划从今天中午起，不再支持 OpenClaw 这类第三方工具了。昨晚，Anthropic 的 Boris Cherny 在 X 上宣布了这项政策变更。简单说，你不能再把 Claude 的订阅账号挂在 OpenClaw 上用，想继续用的话，要么额外购买打折的使用包，要么走 API 付费通道。还没花完的订阅额度，可以申请全额退款。

受冲击最大的显然是 OpenClaw 的开发者 Peter Steinberger，也就是大家常说的 steipete。他凌晨醒来发现，自己的评论区被各种告别和愤怒的声音淹没了。steipete 透露，他和 Dave Morin 之前一直在跟 Anthropic 沟通，试图阻止这件事。最好的结果也只是拖了一周。他用了很重的一个对比——Anthropic 先是在自己的封闭 harness 里抄了几个热门功能，然后反手就把开源工具踢了出去。

但这个决定背后，其实藏着一个很多人在讨论的经济账。Peter Yang 把这事比作当年 Uber 和 Lyft 的补贴大战。现在不管是 OpenAI 还是 Anthropic，那些一百到两百美元的订阅计划，根本扛不住重度用户全天候跑 agent 的算力消耗。Peter 提醒说，这两家公司都快要上市了，一旦财报公开，无限量订阅这种亏本买卖肯定要收紧。要么涨价，要么限流。

换个方向，Karpathy 昨天发了一条几乎是当天最火的推文，讲他如何用 LLM agent 构建和管理一整套个人知识库。他的做法是，把所有原始资料扔进一个目录。然后让 agent 自动把它们编译成一个完整的维基，全是 markdown 文件，包含摘要、反向链接、概念归类。整个维基大概一百多篇文章，四十万字。他用 Obsidian 作为前端阅读器。但几乎从不亲手编辑内容，全交给 agent 维护。

有意思的是，Karpathy 在另一条帖子里说，这条推文传得太广，他决定分享一个改进版的理念文件。这引出了他提出的一个新概念——在 agent 时代，你不需要分享具体代码或应用。你只需要分享想法，对方的 agent 会自己根据需求去定制实现。他把这叫 idea file，刻意保留了一些模糊空间，因为方向实在太多了。如果你对这套工作流好奇，gist 链接在 shownotes 里可以直接拿来喂给你的 agent。

同一天，Arena 上突然冒出三款新的图像模型，代号分别是 maskingtape、packingtape 和 gaffertape。Justine Moore 昨晚连发了几条测试结果，语气相当兴奋。她给的提示词非常简单，比如说 NeurIPS 2025 的海报大厅，或者是斯坦福校园里骑自行车的 POV，模型生成出来的图像质量极高。不只是画面合理，那种对真实世界具体地点的理解力让人有点意外。

Justine 还试了一个提示词，让模型生成 a16z 播客在 YouTube 上的截图。结果界面和时间戳的还原度好得离谱，尽管人物脸部还不太准，但她笑得不行，说虽然不是真正的 Marc 和 David，但已经很可以了。圈内普遍猜测，其中至少有一个是 OpenAI 正在测试的 GPT Image 2。Greg Isenberg 也转发了部分测试图，评价就四个字：看起来疯了。

接下来这段我们多说几句。

今天值得花时间展开的，是昨天 Box 的 CEO Aaron Levie 发的一条长文视频。他讲了一个很容易被忽略、但确实在发生的底层变化——当模型的工具调用能力、上下文窗口、推理能力都在同步往上走的时候，你设计 agent 的思路其实可以完全变了。

起因是 Aaron 在拆解 Box 内部的 agent 架构。他说，哪怕就在一年前，如果你想做一个能处理大量文档的 agent，业界的标准答案还是那套。先把数据做嵌入处理，再靠相似性搜索抽出相关 chunk，配上周围的上下文喂给模型。为什么非得这么干？因为当时的模型能稳定处理的上下文就那点，你只能切片。

这套方案在那个时候确实管用，尤其数据源比较干净的话。但它有一个根本性的别扭——那不是人的工作方式。打个比方，如果文件第一页写着此数据不可用，但第三页有高度相关的信息，chunk 搜索大概率只会把第三页的内容扔给模型，完全忽略第一页的警告。人在读材料的时候不会犯这种错，因为人是全文通读，带着判断去理解的。

而现在，Aaron 说，这一切在变好。模型能阅读的上下文窗口长了，而且读得不晕，推理能力也大幅提升。agent 可以做到更像人：先像你一样全局搜索，放宽查询条件，快速消化大量结果，一口气读完很多份文件。更关键的是，它开始有了自我纠错的能力——当它没找到想要的东西，或者感觉哪里不对劲，它知道自己该再去搜一次。

Aaron 用这个思路重新设计了 Box 的 agent 架构，整个范式从过去的 chunk 拼接变成了人式工作流的加速版。这个判断其实跟 Simon Willison 前两天在 Lenny 的播客里聊到的逻辑高度呼应。Simon 说他每天要同时跑四个 agent 来干活，到上午十一点脑子就已经被掏空了。他用的词是认知极限。agent 再多，人的注意力带宽就那么大，这是物理瓶颈。

Aaron 的说法是，这恰恰解释了为什么在 agent 身上不该有那种工作会消失的论调。因为短期内，agent 能多强几乎完全取决于你给了它多少上下文。它拿了什么工具，你能不能盯住它不跑偏，怎么把它产出的东西拼回系统里。这些事都需要人花真实的脑力去做。

那作为工程师或者产品经理，这件事今天能给你一个什么样的可操作的启发？有一个很具体的转向：你现在评估 agent 项目的时候，可以不再追着单次任务的成功率看了。你该看的是你脑子里能不能同时管住多个 agent。管不住，瓶颈就卡在你自己的认知内存上，跟你写了多少 prompt 没太大关系。

Zara Zhang 注意到圈子里一个新趋势：越来越多人开始把自己认识的人蒸馏成 agent 技能。同事也好，意见领袖也好，甚至前任也行，统统做成可调用的技能包。这个观察本身就是一个信号。

Cursor 的设计师 Ryo Lu 发布了新界面和新图标集。一共四百二十个图标，两种尺寸，两套风格，全部由设计师 Marek Minor 完成。视觉上确实下了功夫，那种有立场、有节制的设计感。

Anthropic 的 Claude 移动端上线了一个中等尺寸的桌面小组件。产品经理 Robert Bye 确认已经上线，你把 Claude 放在主屏幕上，不用再点进 app 就能直接唤起对话。

你最近在用 agent 的时候，有没有发现自己的注意力比写代码的时候烧得更快？这件事可能比你手头的 prompt 链值得想多一步。
