## 今日摘要
Anthropic 突然宣布 Claude 订阅不再支持 OpenClaw 等第三方工具，引发开发者圈强烈反应。Karpathy 分享了如何用 LLM agent 构建和管理数十万字的个人知识库，并提出了“idea file”的新概念。Arena 出现三款神秘新图像模型，对真实世界地点的理解力惊人。Box CEO Aaron Levie 则阐述了 Agent 架构正从“机械式 chunk 拼接”转向“类人工作流”，而工程师的认知极限正成为新的效率瓶颈。

## 重点话题
- **新图像模型现身 Arena**：三款代号为 maskingtape、packingtape、gaffertape 的图像模型在 Arena 上展示了强大的世界知识和文字渲染能力，疑似包含 OpenAI 正在测试的 GPT Image 2。
- **Karpathy 的 agent 知识库工作流**：Karpathy 详细介绍了如何利用 LLM 将原始资料自动“编译”成由 agent 完全维护的个人 Wiki，以及他提出的“idea file”分享理念。
- **深聊 - Aaron Levie 论 Agent 架构的范式转移**：随着模型推理和上下文能力的提升，Agent 设计正从依赖 embedding + chunk 搜索，转变为更接近人类全局阅读、自我纠错的工作模式。

## 快讯
- Anthropic 工程师 Boris Cherny 承诺将通过优化缓存效率降低 API 用户成本，openclaw 的开发者 steipete 对此表示认可。
- Zara Zhang 观察到新趋势：人们开始将同事、KOL 甚至前任“蒸馏”成 agent 技能。
- Cursor 发布全新界面和包含 420 个图标的图标集。
- Claude 移动端推出中等尺寸的桌面小组件，可快速唤起对话。
