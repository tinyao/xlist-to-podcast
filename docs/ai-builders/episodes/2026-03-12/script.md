今天是 2026 年 3 月 12 日，欢迎收听 AI Builders Daily。

今天我们要聊三件大事：Replit 拿了四亿美元融资同时发布了 Agent 4，Karpathy 的 autoresearch 项目让 AI 自己跑实验，还有 Claude Code 的一场宕机风波——以及这场宕机背后一个很有意思的信号。我们开始吧。


第一个话题，Replit 的大日子。

今天 Replit CEO Amjad Masad 宣布，公司完成了四亿美元融资，估值九十亿美元。投资方阵容相当豪华，包括 a16z、Coatue、YC，还有战略投资方 Accenture、Databricks、Okta，甚至还有 Shaq 和贾里德·莱托。

但融资只是开胃菜。同一天，他们发布了 Replit Agent 4，这才是今天真正的主角。

Amjad 在发布推文里说了一句话，我觉得很值得琢磨：软件不再只是技术工作，它是创意工作。Agent 4 的核心卖点是什么？无限画布加上并行 Agent。你可以在一块白板上同时跑好几个 Agent，一边让它们写代码，一边自己在旁边设计下一个功能，就像在画布上涂鸦一样。

Replit 的设计师 Jordan Walke 演示了一个场景：他在画布上构建一个图形着色器应用，同时生成几个设计变体并排摆放，挑中哪个就把哪个拉回主项目。Amjad 自己说，他当年做 Replit 的初衷就是为了保持心流状态，传统 IDE 太慢了，打断他的思路。后来做 Agent 又引入了新的等待感——你输入 prompt，然后干坐着等 Agent 跑完。Agent 4 想解决的就是这个问题：让你在等待的同时继续创作，而不是发呆。

有一个细节挺说明问题的：他们提到 Replit 现在已经在财富五百强里有 85% 的渗透率。这个数字如果是真的，说明 Replit 早就不是那个给学生练手的在线编辑器了，它在悄悄进入企业市场。

我自己的观察是：这次发布的核心叙事是"vibe coding 的下一个阶段"。第一阶段是你用自然语言告诉 AI 做什么，第二阶段是你和多个 AI 并行协作，像一个创意总监指挥一群执行者。这个比喻是 Amjad 自己说的，人类作为 creative director，AI 负责执行。这个方向对不对还要看产品落地，但方向本身是清晰的。

顺带一提，喜剧演员 Theo Von 也在用 Replit 做项目，Amjad 转发了他的帖子，配文"Voncoding"。这种破圈传播对 Replit 来说意义不小——当编程工具开始被非程序员当成创作工具使用，市场边界就彻底不一样了。


第二个话题，Karpathy 的 autoresearch，以及一个关于"智能断电"的有趣隐喻。

Andrej Karpathy 今天发布了一个叫 autoresearch 的项目，GitHub 已经开源。它的逻辑很直接：你给它一个目标，比如"让这个模型更好"或者"找到转化率更高的落地页"，然后它进入一个循环——规划实验、修改代码或配置、在 GPU 上跑短测试、读指标、保留胜者、再来一轮。

Greg Isenberg 用了一个很形象的比喻：机器人研究实习生，跑几百个实验，只保留赢家。你睡一觉，早上起来就有经过实测的改进版本。

但今天更有意思的不是 autoresearch 本身，而是 Karpathy 随后发的一条推文。他说，他的 autoresearch 实验室在今天 Claude 的 OAuth 故障中全部被清空了，他需要重新考虑故障转移方案。然后他说了一句让我印象深刻的话：Intelligence brownouts will be interesting — the planet losing IQ points when frontier AI stutters。翻译过来就是：当前沿 AI 抖一下，整个星球的智力都会掉几个点，这种"智能停电"将会很有意思。

这句话背后有一个很深的预设：AI 已经不是工具了，它是基础设施。就像我们不会说"停电很有意思"，而是说"停电很糟糕"，因为电是基础设施。Karpathy 在暗示 AI 正在走向同样的位置。

而这个预设在今天得到了某种程度的验证。Claude Code 今天上午出现了登录故障，大量用户无法使用。Anthropic 的 Claude Code 团队负责人 Thariq 在推特上发了故障通知，几个小时后宣布恢复。但在这段时间里，推特上有人说"我已经依赖成这样了，没法登录 Claude Code 就只能直接插 token 用"，还有人说不得不切换到 ChatGPT。

这个场景很有意思。一年前，AI 工具故障最多让人觉得不方便。今天，它让开发者的工作流直接中断。这个依赖程度的变化，才是今天最值得记录的信号。

Karpathy 在另一条推文里还聊了 IDE 的未来。他说，大家以为 IDE 时代要结束了，但他的判断恰恰相反：我们需要一个更大的 IDE。因为现在的基本单位不再是一个文件，而是一个 Agent。人类往上移动了一层，在更高的层次上编程，但本质上还是编程。他说，你可以 fork 一个 agentic org，就像 fork 一个代码库一样，但你没法 fork 微软这样的传统公司。

这个"可 fork 的组织"的概念很有意思，值得单独拿出来想一想。


第三个话题，Claude Code 的新功能，以及 Anthropic 在知识工作领域的布局。

就在今天宕机的同一天，Anthropic 其实发布了好几个值得关注的更新。

先说 Claude Code 的 /btw 命令。这个功能是 Claude Code 团队的 Boris Cherny 和 Thariq 一起宣布的，点赞数超过四千，是今天互动量最高的技术帖子之一。

它的逻辑很简单：当 Claude 正在执行一个任务的时候，你可以用 /btw 发起一个侧边对话，问它一个问题，它会基于当前完整的上下文给你回答，但不会打断正在进行的任务。Thariq 补充了技术细节：这个侧边对话不能调用工具，是单轮输出，但拥有完整的对话上下文。这个功能是工程师 Erik Schluntz 作为 side project 做出来的。

这个功能解决了一个真实的痛点：你在等 Agent 跑任务的时候，脑子里会冒出各种问题，但你不想打断它，又不想开一个新窗口重新解释一遍背景。/btw 就是那个"不打断工作流的提问通道"。

然后是 Claude for Excel 和 Claude for PowerPoint 的联动更新。Anthropic 的 Claude Relations 负责人 Alex Albert 说，这两个工具现在可以共享对话上下文了，你打开多个文件，Claude 能在它们之间传递信息，从表格里拉数据、构建表格、更新幻灯片，不需要反复解释背景。Alex 说，他预计未来几个月，整个依赖电子表格和 PPT 的行业都会开始被改变，就像去年 agentic coding 改变软件开发一样。

这两个更新放在一起看，能感受到 Anthropic 的一个明确意图：Claude 不只是对话框，它要嵌入到你真实的工作流里，成为你工作环境的一部分。从 IDE 到 Excel 到 PowerPoint，这是一个很系统性的布局。

还有一个值得一提的是 Claude Code 的 auto-memory 功能。Thariq 两周前发布了这个功能，今天他发推问用户体验如何。这个功能让 Claude 能跨 session 记住你的项目上下文、调试习惯和偏好，不需要你每次都重新解释。他在收集反馈，如果你在用 Claude Code，这是个可以去参与的讨论。


第四个话题，一个关于"agents 作为经济主体"的思想实验。

Box CEO Aaron Levie 今天转发并展开了 François Chollet 的一个观点，我觉得值得在这里聊一聊，因为它触及了一个还没有被充分讨论的问题。

Chollet 说，AI agents 很快会成为真正的经济主体，它们会购买服务、算力，甚至数据。Levie 接着展开说：当有数万亿个 agents 在互联网上活动，会发生什么？

他举了一个具体的例子。现在有大量高价值的专有数据和研究被锁在付费墙后面——金融数据、医学研究等等。人类不会为了偶尔用一次去订阅一个一千美元一年的服务。微支付模式也因为流量太低没跑起来。但如果一个 agent 有一个具体任务的预算，它可能愿意为一条信息支付零点一美元或一美元。这样一来，那些以前因为商业模式不通而无法存在的数据服务，突然变得可行了。

Levie 还提到，被 agent 发现将会成为一个全新的搜索和分发问题。我们现在谈的是"SEO"，未来可能要谈"AEO"——agent engine optimization。

这个方向还很早期，基础设施和行业协议都还没有，但这个思路本身很值得记下来。当 agents 有了钱包，互联网的商业模式会从根本上重写。


好，快讯时间，我来快速扫几条今天的其他动态。

Vercel CEO Guillermo Rauch 宣布，Vercel 的 Chat SDK 现在支持 WhatsApp。两行代码就能把你的 agentic chatbot 接入 WhatsApp，支持消息、回应、输入状态、位置共享等。对于想在 WhatsApp 上跑 agent 的开发者来说，这个集成门槛直接降到了地板上。

另外，Guillermo 还分享了一个内部进展：他们用 AI 实现了自动化的布局抖动修复和 skeleton 生成。用他的话说，就是让产品加载得像一幅渐进式的美丽画作，而不是东西乱跳。他说这个能力很快会开放给用户。

顺带一提，Cursor 今天上线了 Marketplace，超过三十个插件可以一键安装，或者用 /add-plugin 命令添加。Cursor 的设计师 Ryo Lu 说，目标是让 Cursor 能和你用到的每一个工具都能配合工作。

还有一条来自 Lenny Rachitsky 的数据点，挺有意思的。他和普林斯顿 CS 学生聊天，发现 CS 专业报名人数在下滑。数据显示，2025 年全美 62% 的 CS 项目报告了入学人数下降，加州大学系统过去两年下降了 9%。更有意思的是，现有 CS 专业学生对自己专业选择的后悔程度，比人文专业学生还高。Lenny 说，这可能是暂时现象，但如果工程师需求反弹，现有工程师的价值会大幅提升。

最后一条，前 Dropbox CTO 分享了一个招聘观察：他们做了大约二十个工程师的一周试用面试，发现工作年限和 AI 工具适应能力之间几乎没有相关性。反而，个人网站、side project、明显热爱做东西的人，预测成功率更高。名校和大厂背景几乎没有预测力。这个观察被 Peter Yang 总结成一句话：side projects 大于学历。


好，今天就到这里。

今天如果只记一件事，我会记 Karpathy 那句"Intelligence brownouts"。不是因为它听起来酷，而是因为它描述了一个正在发生的结构性变化：AI 正在从工具变成基础设施，而我们大多数人还没有认真想过，当这个基础设施不稳定时，我们该怎么办。
