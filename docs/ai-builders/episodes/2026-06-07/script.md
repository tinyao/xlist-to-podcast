模型路由正在成为企业 AI 成本的核心战场。为什么说即使代码是最容易被 AI 自动化的领域，工程师依然不会消失？Replit 的 Shopify 集成，对独立开发者意味着什么？先从最让 CTO 睡不着的那件事开始。

AI 模型之间的定价鸿沟，正在倒逼整个行业重新思考怎么用模型。Box 的 CEO Aaron Levie 昨天在 X 上说，token 成本已经成了他接触的每家企业最关心的话题。这不是焦虑，恰恰说明 AI 正在被大规模地、实实在在地用起来。

事情的起因是投资人 Chamath Palihapitiya 算了一笔账。他对比了目前几大主流模型的价格：如果一家公司每月消耗 10 亿输入 token 和 10 亿输出 token，用 GPT-5.5 Pro 要花大概 10.5 万美元。而换成 DeepSeek R1，只需要 2740 美元。能力差距在缩小，但价格差了将近 40 倍。

Aaron Levie 把这个话题往前推了一步。他说，这催生了一个新的差异化方向，叫模型路由。未来，应用层需要知道在什么任务上用什么模型最划算。比如文档提取，你得清楚哪个模型处理哪种文档格式效果最好。法律分析、金融分析，同理。

前 Google Gemini 产品负责人 Madhu Guru 也提供了一个观察视角。他总结了过去两年企业用模型的三阶段演变。2024 年是默认用最火的模型。2025 年初开始过度优化，拼命找最便宜的模型，但评估体系跟不上，反而拖慢了速度。到了现在，最聪明的 AI 原生公司已经进入第三阶段：把产品拆成子任务，最难推理的交给 Claude，最简单的交给开源模型。

这对听众意味着什么？如果你在创业公司或负责产品，现在就该建立自己的模型评估体系。不用大而全，针对你产品里最核心的三到五个任务，跑通质量与成本的平衡点。另外，如果你用的是昂贵模型，花一个下午审计一下 token 用量。你的团队可能还在默认跑最贵的那个。

说到成本，Mythos 这个新模型的定价也在圈子里传了一夜。Riley Brown 提到，Mythos 能一次性端到端生成全栈移动应用，甚至直接提交到 App Store。但价格是 Opus 的 5 倍，跑一次大概要 120 到 400 美元。Riley 很好奇，这么贵的模型，在 Claude Code 和 Claude Desktop 上会有多少人真的去用。

另一边，模型能力在飞涨，但人的角色没有消失。Aaron Levie 昨天还回应了一个观点，他指出了一个反直觉的事实：写代码几乎是 AI 自动化里最理想、最完美的场景。训练数据海量，用户高度技术化，结果可以直接测试验证。代码写得烂，应用照样能跑。即便如此，我们依然需要人类工程师去监督 agent。

他的结论是，如果在这个最理想场景里，工程师的需求依然很高，那其他脑力工作受到的冲击，可能比人们想的要小。agent 会让一个人能干更多事，但人不会消失。

先把节奏放慢一点，说一下今天最值得想清楚的一件事。

Replit 的 CEO Amjad Masad 昨天转发了一个用户的真实案例。这位用户用了 25 年 Salesforce，付了大概 50 万美元。然后他花了两周时间，用 Replit 自己写了一个 CRM 系统。线索、客户、合同、项目管理、AI 自动外呼、网站、社交媒体发帖，全有了。成本降到了每月不到 50 美元。

Amjad 说他几乎每天都能听到类似的版本。这不是孤例。同一天，Replit 宣布了和 Shopify 的集成。现在 vibe coder 可以在大概 10 分钟内，通过 AI agent 搭出一个完整的电商店面。

Lenny 昨天在 X 上引用了 levelsio 的一个观点，说现在人人都能写应用了，但几乎没人有分发渠道。要么没受众，要么没预算投广告，要么缺那种靠创意免费获取流量的能力。Lenny 自己的总结很干脆：分发成了新的护城河。

这其实和 Replit 的 Shopify 集成连起来看特别有意思。过去，独立开发者最大的瓶颈是技术实现。现在这个瓶颈在快速消失。Replit 直接把商业化的路也铺好了，搭完应用，一键接上支付和店面。但问题也变了。当所有人都能造船，海上的船就太多了。怎么让别人看到你的船，才是最值钱的能力。

对听众来说，如果你正在用 Replit 或类似的 vibe coding 工具做产品，可以开始把精力从“怎么实现”往“怎么让人知道”倾斜。哪怕只是提前在 X 上记录开发过程，积累最初的几百个关注者。产品上线那天，最怕的不是有 bug，是没人来。

再说几条快讯。

swyx 昨天分享了一个很聪明的 prompt 技巧。与其总是用 plan mode，不如把任务写成问句。哪怕只是在指令末尾加一个问号，模型就更可能提出质疑、给出替代方案，而不是盲目执行你说的字面意思。他说，你说的往往不是你真正想要的。

OpenAI 的 Logan Kilpatrick 提出了一个挺激进的想法。他说，顶级风投机构完全应该组建自己的模型评估团队，通过深度基准测试来发现投资机会。找到能力过剩的地方，或者模型特别不擅长的领域，然后追踪演进轨迹。他甚至认为，顶级机构迟早都会这么做。

Hermes Desktop 的教程昨天在圈子里传得很多。Greg Isenberg 发布了一个 43 分钟的视频，从头讲怎么用 Hermes agent 做 session 管理、省钱、甚至赚钱。他引用 Alex Finn 的话说，Hermes 正在超越 OpenClaw。如果你周末想试个新工具，这个值得看看。

郭宇昨天提到，Codex 的额度恢复正常后，他 20 倍的 Pro 账户终于被用完了。他还分享了一个观察，说 LM Studio 新出的本地应用挺好用，但不支持通过 API 做 remote tool use。他折腾了一圈，发现还不如在 Windows 上直接用 Codex 来操作本地的 LM Studio 方便。

如果你在用自己的 agent 跑任务，这周末可以试试 swyx 那个问号技巧。效果可能比你想的好。
