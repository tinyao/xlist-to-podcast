新加坡的内阁部长 Vivian Bala 在 AI Engineer 大会上公开了自己的 agent 工作流。
swyx 昨天在现场发了两条推文，语气里全是震惊。
他说这是大会历史上第一次有内阁部长上台。
不是来致辞，而是作为一个 NanoClaw 的重度用户，分享技术栈。

Vivian 展示了他怎么用 agent 处理外交政策和议会事务。
具体做法包括：hack WhatsApp 接口来收发信息。
用 SQLite 做图记忆，让 agent 记住对话上下文。

这件事的冲击力在于，它把 agent 从"帮工程师写代码"直接拉到了"协助国家治理"的层面。
如果你在思考 agent 的严肃应用场景，Vivian 这套在 WhatsApp 和 SQLite 上搭建的轻量方案，比任何企业级白皮书都更有说服力。

另一件值得说的事。
旧金山 AI 圈的心理状态正在变成一场公开讨论。
Deedy 发了一条长推文，描述他看到的分裂景象。
过去五年，大概一万人——分布在 Anthropic、OpenAI、xAI、Nvidia、Meta 和一些创业公司——积累了超过两千万美元的退休财富。
而圈子外的所有人，即使拿着不错的薪水，也觉得自己一辈子都追不上。

Deedy 描述了四种人的状态。
年轻人觉得爬公司阶梯是走错了楼，整天在想该不该创业、该不该挤进头部 AI 公司。
中层管理者最焦虑，有家庭、没精力创业、也没 AI 技能，眼睁睁看着中层被掏空。
而那些已经财务自由的人也不快乐。
有人从年薪十五万跳到五千万，人生计划全被打乱。
有人创业只是为了刷存在感，因为卖掉公司之后"就只剩钱了"。

这条推文在圈子里传了一夜。
Lenny 转发了，只说了三个词：太准确了。
Peter Yang 也转发了，给了一个很具体的建议。
他说如果你被困在湾区这场心理内耗里，去其他地方走走。
去欧洲小镇或者亚洲待一段时间，你会发现人生可以不只是 IC7 还是 IC8、在哪家公司打工。
他写了句很重的话：别让你的墓志铭变成"他离了婚、忽视了孩子，但至少他在 FAANG 升到了 D2"。

Google 的 PM 负责人 Madhu Guru 也加入了讨论。
他的视角更向内。
他说自己有朋友赚了上千万但很痛苦，也有朋友赚了同样多但找到了平静。
还有一些朋友赚得少得多，但就是开心。
他的核心判断是：满足感跟银行账户没关系。
硅谷把野心和幸福当成互斥的——好像想要更多就意味着不能享受当下。
他说这是个陷阱，你可以两者都要。

而 Zara Zhang 给这场讨论加了一个更贴近日常的注脚。
她说 AI 圈的人每天都在两种精神状态之间循环。
用完 coding agent 之后：天哪我无所不能，这辈子没这么强大过。
刷完 X 之后：天哪我完全落后了，所有人都跑在前面，我要被甩下去了。
她把这种状态叫做 AI psychosis——AI 精神病。

Felix Lee 的观察更简洁。
他说在旧金山，没有什么比"觉得自己已经太晚进入 AI"更让年轻人焦虑的事了。

如果你也在经历这种循环，Madhu 和 Peter Yang 的两条推文放在一起读，是一个挺完整的解药。
Madhu 说向内看——你到底需要多少才够？
Peter Yang 说向外走——离开这个圈子，看看其他活法。
这两件事都不需要任何技术门槛。

换个方向。
OpenClaw 现在有了"无限记忆"。
Peter Steinberger 昨天转发了一条推文，介绍了一个叫 Lossless 的概念。
简单说，它把对话压缩成一个个块，模型可以随时回溯。
这些块构成一棵树，agent 能在里面查找过去的任何消息。
效果相当于给 OpenClaw 装了一个无限大的上下文窗口。

Peter 的原话是：Lossless 是个非常有意思的概念。
发布这个功能的 Josh Lehman 说，新版本修复了重启时对话记录丢失的问题。
压缩方式也从增量缓存改成了全量整理，热提示缓存受到保护。
如果你在用 OpenClaw 跑长任务，这个更新意味着 agent 不会再"忘记"半小时前发生了什么。

同一时间，Peter 还在推 clawpatch。
他发了一条推文，让大家在自己的 repo 上试一下，让 Codex 找出你不知道存在的 bug。
clawpatch 上周刚发布，能把代码库拆成语义切片做自动审查。
而 Peter 昨天又转发了一条性能对比。
有人用 OpenClaw 和 Hermes Agent 跑同一个任务，都在本地用 Qwen 35B 模型。
OpenClaw 花了 12 分钟、用了 20 万 token，写了个 bash 脚本完成。
Hermes 花了 33 分钟、用了 25 万 token，写了个 SKILL.md 完成。
两个都成功交付了带增长曲线和事件标注的实时仪表盘。
但 OpenClaw 快了将近三倍，token 消耗也更少。

Peter 的回应很简单：看起来我们在性能上的专注有回报了。
如果你在选 agent 框架，这组本地模型的实测数据比任何 benchmark 都更有参考价值。

今天值得展开聊的，是这件事。

过去 24 小时，SF AI 圈的情绪讨论密度达到了一个少见的程度。
Deedy 那篇长文像一根火柴，点燃了很多人憋了很久的话。
但真正值得深聊的，不是焦虑本身，而是 Madhu Guru 和 Aaron Levie 各自给出的框架——它们指向了同一个方向，但路径完全不同。

先说 Madhu。
他在转发 Deedy 的推文时，没有跟着描述问题，而是直接给了一个内部视角的解法。
他说硅谷把野心和幸福当成互斥的。
好像你想要更多，就意味着你不能满足于现在。
这个逻辑的陷阱在于，它让你永远在追赶。
你赚到一千万，发现朋友赚了五千万。
你升到 IC7，发现隔壁组有人 IC8。
这个游戏没有终点。

Madhu 的解法是：你可以同时想要财富，也满足于当下。
不需要从匮乏和绝望出发去追逐。
这句话听起来像心灵鸡汤，但放在 Deedy 描述的那四种人身上，你会发现每一类都卡在同一个地方——他们把"现在"当成了"还不够"的证据。

而 Aaron Levie 昨天给出了另一个角度的框架。
他在讨论 forward deployed 工程师时，说了一段跟情绪无关、但逻辑相通的话。
他说 AI 和软件不一样。
软件交付的是一个稳定的产品，客户拿去用就完了。
AI 交付的是一个持续进化的东西。
模型在变、最佳实践在变、工作流在变。
这意味着你不可能靠"到达某个位置"来获得安全感。
不管你今天是 IC7 还是创始人，明天模型一更新，所有人的起跑线都会重新画。

把 Madhu 和 Aaron 放在一起，你会发现一个有意思的对照。
Madhu 说的是心态层：别把幸福寄托在"到达"上。
Aaron 说的是事实层：在 AI 时代，"到达"本身就不存在。
这两条线指向同一个结论：唯一可持续的策略，是在奔跑中找到节奏，而不是等着冲过某条终点线。

对听众来说，这个判断有一个很直接的启发。
如果你最近也在经历 Zara 说的那种 AI psychosis——用 agent 时觉得自己无所不能，刷 X 时觉得自己全面落后——试着问自己一个问题。
你焦虑的到底是能力不够，还是位置不对？
如果是能力不够，那是可以补的。
如果是位置不对——"我要是两年前加入 Anthropic 就好了"——那 Madhu 和 Aaron 的框架告诉你，这个游戏根本没有"对的位置"。
模型会变、工具会变、最佳实践会变。
唯一不会变的，是你每天坐下来、把一件事往前推一点的能力。

Riley Brown 昨天修正了自己之前的预测。他原来说到 2026 年底，你可以输入一个目标，agent 在 16 小时后把 App Store 前 50 名生产力应用全部复刻到你手机上。现在他把时间线提前到了 7 月底。如果你觉得这太夸张，别急——他昨天还发了 5 个 Codex 教程视频，从 28 分钟入门到 1 小时 44 分钟的完整指南，shownotes 里有链接。

Greg Isenberg 又发了一张大清单，这次是 36 个创业机会。从解决孤独感到 AI 原生媒体公司，从设备端 AI 打开受监管行业到宠物健康监测。其中有一条跟往期节目里聊过的 agent 偏好话题接上了：最大的基础设施机会是 agent 权限、安全和审计追踪。

Logan Kilpatrick 搬回湾区后只坐 Waymo，36 趟下来给了 10 分满分。他说真的感觉像活在未来。

你最近有没有在某个瞬间觉得"天哪我落后了"，然后又用 agent 做完一件事之后觉得"其实我也还行"？这种循环，你是怎么处理的？
