## 今日摘要

本期聚焦两个对工程师和产品设计师都高度相关的话题。swyx 分享了"杀死 Code Review"这一 agentic engineering 终极命题，多个团队已在探索全自动化开发流水线。Anthropic 设计负责人 Jenny Wen 则在 Lenny 的播客中详细拆解了 AI 时代设计工作的两种新模式，以及反直觉的招聘建议。两个话题共同指向一个核心问题：当 AI 接管执行层，人类的价值锚点在哪里？

## 重点话题

- Code Review 的终结：swyx 指出 agentic engineering 的"最终 Boss"已经到来，StrongDM 等公司已在跑无人审查的"Dark Factory"开发模式，PR 数量爆炸让人类 review 成为瓶颈
- AI 时代的设计工作：Anthropic 设计负责人 Jenny Wen 分享传统设计流程失效、工作分裂为两种模式、以及为何"cracked new grad"是当下最被低估的招聘对象
