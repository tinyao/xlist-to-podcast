今天是2026年3月3日，欢迎收听 AI Builders Daily。今天我们要聊三件事：Claude Code 迎来一波大更新、OpenClaw 社区爆炸式增长背后的故事，还有一个17岁少年用AI把应用卖给 MyFitnessPal 的励志案例。我们开始吧。


先说说过去这一周 Anthropic 到底在忙什么。

Alex Albert，Claude 的关系负责人，昨天发了一条推，开头就说——"鉴于上周发生的一切，大家很容易错过我们其实还发布了一堆东西。"他说的"上周发生的一切"，指的是 Claude 冲上 App Store 榜首、服务器被打爆、注册量破纪录，连特朗普和 Katy Perry 都在发推提到他们。

但就在这片混乱里，Anthropic 其实悄悄塞进来了不少更新。

先说最让人眼前一亮的：Claude Code 上线了语音模式。负责 Claude Code 的工程师 Thariq 宣布，语音输入正在向用户逐步推送，目前大约5%的用户已经可以用了。使用方式非常简单——按住空格说话，松开就发送。转录内容会直接流式插入到你光标所在的位置。这意味着你可以打一半提示词，切换成说话把中间那段说完，再接着打，完全是混合输入。而且 Thariq 特别强调，语音 token 不计入你的使用限额，Pro、Max、Team、Enterprise 用户都可以用，不额外收费。

郭宇在推特上看到这个消息，第一反应是——"我买的一年 Typeless 会员算什么？"这个反应挺能说明问题的，AI 原生工具的迭代速度，已经快到让你上个月买的订阅都可能变成"冤大头"。

除了语音，还有几个更新值得关注。Claude Code 新增了两个技能：slash simplify 和 slash batch。前者帮你把 PR 从开发推到生产，后者用来做可并行的代码迁移任务。还有一个 Auto-memory 功能，Claude 现在可以跨会话记住你的项目背景、调试偏好、常用模式，不需要你每次重新解释。另外，Remote Control 功能让你可以在终端启动任务，然后在手机上继续监控和控制，Claude 在你的机器上继续跑。

Cowork 那边也没闲着，加入了定时任务功能，可以让 Claude 在指定时间自动完成重复性工作，比如每天早上生成简报、每周更新表格、每周五准备团队汇报。

有一个数据特别能说明 Claude Code 的渗透程度。Anthropic 的 cat 发了一个企业案例合集：Ramp 用 Claude Code 在30天内写了超过100万行代码，事故排查时间缩短80%；Rakuten 把上市周期从24天压缩到5天，缩短了79%；Brex 在特定任务上实现了3到4倍的效率提升，而且非技术团队的人也开始自己写代码；Wiz 用一天时间完成了原本预计需要2到3个月的5万行代码库迁移；Shopify 的采用范围扩展到了全公司，不只是工程师；Spotify 最好的工程师们，现在的工作变成了"监督 Claude Code"，而不是自己写代码。

这最后一条值得多停一秒——Spotify 的顶级工程师在做的事，是监督 AI，而不是写代码。这不是某个创业公司的实验，这是一家拥有几千名工程师的上市公司在财报里披露的信息。

Peter Yang 说了一句很有意思的话——"Claude 宕机可能会让整体白领生产力下降20%。"这个数字当然是个玩笑，但玩笑背后的逻辑已经不是玩笑了。当一个 AI 工具的依赖程度高到这种地步，它的可靠性就不再只是产品问题，而是基础设施问题。


好，我们来聊第二个话题：OpenClaw。

如果你这几天没有刷推特，可能不知道 OpenClaw 是什么。简单说，它是一个开源的 AI agent 执行框架，由 Peter Steinberger 主导，绰号"螃蟹爸爸"。

就在昨天，他发布了一个新的 beta 版本，然后社区直接炸了。Lenny Rachitsky 转发并评论说：全球已经有超过80场 OpenClaw 线下 meetup 排进了日程，还在不断增加，而这个项目上线才不到几个月。他说，"我从来没见过这种事。有什么非常特别的东西正在发生。"

能让 Lenny 说出这种话，是有分量的。他是硅谷最受信任的产品和增长分析师之一。

而且 OpenClaw 这两天还出了一个小插曲，挺值得聊。Peter 发现有用户直接复制别人的 PR 然后提交，被他直接封号了。他补充说这个人来自加密圈，然后去更新了历史 changelog，把原始贡献者的名字加了回去。这个事情本身不大，但是社区的反应特别有意思——这条推获得了超过1400个赞，说明大家对"开源社区里的投机取巧"这件事，情绪是很强烈的。

Vercel CEO Guillermo Rauch 也宣布 Vercel 正式赞助 OpenClaw，配了一张三角形加螃蟹 emoji 的图，简洁但有力。

还有一个场景我觉得特别有画面感：在 Laracon EU 的现场，Taylor Otwell，也就是 Laravel 的创始人，在台上演讲的时候，OpenClaw 直接打电话给他，请他合并一个 PR。他在台上接了这个电话。现场直播的。Peter 说这是他见过的"最有胆量的 demo"。

把这些放在一起看，OpenClaw 不只是一个工具，它正在变成一个运动。开发者们在全球各地自发组织见面，这种能量是很难被复制的。


我们再来说一个稍微轻松点但同样值得关注的故事。

两个17岁的高中生，用 ChatGPT 自学写代码，做了一个叫 Cal AI 的卡路里追踪应用，18个月内做到了5000万美元年营收、1500万下载量，然后卖给了 MyFitnessPal。其中一个创始人卖出去的时候还在上学。

Greg Isenberg 分享了这个故事，他说这个故事"让人脑子转不过来"，因为它打破了你被灌输的那套剧本——要先拿学历，再融资，再去硅谷，再等时机。

他总结了三点：AI 消灭了技能借口，互联网消灭了地理借口，分发渠道取代了融资轮次。

我想在这里加一句自己的观察：这个故事真正的信号，不是"少年创业者很厉害"，而是"AI 把创业的起跑线拉平了"。当你可以用 AI 学会写代码、用 AI 生成营销内容、用 AI 做数据分析，那么以前需要一个完整团队才能做到的事，现在一两个人就够了。这不是励志故事，这是结构性的变化。


接下来是我们的快讯板块，几条值得知道的事，快速过一遍。

另外，Cognition 也就是 Windsurf 背后的公司，发布了 SWE-1.6 模型的早期预览。这个模型在 SWE-Bench Pro 上超越了顶级开源模型，推理速度达到每秒950个 token，差不多是无限制的 Opus 级别编码能力。swyx 的评论是，他之前觉得 Cognition 不该在自研模型上投入太多，但现在他的看法转变了——对于一个已经在政府客户里做到数十亿 ARR 的公司来说，自研模型是进攻，不是防守。

顺带一提，Vercel 出了一个比较大的基础设施更新，叫 Vercel Queues，本质是持久化的事件流服务。Guillermo 说它的 API 只有两个核心方法，极其简单但功能强大，可以作为更高层工具的底层，比如 Workflow 就是基于它构建的。同时他还宣布，AI agent 现在可以通过 Vercel CLI 自主发现并安装 Marketplace 集成，也就是说 agent 可以帮你"采购"第三方服务了。

快速说一条，Apple 正在和 Google 讨论让 Google 来托管新版 Siri 的可能性，因为 Apple 在云端 AI 能力上遇到了困难。Peter Steinberger 评论说"Apple 在这方面的挣扎一如既往"。如果这件事是真的，那 Apple 在 AI 时代的竞争力问题就不只是产品层面的了。

另外，swyx 最近在写一个关于"Agent Labs"的论文，核心观点是 Agent Labs 正在作为 Model Labs 的补充独立崛起。这个框架如果你在思考 AI 行业的结构，值得去找原文看看。

还有一条，Anthropic 的 Claude 设计负责人 Jenny Wen 接受了 Lenny Rachitsky 的播客采访，有几个观点值得记一下。她说传统的"发现-发散-收敛"设计流程已经死了，因为工程师用 AI 可以比设计师探索选项更快地把东西做出来。她还说，现在最被低估的招聘对象是"没有历史包袱的应届毕业生"，因为他们没有那些已经过时的流程习惯。她自己也从设计总监主动降回了 IC，她认为中层管理的未来是不确定的，她想在这个变化最快的时候保持亲手做事的状态。


好，今天最后说一句话总结。

这24小时里，我看到的最大信号是这个：Claude Code 被 Spotify 的顶级工程师用来做他们的日常工作，OpenClaw 在全球自发组织了80场线下聚会，一个17岁的孩子用 AI 做了一个5000万美元的公司。这些不是孤立的案例，它们指向同一件事——AI 工具已经不是"辅助"，它正在成为主干。
