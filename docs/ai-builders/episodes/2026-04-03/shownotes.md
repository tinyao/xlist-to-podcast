## 今日摘要

OpenAI 宣布收购科技播客 TBPN，Sam Altman 亲自表态节目形式不变；Karpathy 分享了用 LLM 构建个人知识库的完整方法论，Obsidian 创始人 kepano 接力提出"污染防控"分库策略；Google 同时发布 Gemma 4 开源模型和 Gemini API 弹性计费分层；Box 发布 Box Agent，整合企业文件系统与 AI 能力；Lenny 播客专访 Django 联合创始人 Simon Willison，深聊 coding agent 时代中级工程师的真实处境与三个应对 pattern。

## 重点话题

- **OpenAI 收购 TBPN**：科技实时直播节目被 OpenAI 收购，价格据报道为"低几亿美元"，节目形式和团队不变，引发圈内对"AI 时代什么内容有护城河"的讨论
- **Karpathy 的 LLM 知识库方法论**：用 LLM 把原始资料增量编译成 markdown wiki，以 Obsidian 为前端，实现可查询、可增强的个人知识库
- **kepano 的 vault 分离策略**：agent vault 与个人 vault 分开维护，防止 agent 生成内容污染个人知识图谱
- **Google 双发：Gemma 4 + Gemini API 弹性计费**：Gemma 4 有 26B MoE 和 31B Dense 两个规格，Apache 2.0 开源；Gemini API 新增 flex（降价 50%）和 priority（涨价 80%）两档
- **Box Agent 发布**：跨整个 Box 文件系统工作，保持企业安全控制，支持 API 和 MCP server 调用
- **Simon Willison 深聊 coding agent**（今日深聊）：中级工程师最先受冲击、red/green TDD / thin templates / hoarding 三个 pattern、AI Challenger 灾难隐患
