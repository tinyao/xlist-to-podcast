## 今日摘要
Moonshot AI 因需求激增暂停 Kimi K3 新用户订阅，并计划拆分为通用与代码两个独立会员计划。Claude Code 团队透露已将系统提示词削减 80%，因为新模型需要更少约束和更多自由发挥空间。Vercel 发布 AI Gateway，让开发者一次接入即可同时调用多个模型。本期深聊聚焦 AI 时代软件与设计的价值重塑：当构建本身变得廉价，品味、品牌和对现实约束的理解成为新的护城河。

## 重点话题
- Kimi K3 暂停新订阅：需求远超 GPU 容量，未来将拆分通用与代码会员计划，更精准匹配算力
- Claude Code 系统提示词削减 80%：模型越聪明，需要的指引越少，示例反而会限制其自由发挥
- Vercel AI Gateway 发布：统一 API 网关，让开发者“同时押注每一个模型”，自动路由最佳模型
- 深聊：AI 时代的护城河——当所有人都能构建相同产品，设计、个性与现实世界反馈成为真正的竞争维度
