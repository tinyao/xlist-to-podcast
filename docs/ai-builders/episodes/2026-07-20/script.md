Kimi K3 为什么突然暂停了新用户订阅？Claude Code 的系统提示词被砍掉 80%，这背后是一套什么样的新哲学？Vercel 的新产品为什么叫“同时押注每一个模型”？先从最让工程师睡不着的那件事开始。

Moonshot AI 昨天暂停了 Kimi K3 的新用户订阅，同时宣布要把会员体系拆成两个独立计划。
这件事的起因不是模型能力不行，而是太行了。Guillermo Rauch 昨天早上发了一条推文，引用 Kimi 官方的公告。公告里说，Kimi K3 在过去 48 小时内需求激增，已经逼近了现有 GPU 容量的极限。为了保护现有用户的体验，他们暂时停止接受新订阅，优先保障老用户的算力。
公告还透露了一个更长期的变化：未来 Kimi 会把会员拆成两个版本。一个是通用会员，覆盖网页、App 和工作场景。另一个是 Kimi Code 会员，专门服务编程工作流。这么做的目的是更精准地匹配算力资源，保持服务稳定。
Box 的 CEO Aaron Levie 看到这条公告后，发了一段很精炼的评论。他说，很多人误以为 AI 成本下降，总支出就会跟着降。实际上恰恰相反。当你把 AI 变便宜，它就会被消耗得更多。因为现在你可以用它来处理更广泛的任务了。写更多代码，审查更多代码的安全漏洞，在以前处理不了的大数据集上跑 agent。所以，任何降低 token 成本的事情，都会进一步推高推理需求。
Guillermo 昨天也单独发了一条，说 Kimi K3 在网络安全这个领域是顶级的。他提到 X 上有人在质疑 Moonshot 是否针对基准测试做了过度拟合，但他强调他们跑的是非公开的隐蔽评估，模型展现的是真正的推理能力。如果你正在用 Kimi K3，暂时不受影响。但如果你在考虑做 coding 相关的重度集成，可以留意一下他们后续的 Code 会员计划。

另一件值得说的事。Claude Code 的系统提示词被砍掉了 80%。
这个细节是 Anthropic 负责 Claude Code 的 Thariq 在 Peter Yang 的播客里透露的。Thariq 解释说，随着模型越来越聪明，它们需要更少的方向指引、更少的约束、也更少的示例。那些示例反而会限制模型，因为它会觉得“哦，你想要的是类似这样的东西”。把示例拿掉，模型反而能更自由地发挥。
他给了一个很具体的建议：每次新模型发布，你都应该主动去修剪你的上下文。最新的模型往往需要更多空间来自己跑。Thariq 昨天也发推说，他正在写一篇更详细的文章，讲他们从这个过程里学到了什么，以及你怎么把这些方法应用到自己的技能和系统提示词上。
Peter Yang 这条采访视频在圈子里传了一夜，很多人在等 Thariq 的后续文章。如果你现在还在给 Claude 4 级别的模型塞大段示例和详细指令，今天可以试试反着来。把提示词精简一半，看看效果是变好还是变差。

换个方向。Vercel 的 AI Gateway 产品昨天正式亮相，Guillermo 给它的定位是“同时押注每一个模型”。
这个产品本质上是一个统一的 API 网关，让开发者可以一次接入，同时调用多个不同厂商的模型。Guillermo 发了一张架构图，核心逻辑是不要把应用绑死在单一模型上。通过网关层做路由和 fallback，哪个模型当前表现最好、成本最低，就自动切过去。
对开发者来说，这解决了一个很实际的痛点。现在前沿模型的排行榜几乎每周都在变，Kimi K3 在网络安全上强，Sol 在深度分析上强但贵七倍，GPT 5.6 综合最强但成本也高。AI Gateway 让你不用在每个模型发布后都改一遍代码。如果你正在维护一个多模型调用的产品，这个方向值得关注。

先把节奏放慢一点，说一下今天最值得想清楚的一件事。

今天 X 上有几条看似不相关的推文，但放在一起看，指向了同一个问题：当 AI 让构建本身变得廉价，什么才是真正的护城河？
起因是 Greg Isenberg 昨天发的一条推文。他说，当一切都开始看起来像同样的 AI 垃圾，一点点个性就能走很远。他会被那些感觉像手工制作的东西吸引。一个有趣的落地页，一个古怪的复古 App，一个有自己声音的产品。很明显，是一个真实的人做的，并且做的时候很开心。这种感觉正在变得稀有，而这恰恰是它值钱的原因。
Greg 接着说，他注意到自己设计公司的设计冲刺和品牌需求最近明显在增加。一开始他以为是偶然，后来他想明白了。当所有人都能用同样的 AI 构建同样的产品，唯一剩下的竞争维度就是它看起来和感觉起来怎么样。对塑造个性和品牌的需求正在激增。
Aaron Levie 昨天也发了一条长文，从另一个角度呼应了这个观察。他说，AI 驱动的进步最终会被它与真实世界的交互速度所限制。写代码之所以被采纳得这么快，是因为你可以在电脑上写几乎无限的代码、测试它、运行它，而且不需要外部世界的任何人改变任何行为，就能端到端地产生价值。但药物研发不行，新药最终需要多年测试。做销售也不行，需要和潜在客户反复沟通。甚至签合同也不行，需要对方也参与谈判。现实世界的反馈循环，才是真正的限速步。
Zara Zhang 昨天早上也发了一条推文，说我们需要习惯一个观念：代码和软件现在可以是可抛弃的。她举了几个例子：临时搭一个设计 playground 来微调 UI 的观感，生成一个 HTML 页面来帮你理解代码，或者快速做一个一次性 dashboard 来查某个数据。用完就扔。
这三条线串在一起，其实在说同一件事。AI 让“做出来”变得极其便宜，但“做好”和“做对”的门槛反而更高了。因为当功能层面大家都拉不开差距，品味、品牌、对真实世界约束的理解，这些软性的东西就变成了硬通货。
对听众来说，这个观察可以落到一个很具体的行动上。在你下一个项目里，试着花 20% 的时间只打磨一个细节。一个交互、一句文案、一个错误提示的语气。看看用户会不会注意到。

再说几条快讯。
a16z 的 Justine Moore 昨天发现了一个完全由 AI 生成的虚假产品骗局。一个叫“float bro”的产品，AI 生成的视频在 Instagram 上拿到数百万播放，现在这些账号甚至链接到了真实的 Shopify 商店，可以走完完整结账流程。Justine 还发现连所谓的“评测”视频都是 AI 生成的语音在滚动网页。

Peter Yang 和他八岁的女儿用 ChatGPT Sites 搭了一个乘法学习游戏，叫 Serena's Safari Math。整个 UI 和角色用 ChatGPT Images 生成，还加了音乐和计时 Boss 关卡。这是 ChatGPT Sites 在教育场景里一个很完整的用例。

Zara Zhang 建议每个人都应该建立自己的“个人评估集”。就是几个跟你日常工作真正相关的任务，用它们来测模型，而不是只看行业基准。她说，你只有通过亲自戳它、撞到它的能力边界，才能真正找到哪个模型对你有用。如果你还没建自己的评估集，这周可以开始记一下你最常让 AI 做的三件事。
