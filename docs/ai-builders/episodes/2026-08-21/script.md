NVIDIA 花 60 亿美元买下了一个模型工厂，但创始人没跟过去，为什么？Anthropic 给企业级模型加了一把数据锁，这把锁的钥匙在谁手里？Replit 把 GPT-5.6 Luna 免费开放了，这对 AI 编程意味着什么？先从最贵的那笔交易说起。

NVIDIA 以 60 亿美元收购了 Poolside 的模型工厂。这笔交易的结构很有意思——NVIDIA 买走的不是整个公司，而是 Poolside 的模型工厂部分，以及大量研究员。而 Poolside 的创始人团队选择留在原公司。

swyx 昨晚在 X 上确认了这个消息。他说自己刚和 Poolside 的 CEO Eiso Kant 录完播客，详细聊了这笔交易。一个关键细节是，Poolside 的模型工厂正在产出能击败 Thinky 的模型。swyx 的原话是“这不是夸张，去看数据”。

而创始人留守这件事，让 swyx 觉得很不寻常。他在猜测，Poolside 剩下的部分会不会转型成一家纯粹的算力提供商，也就是 NeoCloud。因为公告里完全没提到 PIC，也就是 Poolside 的基础设施公司。

这笔交易本质上是一场人才和技术的双重收割。NVIDIA 拿到了能打硬仗的模型团队，Poolside 则可能转向算力生意。如果你在关注 AI 基础设施层的博弈，这个案例值得盯紧后续动向。

另一件值得说的事。Anthropic 推出了 Fable 安全措施，让企业完全掌控自己的数据。Claude Code 团队的 Boris Cherny 和 Thariq 昨天都发了推文确认这个消息。

Fable 的核心是，企业可以在自己的基础设施上运行 Mythos 级别的模型，Anthropic 不保留任何数据。Boris 说他们已经和大约一百家公司一起开发了一段时间，计划在今年秋天更广泛地推出。

Thariq 的表述更直白——客户可以掌控数据存放在哪里、谁能访问。这是 Anthropic 在数据保留政策上的一次实质性让步。彭博社昨天也报道了这件事，说明这不只是产品更新，而是企业级 AI 部署的一个合规基础设施变化。

如果你所在的公司因为数据主权问题一直在观望 Mythos 级别的模型，Fable 上线后，这个障碍可能就没了。

换个方向。Replit 的免费模式正式上线了，搭载的是 OpenAI 的 GPT-5.6 Luna。Amjad Masad 昨天发了一段视频，讲了这个合作背后的故事。

他在推文里说，这次合作“早就该发生了”。在 Replit 进入 YC 之前，Paul Graham 就让 Sam Altman 去招募他们。Sam 本人也在视频里讲了他们第一次见面的故事。

更实际的是产品体验。Amjad 转发了一个用户的演示——在 Replit 免费模式下，六分钟内用 AI agent 建了一个有 200 个村民的中世纪小镇。每个村民都有名字、性格、工作和日常作息。Amjad 特别强调，免费模式的速度很快，用他的话说，“让编程重新变得有交互感了”。

这对开发者意味着什么？GPT-5.6 Luna 免费可用，加上 Replit 的 agent 能力，AI 编程的试错成本被压到了零。如果你还没试过，现在是一个不错的时机。

说到 AI 编程，Vercel 的 CEO Guillermo Rauch 昨天扔了一句话：我们正在构建 Agent 的 AWS。他是在转发 Vercel 容器注册表更新时说这话的。

具体进展是，Vercel CLI 现在可以管理容器注册表了，支持 Docker 构建和推送。Guillermo 说，Bun 1.4 也已经跑在 Vercel Functions 上了，支持 WebSocket、Next.js、Elysia 和 Hono。

而最让人印象深刻的，是 Guillermo 对 fx 这个原生 agent 的评价。fx 是一个用 Zig 编译的静态 ELF 二进制文件，只有 6.3MB，启动时间是 10 微秒。Guillermo 的原话是：“fx 可以在其他 agent 还没启动完之前就完成任务。”

他特别强调了一句话：快是一条单行道。AI 会让大部分基础设施变成原生优化的。如果你在做 agent 相关的开发，fx 这个项目值得关注——它的 WASM 版本比原生二进制还小，因为网络栈被委托给了 JS 运行时。

今天值得展开聊的，是这件事。

Box 的 CEO Aaron Levie 昨天发了一条长推文，讨论 AI 时代的专家和通才之争。他的核心观点很明确：到目前为止，专家占上风，而且这个趋势不会慢下来。

Levie 的逻辑是这样的。AI 让任何任务的入门门槛降低了十倍——编程、法律工作、研究、财务分析，都是如此。但真正拉开差距的，是判断力。你要知道怎么把 agent 引导到正确的工作上，怎么让它纠偏，怎么审查和测试输出，怎么判断什么是“好”——这些都需要很高的技能。

他的原话是：“AI 会成为一种加剧技能差异的技术，因为专家获得了前所未有的杠杆。”所以他的建议是：不要放弃成为某个领域的专家。

这个观点跟前天 Uncle Bob Martin 的一条推文形成了呼应。Uncle Bob 说，他花了很多精力去“驾驭”这些 agent，虽然不用看代码，但所有的软件工程和问题解决技能都被调动起来了。Levie 正是引用了这条推文展开的讨论。

而另一边，Greg Isenberg 昨天连发了几条推文，其中一条是“vibe coding 现在就是 coding”。这句话在圈子里传了一夜。他的另一条推文是“2008 到 2025 年，人们说‘有个 app 能做这个’，2026 年开始，人们会说‘有个 agent 能做这个’。”

这两条放在一起看，你会发现一个有趣的张力。一边是 vibe coding 让编程越来越像自然语言对话，另一边是专家在用判断力把 agent 变成自己的十倍杠杆。入门越来越容易，精通越来越难。

Peter Yang 昨天也提供了一个佐证。他问 ChatGPT Codex 团队，一个 200 多页的对话线程会不会降低模型性能。这个问题本身就说明，重度用户已经在跟 agent 进行深度协作，而这种协作的质量，取决于你问问题的能力。

对听众来说，这个讨论的启发很具体。如果你在带团队，现在更应该鼓励成员在一个方向上深耕，而不是变成什么都懂的 AI 通才。因为 AI 已经把“什么都懂”这件事自动化了，但“知道什么值得做”这件事，反而变得更贵了。你怎么看这个趋势？你觉得自己正在变成专家还是通才？

再说几条快讯。

Greg Isenberg 断言“vibe coding 现在就是 coding”。他说 2008 到 2025 年是“有个 app 能做这个”的时代，2026 年开始是“有个 agent 能做这个”。

Lenny Rachitsky 的 Lennybot 上线了 Grok 版本。用户最常问的问题包括怎么找到前一千个用户、怎么晋升、怎么提供困难反馈。Lenny 说这可能很快成为消费他内容的最佳方式。

Meta 的 AI 高级总监 Madhu Guru 分享了 eval 失败模式分类法。他强调“坏答案”不是有用的分类，必须精确到“检索了错误文档”还是“正确文档但无关段落”，然后才能建立改进飞轮。

Justine Moore 收集了 400 多份陌生人关于 AI 的手写秘密。她的发现是，很多人用 AI 来更好地理解和沟通身边的人。她认为，矛盾的是，AI 会帮助人类发展出更多的共情能力。

最后，fx 这个 6.3MB 的原生 agent 值得你花十分钟去试试。启动时间 10 微秒，Guillermo 说它比其他 agent 启动还快就能完成任务。如果你在找轻量级的 coding agent，fx.sh 可以直接在线体验。
