## 今日摘要
本周二，AI 编程工具和 agent 工作流迎来密集更新。Cursor 发布了全新的 Composer 2.5 模型，Riley Brown 在半年后重新评估了它的设计能力。Vercel 推出了面向 agent 的防火墙 CLI 命令。但今天的核心信号来自 Anthropic 的 Thariq：一条关于让 agent 在执行过程中主动维护"决策笔记"的提示词，正在重新定义人与 agent 的协作边界。

## 重点话题
- **Agent 的"决策笔记"工作流**：Thariq 分享的提示词要求 agent 在执行任务时维护 implementation-notes.html，记录决策、偏离和待确认项。这解决了 agent 长任务中最大的痛点——人在环的信息断层。
