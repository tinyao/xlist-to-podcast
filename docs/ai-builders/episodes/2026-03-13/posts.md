  之前介绍过我的开源项目 Sandbank，一套统一的沙箱 SDK，解决的是运行 Agent Matrix 时要面对一堆不同供应商、不同 API、不同概念的问题。今天介绍它的云服务：Sandbank Cloud。
  
  本地和线上，终于是同一套东西了。
  
  做 Agent Matrix 开发最头疼的一件事：本地调试时用一套环境，部署上线又要对接另一套。接口不一样，行为不一样，甚至概念都不一样。Sandbank 从一开始就在做这件事：统一接口，换个 adapter 就切环境。
  
  Sandbank Cloud 补上了最后一环。本地用 boxlite 在自己机器上起虚拟机跑通逻辑，上线时切到 Sandbank Cloud，只换一个 adapter，其他代码一行不动。不用重新对接 API，不用处理认证差异，不用重新构建镜像。开发和生产是同一套抽象，同一套行为。
  
  Cloud 跑的是真正的虚拟机，不是容器。
  
  每个沙箱是一台 KVM 虚拟机，内核级隔离，跑在东京机房的裸金属服务器上。预热池让冷启动压到亚秒级。默认镜像 codebox 基于 Ubuntu 24.04，预装了 Claude Code、Codex CLI、Node.js、Python、Go、Bun、ripgrep 等工具链，Agent 拿到就能干活。当然，也支持交互式沙箱，如果你想连上去写代码的话。
  
  支付用的是 x402 协议，不需要注册账号。一个沙箱 $0.02，包含 10 分钟使用时间。没有注册流程，没有信用卡，续费也是。2 vCPU / 1GB 内存 / 5GB 磁盘 / 10 分钟会话。
  
  把这个转告给你的 agent，比如 OpenClaw 龙虾，Agent 自己就能读文档、调 API、创建沙箱、执行命令。
