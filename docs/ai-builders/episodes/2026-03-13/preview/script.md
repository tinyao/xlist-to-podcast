今天是2026年3月13日，欢迎收听 AI Builders Daily。今天的关键词是：Replit 四亿美金进场、Perplexity 用一台 Mac mini 宣告"赛道结束"、还有 Karpathy 谈智能停电和可以 fork 的 AI 公司。内容很多，我们直接开始。

先说今天最重量级的消息：Replit。

Replit CEO Amjad Masad 昨晚官宣，公司以九十亿美元估值完成了四亿美元融资，投资方阵容相当豪华——机构有 a16z、YC、Coatue、Georgian，战略投资方包括 Databricks、Accenture、Okta，还有 Tether，以及名人投资人 Shaq 和 Jared Leto。这条推文拿到了六千多个点赞、五百多条回复，是今天互动量最高的推文之一。

但钱的事情只是配菜，主菜是同步发布的 Replit Agent 4。

Agent 4 的核心概念叫做"无限画布加并行 agent"。传统的 agent 工作方式是：你输入一个 prompt，然后等着它跑完，这个等待很影响心流。Amjad 说他最初做 Replit 就是因为觉得传统开发环境太慢——他喜欢 REPL 那种快速迭代的感觉。Agent 4 想把这种感觉带回来，只不过规模化了。

具体来说，你可以在一个画布上同时开十几个任务，让多个 agent 并行执行，同时你自己还在另一个区域做设计或者头脑风暴。开发者 Mark Mathson 展示了一个案例：他在两分钟内建了一个 PRD 生成器，自动生成了十三个任务，同时跑这些任务——以前需要三个小时顺序操作，现在差不多一小时搞定，而且十二个任务在后台跑的时候，他同时还在改 UI 设计。

更有意思的是，Agent 4 的输出不只是代码，还包括 slides、视频、动画——一个 prompt 可以生成整套产品素材。

然后是几个数字。Replit 说现在 85% 的财富五百强企业在使用他们的产品。Databricks CEO Ali Ghodsi 专门说了一件事：他们公司的五六千个非技术员工——市场、HR、财务——都在用 Replit 自己搭工具。这不是早期创业公司用的东西了。

swyx 的评论说得很到位：他说 Replit 是 Paul Graham 所说的"蟑螂型公司"——不管外面发生什么，它总能活下来、活得很好。从最初帮学生学编程，到今天做出比 Google 和微软都更完整的 AI 生产力套件，每次 Replit 的转型，回头看都显得理所当然，但每次都让人意想不到。

说完 Replit，再来说今天让中文 Twitter 圈最震动的一条消息，来自 Perplexity。

Perplexity 宣布了一个叫 Personal Computer 的产品。形态是：一台持续运行的 Mac mini，24 小时在线，本地处理你的数据，跨越文件、应用、历史会话，持续为你工作。不是云端的订阅服务，而是物理意义上跑在你桌上的机器。

郭宇转发这条消息，评论只有一句话："我宣布更好的 OpenClaw 赛道确实结束了。"这条推文拿到了五百五十个点赞和四百一十五个书签，是他今天互动遥遥领先的一条。

OpenClaw 这段时间在开发者圈热度很高，它是一个开源 AI agent 框架，让你在本地跑各种模型、完成复杂任务。Perplexity 的 Personal Computer 方向上是相似的——本地、持续、私密——但作为一个有完整产品、有强大品牌的商业公司直接入场，竞争压力确实不是一个等级。

"赛道结束"当然是情绪表达，开源生态不会因为一个商业产品进场就消失。但这个反应背后有一个更重要的信号：大家越来越相信，下一代 AI 助手的形态不是你偶尔打开的应用，而是持续运行在你设备上的基础设施。这个方向，现在已经有巨头在正式押注了。

我们来聊一聊 Karpathy。昨天我们聊过他的 autoresearch 项目，今天他有两条新动态。

第一条是个小插曲，但很有画面感。他说自己的 autoresearch 实验室在一次 OAuth 服务宕机时被"一锅端"——数据全清了，现在得重新想容灾和故障切换方案。他说了一句让我印象很深的话："智能停电将会很有趣——当前沿 AI 系统故障时，整个星球的智商都在同步下降。" Intelligence brownout，智能停电。

听起来有点夸张，但想想如果你的整个 agent 工作流、你的研究实验室、你的自动化流程，都依赖着同一个 AI 服务商——当那个服务商宕机时，你是不是真的会突然"变笨"？这是一个关于 AI 依赖和基础设施冗余的真实问题，不只是哲学。

第二条是一个更深的技术视角。Karpathy 说："人们的预期是 IDE 时代要结束了，但我觉得现实是：我们需要一个更大的 IDE。"

理由是：人类的编程层级在上升。以前你操作的基本单元是一个文件，现在是一个 agent，未来可能是一个 agent 组织。这仍然是编程，只是抽象层级不同了。

他还提了一个很有趣的观点：传统人类组织是不可 fork 的，你没办法 fork 微软或者谷歌。但 agent 组织理论上是可以 fork 的——因为它的结构可以被代码化、被复制、被修改。就像你 fork 一个 GitHub 仓库一样，未来你也许可以 fork 一个公司的运营逻辑。

他还说，现在 CEO 没办法实时"缩放看"公司内部每一个角落在发生什么，没有真正的透明度。但 agent 组织天然有这种可观测性。

Box CEO Aaron Levie 转发并补充说：现在的软件都是为人设计的，未来大部分工作将由 agent 完成，软件的核心功能会变成管理 agent——在 agent 方向跑偏时介入，给 agent 提供正确的上下文，把 agent 的工作整合进更大的工作流。

这几个观点放在一起，描述了一个正在发生的结构性转变：我们不再只是在用 AI 写代码，我们在用 AI 管理 AI，而 AI 在管理工作。层层嵌套，越来越深。

再来聊一个郭宇做的实验，我觉得这是今天技术含量最高的一条内容。

他用 wanman AI 跑了一个多 agent 公司模拟，目标是：在日本市场创建一家服务汽车用户的软件公司。跑了 200 个工作日循环，整个实验耗时大约五十分钟。

架构是：CEO 和 CTO 都用 Claude Opus 4.6，普通 worker agents 用 Qwen 3.5 35B 模型。

整个实验有几个关键节点值得具体说说。Loop 82 到 83，CTO 生成了一份一千一百七十五行、54 KB 的完整产品定义和技术架构文档。Loop 99，CEO agent 进入发散阶段，自主提出了三个市场假设：H1 是深耕日本独特的"车检"制度，H2 是和九万家整备工厂合作走 B2B2C，H3 是进入 LINE Mini App——LINE 在日本有九千五百万月活用户，是最主流的通讯工具。Loop 120，CTO 独立完成了一份 25 KB 的可行性评估，验证了 H3 并推荐采纳。Loop 192，整个技术架构被改写为"LINE Mini App First"。

但实验在 Loop 175 之后卡住了——有七个任务因为等待架构更新而一直被 block，最后没有完成。

这个实验给我印象最深的，不是它成功了多少，而是它卡住的方式——架构更新期间的"等待"造成了任务停滞，这和真实公司里的协作瓶颈几乎是一样的逻辑。CTO 在更新架构，开发者还没拿到新的 spec，所以什么都做不了。这是一个组织协调问题，不只是技术问题。

郭宇说，他几乎确信下个月不需要再亲自写任何代码了。这当然有夸张的成分，但作为一个在认真构建这些系统的人，他的判断值得认真对待。

快速说一条 Anthropic 的更新。Claude 的 Excel 和 PowerPoint 插件现在可以共享对话上下文——你同时打开这两个文件，Claude 可以从表格里拿数据更新到 deck 里，不需要重复解释。同时两个 add-in 也开始支持 Skills。Anthropic 的 Alex Albert 说，他觉得 Claude 在知识工作领域的演进路径，和去年 agentic coding 的轨迹非常像，预计接下来几个月依赖电子表格和 PPT 的整个行业会开始被改变。如果你想想有多少财务、咨询、产品的专业人士每天花在这两个工具上的时间，就能明白这个方向的体量。

好，接下来进入快讯。

OpenClaw 发布了一个新 beta，带来了两个神秘的隐藏模型：Hunter，号称一百万 context，Healer，免费。两者来自 OpenRouter，目前没有人知道底层是什么。同时这个版本修了一个比较严重的 bug——GPT 5.4 在 OpenClaw 里会"说完就停、不干活"，原因是 WebSocket 实现漏发了一个叫 phase 的新参数。Peter Steinberger 说还顺带修了 Kimi Moonshot 工具调用的问题。对每天在用 OpenClaw 的开发者来说，这是一个值得升级的版本。

另外，郭宇今天正式上线了他的第十个 vibe 项目：Sandbank Cloud，一个专门为 agent 设计的按需沙箱服务。特点是用真实 KVM 虚拟机，不是容器，内核级隔离，跑在东京裸金属服务器上，冷启动做到了亚秒级。支付方式很特别：用 x402 协议，USDC 支付，不需要注册账号，一个沙箱两分钱包含十分钟。他的定位是做全网第一个只给 agent 用的 sandbox 云，没有 web dashboard，agent 自己读文档调 API 就能创建沙箱。

顺带一提，Vercel 发布了 Chat SDK 的 WhatsApp adapter。npm install ai，创建一个 createWhatsAppAdapter，没有第三步。这让构建 WhatsApp agent 的门槛大幅降低。这条推文有一千多个点赞、将近七百个书签，说明开发者的需求就在那里。

Google Maps 宣布了过去十年最大的一次升级，内嵌 Gemini 的问答功能，支持个性化推荐，还有沉浸式导航。郭宇的评论让人会心一笑：他说原来地图导航时不能同时搜索，是故意留着做这个功能的。

Gemini API 今天上线了 spend caps，开发者可以给自己的 API 消费设置上限，控制不小心跑飞的账单，后续还会加邮件提醒。另外 Cursor 上线了 Marketplace，目前有三十多个插件，支持一键安装或者 /add-plugin 命令直接加——IDE 正在变成一个平台。

快速再说一条，OpenAI Codex 在面向开源项目免费开放 Pro 订阅，感兴趣的可以去 developers.openai.com/codex/community 看看，Peter Steinberger 说还有几个名额。
