Sam Altman 写了一篇他自己都不确定要不要发的博客，到底讲了什么？OpenClaw 和 Anthropic 的拉扯又升级了，这次是系统提示被随机拦截。Claude Code 推出了一个叫 ultraplan 的新模式，把计划搬到云端。先从最让独立开发者头疼的那件事说起。

OpenClaw 的用户昨晚发现，他们的 agent 开始随机报错，系统提示被 Anthropic 拦截了。OpenClaw 的创建者 Peter Steinberger 随后证实，Anthropic 的随机拦截器变得更奇怪了。他的账号一度被暂停，几小时后又恢复。但更麻烦的是，Anthropic 修改了第三方应用的配额规则——现在从额外用量扣，不再走套餐限额，并附赠了 100 美元信用额度。另一边，Peter Yang 说，没有哪个模型能像 Opus 那样适配 OpenClaw，而 Claude Code 作为个人助理总感觉不是“自己的”。如果你在用 OpenClaw 跑自动化，建议马上检查一下关键流程，看看有没有被静默阻断。

另一件值得说的事。Sam Altman 今天早上发了一篇新博客，他在推文里说自己天没亮就写了，犹豫再三才决定发出来。博客链接指向 blog.samaltman.com，目前内容还在被社区消化，没有太多细节流出。但 Altman 这种“不确定要不要发”的姿态本身就挺少见的。你会怎么解读这种犹豫？是内容太激进，还是太个人？

说到工具更新，Claude Code 推出了一个叫 ultraplan 的新命令，让 AI 在云端制定实施计划。Anthropic 的 Thariq 在 X 上演示了这个功能。你输入 /ultraplan，Claude 会读取你的代码库，在网页端生成一份可编辑的计划。你可以直接在网页上调整，然后选择在云端或终端执行。令牌消耗跟 plan 模式差不多。如果你经常在本地跑规划把终端占满，可以试试把计划阶段搬到云端。

换个方向。Replit 宣布与咨询巨头 Accenture 达成合作，要把 vibe coding 带进企业。Replit CEO Amjad Masad 公布了这一消息。Accenture 不仅投资了 Replit，还会在内部全面采用，并一起向全球企业客户推广安全的 AI 开发。Accenture 有超过 70 万员工，客户遍布所有经济领域。如果你在推动企业内部的 AI 开发工具落地，这次合作可能会成为一个参考模板。

今天值得展开聊的，是这件事。Andrej Karpathy 昨天发了一篇长文，分析为什么人们对 AI 能力的感知差距这么大。他把人群分成两类：一类用免费或旧模型，看到的是各种翻车；另一类花 200 美元月费用 Codex 或 Claude Code 做专业开发，看到的是模型在几小时内重构整个代码库。这两拨人完全在平行宇宙。

有多位圈内人给出了自己的视角。Raiza Martin，Huxe 的联合创始人，描述了她的日常工作流：设置好长期任务，跟编排器辩论完方案，就离开去干“人类的事”——聊天、设计、学雕塑。然后收到通知回来验收。她说这感觉既像乌托邦又像黑镜。Zara Zhang 补充说，要真正理解 AI 的能力，你必须成为 builder。用 AI 编程不只是为了效率，更是最好的学习方式。她提出“Learn to build, then build to learn”。

Box 的 CEO Aaron Levie 从企业视角分析，认为大多数用户还在用聊天工具，生产力提升有上限；但部署代理做长任务的人，能立刻获得一两倍的效率提升，而且没有上限。不过他也指出，企业落地还有合规、安全、上下文获取等一堆问题要解决。

如果你还没让代理独立完成过一个完整项目，可能真的低估了当前的能力。这个周末可以试一下：找一个你熟悉的小项目，把需求描述清楚，然后完全放手让 Codex 或 Claude Code 去实现。看看它能在多长时间内做到什么程度。你可能会被吓一跳。你上次被 AI 的能力震惊是什么时候？是惊喜还是惊吓？
