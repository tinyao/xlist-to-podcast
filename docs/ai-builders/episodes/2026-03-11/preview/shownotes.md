## 今日摘要
Claude Code 上线了 /btw 功能，让用户可以在 agent 工作时插入侧边问题而不打断任务，这背后揭示了 agent 时代"异步协作"交互范式的新方向。Nous Research 发布开源 agent Hermes Agent，Greg Isenberg 直接问它是否是下一个 OpenClaw，开源 agent 生态的竞争格局正在形成。GPT-5.4 疑似解决了 Epoch AI FrontierMath 题库中的首道开放数学难题，OpenAI VP Kevin Weil 公开转发并称"如果属实将是里程碑"。此外，Vercel AI SDK 周下载量破千万，但 agent 时代的产品分发逻辑还没有被重新定义。

## 重点话题
- Claude Code /btw 功能：agent 跑任务时可插入侧边问题，不打断工作流，揭示异步协作交互范式
- Hermes Agent vs OpenClaw：Nous Research 开源 agent 有持久记忆和专属机器访问，开源与闭源 agent 路线的分化
- GPT-5.4 解数学难题：疑似解决 FrontierMath 首道开放研究级数学题，形式化证明用 Lean 验证，结果待社区确认
- Vercel AI SDK 破千万周下载 + agent 时代产品分发困境：工具层成熟，但"给 agent 的产品"逻辑尚未建立
- Anthropic 工程博客：agentic coding eval 噪声问题，基础设施差异可导致 benchmark 结果偏差超过模型间差距
