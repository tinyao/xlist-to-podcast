GPT-Live 今天在 ChatGPT 里上线了。这是个新一代语音模型，Sam Altman 自己的评价是"很有魔力"、"很真实"。

Sam Altman 昨天说，他以前一直更喜欢打字而不是跟 AI 说话，现在他觉得这个习惯要变了。Greg Isenberg 在 X 上发了一句很直接的话——"2026 年是语音 agent 终于变好的一年"。

这个模型的具体能力，OpenAI CTO Justin Uberti 给了技术上的说明：GPT-Live 是全双工模型，内置异步委托机制。说人话就是，你在说话的时候，它可以同时在后台执行任务，比如搜网页、查数据，不用等你停下来。

Riley Brown 提前体验过了。他的描述是"几乎是吓人的逼真"，而且模型使用工具的能力很强，搜索速度非常快。他的判断是，再加一层生成式 UI，这个技术就基本上能做出贾维斯了。

如果你今天更新了 ChatGPT，可以试试它。这可能是语音交互真正变得像打字一样自然的一个转折点。

说到 GPT-Live，另一边还有个配套的消息。OpenAI 的 OpenClaw 团队——那个专门做 Mac 端桌面 agent 的——已经宣布对接了 GPT-Live。团队负责人 Peter Steinberger 发帖说，这就是你想跟你的"爪"说话的方式。OpenClaw 之前发布过 Nameplate 功能，可以在 agent 需要人类协助时弹出带上下文的提示，而不是一个冷冰冰的权限弹窗。

这意味着什么？以后你的桌面 agent 不仅能帮你点按钮，还能跟你语音对话，边帮你处理日程边问你需要什么。

GPT-5.6 周四就要发布了。Sam Altman 昨天官宣的时候，那条推文只写了两句话："GPT-5.6 sol 周四发布！祝你打造开心。"

Riley Brown 提前用了几周，说 Codex 平台因为 5.6 变得更加有趣了——好玩程度大约是之前的三倍，不止是编码，非编码任务也一样。有人问他前端做得怎么样，他回了三个字："更好了。"

Peter Steinberger 引用了一条其他人的评价，说 GPT-5.6 虽然未必比 Fable 更聪明，但它"特别可靠、特别好玩"，团队用的 token 量已经是之前的 5 倍。他还贴心地分享了一个小技巧：如果你跑的是 Sonnet 5 为主力、Fable 5 做顾问的工作流，可以让 Fable 把 Codex 指定成干活的模型，省 token。

坦白讲，这种"可靠 + 好玩"的组合，比单纯的高分基准更让人想一直用下去。你最近在用什么模型？有没有哪个让你想一直开着不关的？

另一件值得说的事。Cognition 昨天正式发布了 SWE-1.7，他们训练过的最强模型。分数跟最强前沿模型差几分，但成本只是一小部分。关键是速度——每秒一千个 token。

swyx 点出了一个容易被忽略的细节。大多数 agent 公司不愿意公开谈论用了中国模型，因为有政府或国防客户要照顾。Cognition 的做法是：自己建一套多语言的宣传和审查 eval，在后训练阶段专门修正，然后才能放心地、便宜地提供给客户。

这不仅是技术细节。它说明 agent 公司在模型选择上的实际挑战——不是用不用某个模型的问题，而是用了之后怎么让不同背景的客户都能放心。swyx 说"大多数 agent 公司都回避这个话题"，Cognition 是少数正面做这件事的。

昨天 Lenny Rachitsky 发布了他今年的第二份大规模调查，主题是科技从业者怎么感受 AI 对工作的影响。这次收了上万人数据，他把人群分成了四个原型，而且这个分类不是按职位、资历或公司大小来划的——核心问题是："AI 让你怎么看待自己？"

四个原型分别是：

第一种，充能派。占了 41%。这些人对 AI 是全盘拥抱的。91% 选了"兴奋"做自我介绍，83% 是"好奇"，59% 是"充满希望"。Lenny 说，这是唯一一个对自己的领域有正面评价的群体。原话是"产品工作又变得好玩了"。

第二种，挣扎派。这组最大，35%。核心情绪是"矛盾"——68% 的人说"我同时有正面和负面的感受"，好奇的占 64%，但疲惫和不知所措的也超过一半。他们不排斥 AI，只是被"跟上 AI"这件事搞得身心俱疲。

第三种，迷失派。12%。几乎所有人选了"我的角色一直在变"。74% 感到不知所措，73% 疲倦。他们不是拒绝用 AI，是工作的形状在底下变了，他们还没找到立足点。有个 VP 级产品负责人的原话是："我们就像工业革命前夕的农民，知道种地是对的，但看不清路。"

第四种，怨念派。也是 12%。100% 选了"有压力被逼着用 AI"，而且集体选择了"疲倦"和"矛盾"，乐观度最低。这群人不觉得 AI 在帮他们，反而觉得被挤压了。

最让我注意的是 Lenny 报告里的一个数字。科技从业者最怕的不是"被 AI 取代"——只有 22% 选了这一条。更多人怕的是"被期望干更多活"、"质量下降"、"被按在一个不可持续的节奏里"。

如果你现在觉得自己在第一个阵营里，当然很好。如果你在第二个甚至第三个阵营里，这个调查至少告诉你，你不是一个人，这也不是你的个人问题。它的根在于组织怎么引入 AI、怎么设预期、怎么分配人。

同一时间，Box 的 CEO Aaron Levie 说了一件相关的事。他跟几十位企业 IT 负责人聊 agent，发现企业现在最麻烦的问题不是技术，是组织。agent 最能发挥价值的地方往往跨部门，但大多数公司的部门是隔离的。谁来管一个跨部门的 agent？它怎么被部署、被推广、被接纳？这个问题没解之前，agent 再聪明也用不到点上。

Levie 还提到数据碎片化是另一个大坑。结构化数据和非结构化数据都没统一格式，agent 拿不到准确信息，输出的就不靠谱。而企业真正想做的，是把 AI-native 的流程变成公司自己的数据护城河——不是靠比别人更先进的模型，而是靠比别人更好的上下文。

最后他提到了一个很有意思的矛盾。企业在 AI 上想要的是商业成果，比如更多收入、更多产品发布。但商业成果本身很难量化成 token 数。所以大家都在找合适的指标，目前还没有标准答案。

这件事在 X 上传了快一天了，起因是 Anthropic 的一个异常客户 Abnormal Security 发了一篇博客。OpenClaw 的 Peter Steinberger 是 Anthropic 的大客户，他转发了其中一句原话："我们是 Anthropic 非常大的客户，他们到现在都没告诉我们那个诉讼。我是从记者那里知道的，不是从我们所谓的'合作伙伴'那里。"

事情的背景是 Anthropic 最近卷入了某个官司，细节没公布，但从 Abnormal 的措辞来看，客户关系上出了问题。Steinberger 的转发里没有加评论，只发了一个链接。但那条推文在圈子里被反复引用，讨论点是"模型再好，企业关系也得透明"。

Abnormal 的博客里有几个具体抱怨。第一，他们在诉讼消息公布后主动联系 Anthropic，对方没有第一时间给说法。第二，他们觉得作为大客户，应该有提前知情权，而不是从媒体上读到。

这件事让人联想到之前 Aaron Levie 说的 agent 信任问题。如果连大客户都担心合作方不透明，那 agent 在企业落地的最大障碍可能不是模型水平，而是信任机制。

这对你的启发是什么？如果你在跟模型供应商签企业合同，除了看指标和价格，问一句"你们的客户通知机制是怎么设计的"——这件事现在可以放到谈判优先级里了。
