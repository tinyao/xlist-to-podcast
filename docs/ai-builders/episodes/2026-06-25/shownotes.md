## 今日摘要
Notion 和 Cursor 宣布深度集成，让 coding agent 直接嵌入协作工具；Claude Tag 上线，AI 员工在 Slack 里有了自己的账号；Greg Isenberg 提出了"给 agent 开独立账号"的未来工作框架；Google 开除了那个给 Workspace 写 CLI 的工程师；GLM 5.2 Fast 版在 Vercel AI Gateway 独家上线；Figma Motion 发布，Databricks 联合创始人深度访谈，以及一个让人上瘾的劈柴模拟器。

## 重点话题
- **Notion × Cursor 深度绑定**：Notion 宣布 External Agents 功能，Claude 和 Cursor 可以像团队成员一样被 @ 提及并完成任务，同时 Cursor 编辑器内可直接访问 Notion 知识库。这打通了产品需求和代码实现之间的最后一层隔阂。
- **Claude Tag 与 AI 员工的未来**：Anthropic 给 Claude 在 Slack 里开了正式账号，Greg Isenberg 提出未来公司将像招聘员工一样"招聘" agent，并列出六大二阶效应，包括 agent 账号黑市、组织架构图里出现非人名字等。
- **Google Workspace CLI 事件**：开发者 Justin Poehnelt 因制作非官方 Google Workspace CLI 被 Google 开除，工具上线即爆火，Google 随后宣布将推出官方 CLI。

## 快讯
- Vercel CEO Guillermo Rauch 开了一个私密群组，专门收集对 eve agent 框架的高质量反馈。
- GLM 5.2 Fast 版在 Vercel AI Gateway 独家上线，内部 benchmark 显示 token 吞吐比别家快一倍。智谱今年一月已在香港上市。
- Databricks 联合创始人登上 Latent Space 播客，解释了为何在 agent 基础设施层下注，以及为何 Databricks 赢了 Snowflake。
- Figma 在 Config 大会上正式发布 Figma Motion，进军动效设计领域。
- CapCut 宣布举办 AI 电影节，总奖金 20 万美元。
- Anthropic 内容设计负责人 Chelsea Larson 在 Figma Config 分享 AI 产品的内容设计方法论。
- Justine Moore 分享了一个用 AI 渲染的劈柴模拟器，创作者 3D 扫描了自家木头并录制了真实劈柴动作。
