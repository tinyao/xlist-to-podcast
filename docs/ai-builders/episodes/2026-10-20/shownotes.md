## 今日摘要
Vercel 开源了 agent 基础设施 libfx，同时与 Shopify 的合作正式落地，让 agent 成为头等购物者。fal 和 Black Forest Labs 发布 FLUX 3 Max 视频模型，生成速度提升显著。Lenny 与 Anthropic 可解释性研究员 Emmanuel Ameisen 的深度对话揭示了模型内部工作机制的反直觉发现。此外，模型智能提升与用户增长脱钩的趋势引发讨论，swyx 强调数据工程师正变得比 AI 工程师更稀缺。

## 重点话题
- Vercel 开源 libfx：为 v0 构建的底层 agent 管道，让 agent 更“耐用”，已开源并免费提供。
- Vercel x Shopify 合作：Vercel Shop 模板 GA，agent 可通过 MCP 直接搜索产品和操作购物车。
- FLUX 3 Max 发布：fal 与 BFL 联合推出，10 秒生成 10 秒视频，速度比 Seedance 2.5 快 22 倍。
- 模型智能与使用量脱钩：The Information 报道，10 点智能优势现在仅带来 20% 流量增长，远低于去年的 69%。
- 模型可解释性深聊：Lenny 对话 Anthropic 研究员，揭示模型会提前规划、J-space 内外的思考差异，以及拟人化理解的实用性。
