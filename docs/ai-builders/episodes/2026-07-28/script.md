Vercel 发布了 DeepsecBench 基准，Grok 4.5 在网络安全漏洞发现上成了性价比之王。
Guillermo Rauch 昨天公布了最新结果。Grok 4.5 比 Sol 便宜 10 倍，比 Opus 5 便宜 5.7 倍，比 Kimi K3 便宜 2.2 倍。但它的得分接近 Kimi，稳稳挤进前十。
也就是说，用不到五分之一的成本，就能拿到接近顶级的检测能力。
如果你正在选安全扫描模型，Grok 4.5 可能是成本敏感场景的首选。Sol 依然是基准天花板，但预算有限的时候，这个选项挺香的。

另一件值得说的事。Kimi K3 现在通过 Vercel AI Gateway 在美国上线了，而且支持零数据保留。
Guillermo 和 Aaron Levie 都转发了这个消息。K3 是目前最强的开放权重模型，2.8 万亿 MoE 参数，100 万 token 上下文。现在你可以从美国境内的推理提供商调用它，同时启用 ZDR，确保 token 流量不回传。
这对有数据主权要求的团队来说，是个不小的进展。如果你在构建需要合规的应用，现在就可以去 Gateway 里把 `moonshotai/kimi-k3` 接进来，勾上 ZDR。

换个方向。前 Anthropic 员工爆了一个反直觉的料：黑客更喜欢用闭源订阅模型搞攻击，而不是开源模型。
Amjad Masad 引用了 Noah Lebovic 的帖子。Noah 之前在 Anthropic 工作，他说尽管 GLM 5.1 这类开源模型已经很强，但他认识的黑客圈子仍然在用 Claude Code 或 Codex 的订阅。因为绕过闭源模型的安全限制反而更容易，而且 Anthropic 和 OpenAI 的订阅有灰色市场代币，成本极低。
更让人不安的是，Noah 提到他亲眼见过 Anthropic 的销售人员以大额合同为前提，帮客户降低安全护栏。这直接挑战了“开源模型更危险”的主流叙事。你怎么看这种攻防格局的错位？

说到编译，Guillermo 还干了一件让工程师眼前一亮的事：他用 scriptc 把 Vercel CLI 编译成了原生二进制。
scriptc 是一个 TypeScript 到原生的编译器，不需要嵌入 V8 或 QuickJS，完全静态编译。Guillermo 拿它编译 Vercel CLI，结果二进制只有 1.28MB，启动开销平均 1.5 毫秒，整个编译过程只花了 2.94 秒。代码翻译靠的是 GLM 5.2 Fast。
他展示的视频里，CLI 部署丝滑得像原生 Go 程序。如果你在写 Node.js 工具又受不了冷启动，scriptc 这条路径值得放进待办清单。

先把节奏放慢一点，说一下今天最值得想清楚的一件事。
Lenny 昨天放出了和 Anthropic 产品研究负责人 Dianne Penn 的深度访谈，信息量巨大。Dianne 是 Anthropic 第一位技术 PM，从 Claude 2 一路跟到 Mythos。她分享的内部原则，几乎每一条都在挑战传统产品经理的工作方式。

她提了一个核心观点：Evals 就是新的 PRD。过去产品经理写需求文档描述要做什么，现在她团队的核心工件变成了 eval 集。每个重要功能，他们会生成 30 到 40 个代表性示例，编码成带黄金答案的 prompt。PRD 还在，但只用于跨团队对齐，真正的产品定义已经转移到模型能通过哪些测试。
这背后是 Dianne 说的“token maxing”——像过去死抠像素一样死抠 token。产品经理得去读 AI 的对话记录，诊断一次失败到底是幻觉、过度自信还是调错了工具。每种诊断对应不同的修复路径，而这正在变成 PM 的核心手艺。

她聊到的另一个转折点是“Golden Gate Claude”。2024 年初，团队发现模型内部有可调节的特征向量，比如对金门大桥的执念。他们花 24 小时搭了个体验站，虽然只触达了两千人，但让 Anthropic 找到了不同于别家的产品气质。Dianne 说，那是他们身份认同的隐藏转折点。
而推动这些实验的 Labs 团队，运作方式也很特别。他们专做 10 倍到 1000 倍的赌注，团队极小，有时只有一个工程师。赌输了就关掉，等一两代模型后再试。选人标准是创始人型——能把心掏出来赌，赌输了还能再来。

对听众来说，最直接的启发有三点。第一，如果你在带 AI 产品团队，现在就该把 eval 集当成主要交付物，而不是 PRD。第二，Dianne 强调管理者必须保持 hands-on，否则会失去对模型能力的直觉。她会给每个老手 PM 安排和新手一样的上手流程——读记录、聊用户。第三，她建议先形成自己的观点再用 Claude 对练，避免“AI 脑腐”。这比任何效率技巧都重要。
