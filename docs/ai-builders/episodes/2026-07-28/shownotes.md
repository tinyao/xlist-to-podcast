## 今日摘要
Vercel 发布 DeepsecBench 基准，Grok 4.5 以极致性价比成为网络安全检测黑马。Kimi K3 通过 Vercel AI Gateway 在美国上线并支持零数据保留。前 Anthropic 员工爆料黑客偏好使用闭源订阅模型攻击，挑战安全叙事。Guillermo Rauch 用 scriptc 将 Vercel CLI 编译为 1.28MB 原生二进制。Lenny 对 Anthropic 产品研究负责人 Dianne Penn 的深度访谈，揭示了 evals 作为新 PRD、token maxing 和 Labs 团队 10x 赌注等内部原则。

## 重点话题
- DeepsecBench 基准：Grok 4.5 在网络安全漏洞发现中性价比最高，成本仅为 Sol 的十分之一
- Kimi K3 上线：最强开放权重模型通过 Vercel AI Gateway 在美国可用，支持零数据保留
- 前 Anthropic 员工安全爆料：黑客偏爱闭源订阅模型，大额合同可降低安全护栏，挑战开源风险假设
- Lenny 访谈 Anthropic 产品负责人：evals 取代 PRD，产品经理需死抠 token，Labs 团队做 10x 赌注，以及避免 AI 脑腐的方法
