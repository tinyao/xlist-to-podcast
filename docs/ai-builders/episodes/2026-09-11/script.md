GPT-6 Astra 的电脑操控能力开始让资深开发者紧张了。
确切地说是兴奋到有点慌。
郭宇，就是那位早早退休、现在整天琢磨前沿技术的开发者，昨天在 X 上发了一条让大家有点坐不住的分享。

他让 GPT-6 Astra 连上达芬奇，就是那个专业影视调色剪辑软件。
没有写复杂的提示词，是一次性指令。
模型自己动手，把他 2020 年第一次去四季岛旅行的 4 个小时高清素材，剪成了 17 分半的 4K 成片。
自动加好了字幕，做完了调色。
他随后补了一句，这波操作直接花掉了 Codex 一周额度的 30%。

这是个什么概念？
这说明模型不仅会调用剪映或 CapCut 这类简单的 API，现在它能像一个真人剪辑师那样，在复杂到劝退普通人的专业软件里精准作业。
郭宇自己也感叹，时隔半年再次被语言模型震到。
他抛出了一个很尖锐的问题：如果电脑操作可以直接用所有专业软件，那谁还会用过去那些有些粗糙的微调产品呢？

顺着这个话题往里看，AI 内容创作者 Riley Brown 也观察到同样的变化。
他直言不讳地说，如果你是个开发者想做内容，现在就应该打开录屏软件，去录你如何用 GPT-6 写代码。
因为在 YouTube 上，大家对 Astra 的搜索热度和真正深度的技术视频之间存在巨大空白。
另一边，Greg Isenberg 则看到了更偏商业的爆发点。
他说 Astra 把两种创业门槛直接打下来了。
一种是帮人做外包然后转成软件服务，另一种是硬件实体产品的生意。
模型现在能跨浏览器、代码库、文档、Blender 还有物料清单来协作。
你只需要给一个想法，它能给你拉出 3D 草图、零件清单和供应商路径。
不用再先花两百万美金的启动资金。

不过，郭宇的担忧也说得很明白。
专业软件销量要大增，Token 消耗要大增，数据中心需求会更疯狂。
如果你现在的工作流还停留在让 AI 只聊天的层面，或许真的该去试试让它动手了。

接下来这段我们多说几句。
今天真正值得展开的，是一个看似不起眼、但正在冲击编程习惯的议题：代码复制的代价正在归零。

大概昨天晚上，OpenClaw 的创始人 Peter Steinberger 转发了一条推文。
推文内容很直白：复制逻辑不再让人痛苦，抽象依然痛苦。
他加了一句评价，说这非常有道理。

这直接点破了 AI 编码带来的一个深层行为改变。
以前我们写代码，讲的是要写一次、可复用、分层清晰。
重复逻辑是万恶之源，抽象是基本功。
但现在，当 Claude、GPT-6 这些模型让"复制一份、微调适配"变得几乎零成本时，坚持抽象反而成了某种负担。
代理可以直接为你生成 100 段看起来相似但各有说法的小函数。
你不用花精力去维护那个完美的底层库。

这个转变带来的冲击，在不同人眼里是完全不一样的。
Anthropic 的 Claude Code 开发者 Boris Cherny，今天给 Claude Code 上线了一个新功能。
diff 面板变成持久化存在，可以滚动、点击，实时更新。
这背后的潜台词是什么？就是让你别切屏，完全沉浸在 AI 助手中。
如果你接受 AI 来管理这些复杂又相似的代码块，一个极致优雅的代码浏览界面就成了必须品。
而 Box 的 CEO Aaron Levie 则把这提升到了产业高度。
他说世界会用上远超我们预想的编码代理。
软件生产成本在下降，结果是用量暴增。
我们是在保护老旧系统、做生命科学研究、处理海量复杂数据。
这反而需要更多的工程师，不是更少。

Adam，也就是 Replit 的 CEO Adam Masad，在昨晚的一个播客访谈里聊得更偏哲学一些。
他不喜欢"vibe coding"，也就是国内圈子里讲的"氛围编程"这个词。
他觉得这是一种傲慢，暗示人们没有在真正编程。
但数据摆在那里，他认为 AI 的能力已经超越了 95% 的工程师。
与其花时间争论复制代码是不是犯罪，不如把时间花在想清楚产品逻辑上。

当然，也有人看到了风险。
Anthony，Anthropic 的产品经理，他就比较务实。
他用 Fable 这个框架半天就搞出了一个带 3D 走览的户型设计工具。
他本来的心态是，一个月得花 29 美刀订购专业软件，现在不用了。
这当然是好事，但同时也说明当复制和衍生变得太容易，软件本身的稀缺性就完全转移到了"想法"和"整合"这一步。

所以，这对每天在电脑前干活的人来说，到底意味着什么？
首先是别跟趋势较劲。
如果你发现某个重复逻辑已经复制了三四遍，或者 AI 生成的代码里到处是雷同片段，让它们保持原样不要急着去抽象成一个完美基类。
你的精力应该用在审查那些边缘 case 是否通顺上，而不是做语法优化。
再一个，是文件结构要往前放。
以前说代码即文档，以后可以说文件结构即意图。
把相关的业务逻辑分目录放好，代码哪怕全是复制的，团队和将来的 Agent 也能一目了然。
你最近在 Copilot 或 Cursor 里，是不是也开始懒得去写那个 `utils.ts` 了？
如果不是，也许你的抽象正在成为你工作流里最慢的那块。

换个方向，说几件今天相对轻量但关乎日常的事。

Claude Code 今天更新的那个 diff 面板，持久化、可滚动、实时刷新，能让你在 AI 编辑代码时不用来回切窗口。
如果你觉得在命令行和 IDE 之间跳来跳去很烦，这个更新值得立马试一下。
同一时间，OpenClaw 宣布云会话能高速运行了，带上远程终端和 WebVNC，整个电脑使用体验顺畅了不少。
不过另一边，也有人发现 ChatGPT Pro，就是那个 20 倍价格的订阅，购买入口被暂时停掉了。
Peter Steinberger 的判断是 Astra 的需求涨太快，他们在控量。
如果你想冲一下 Pro，可能得抓紧刷一下页面。

再说一条工具侧很有意思的发布。
Obsidian 的创始人 kepano，正式开源了一个叫 Knap 的小语言。
发音是 knap，K 不发音。
它的作用，是把任何数据转成 Markdown 格式。
这听着很小，但实际场景很顶。
现在什么数据都要喂给大模型，AI 最友好读的就是结构清晰的 Markdown。
这个语言已经有上百万人在间接使用，最初是藏在他的 Web Clipper 模板引擎里。
你现在可以在自己的 App 里用它，也可以命令行批量把 JSON 或 CSV 转成 Markdown。
如果你日常需要给模型准备格式化文档，Knap 值得放进工具箱。

如果你连这两件事都没去试一试，可能需要两边都跑跑看。
