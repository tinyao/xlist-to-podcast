郭宇连发了好几条推文分析这件事。

大家不需要一个复杂的 OpenClaw 或者 Hermes。
只需要一个跨平台的 Codex，对着手机说一句 /goal。
他提到 Codex 的做法很像 Claude Code 的 remote 模式。
而不是像 Claude 一开始就搞 cloud sandbox。
那个 sandbox 推出来挺早，但用的人不多。

他原话是：“当你想控制的马车几乎能自动驾驶去任何地方，控制它这件事本身就缺乏意义。”
这话说得挺重的。

另一件值得说的事。
Lenny Rachitsky 昨天发了一条推文，引爆了评论区。
他列了一张清单：工程师不写代码了，PM 直接上线产品，设计流程没了，市场自己发 campaign，SDR 被 AI 替代，人人都是数据科学家。
然后他问了一个问题：到目前为止，哪个岗位受 AI 影响最小？

这个问题问到点子上了。
不是因为答案重要，而是因为这个问题本身在逼你重新审视自己的工作。
评论区里各种答案都有。
有人说销售的关系维护还没被替代。
有人说幼儿园老师暂时安全。
有人说心理咨询师的核心是人和人的信任。

但 Aaron Levie 昨天从另一个角度回答了这个问题。
他转发了 nader dabit 的推文，说 Forward Deployed Engineer 是现在最热门、需求最大的岗位之一。
OpenAI、Cognition、Anthropic、Google 都在招。
Aaron 补充说，如果是大学就业指导中心的人，应该赶紧让学生知道这个岗位的存在。
而且不只是科技公司在招，咨询公司、IT 服务公司、中大企业的内部团队，全都在招。

这个岗位要求什么？
Aaron 列得很清楚：深厚的工程背景，CS 专业或辅修。
系统化思维，商业敏感度。
最关键的是，你得对 AI agent 非常熟。
能用 coding agent、懂 MCP、CLI、Skills。
他说，未来会有成百上千的科技公司需要这种人。

这个判断跟两天前我们聊过的 OpenAI 部署公司是同一条线。
当时 Aaron 就说，agent 部署需要的不是更好的 prompt，是更深厚的行业 know-how。
现在他直接把话挑明了：这是一个全新的职业市场，门已经打开了。

如果你在考虑下一步的职业方向，这两条推文值得放在一起看。
Lenny 问的是“什么岗位还没被影响”。
Aaron 说的是“什么岗位正在被创造”。
一个在看存量，一个在看增量。

今天值得展开聊的，是这件事。

过去 24 小时，有三条线同时指向了一个正在被重写的概念——岗位。
第一条是 Lenny 的提问。第二条是 Aaron 的招聘判断。
第三条来自 Peter Yang，他问了一个更具体的问题。

Peter Yang 昨天发了一条推文，问怎么让 Claude Design 或者 pencil 这类工具有品味。
他提了两个具体问题：有没有什么设计 skill file 可以用？是不是应该先让 AI 建一套设计系统？
然后他自己补了一句：“设计师看到这条可以翻白眼，但翻完之后给我点建议。”

这条推文下面有很多设计师回复。
有人说，品味不是文件能教的东西。
有人说，先建设计系统是对的，但 AI 建的系统往往缺灵魂。
有人说，问题不在于 AI 有没有品味，在于你有没有品味去判断 AI 的输出。

把这三天的事串起来看。
两天前 Julie Zhuo 说，把人的品味教给 AI，是当下最难也最值钱的一门手艺。
昨天 Peter Yang 就在问，怎么把设计品味变成 AI 能用的文件。
而 Lenny 在问，什么岗位还没被 AI 碰到。
Aaron 在说，能把 AI 部署进企业的人，是现在最抢手的。

你会发现一个正在成型的职业分层。
最底层，是那些被 AI 直接替代的重复性工作。
中间层，是那些正在被 AI 增强、但还需要人做判断的工作。
最上层，是那些因为 AI 而诞生、以前根本不存在的工作。

郭宇昨天还有一条推文，挺能说明中间层的变化。
他说自己用 Codex 做签证申请材料。
Codex 用 LaTeX 排版，做出来的文件精致得不像话。
他感叹：如果没有这些 coding agent，谁会发癫写 LaTeX 来做签证申请？
以前自己搞签证材料要花一天，现在 Claude Code 两下就做完了。
他连 doc 都懒得自己填。

这个场景很有意思。
签证申请这件事本身没变。
但完成这件事的人，技能要求完全变了。
以前需要的是耐心和细心。
现在需要的是“知道怎么让 agent 替你干活”的能力。
这就是 Peter Steinberger 说的那句话：你还是需要大脑做主模型。
agent 能帮你跑一百遍 review，但系统架构还得你自己想。

对听众来说，这件事有一个很直接的启发。
如果你现在的工作里有一部分是“被 agent 增强”的，试着问自己两个问题。
第一，agent 替你省下来的时间，你用来做什么了？
第二，你的判断力——那个“大脑做主模型”的部分——有没有在变强？
第一个问题决定你的效率，第二个问题决定你的不可替代性。

再说几条快讯。

Guillermo Rauch 昨天展示了一个新玩具。在终端里用 ai-cli 直接渲染图片，一行命令就能调用 Vercel AI Gateway 上的所有图像、视频和文本模型。他说“你可以在终端里渲染图片，顺便说一句”。这个工具对喜欢在 CLI 里干一切的人挺实用。

Notion 的开发者平台正式上线，底层跑在 Vercel Sandbox 上。Guillermo 转发了介绍页面，说“这个落地页也是 next-level”。开发者现在可以原生扩展 Notion，或者通过 MCP 把 Notion 带到自己的工作流里。

Matt Turck 发了一期播客，跟 Daytona 的 CEO Ivan Burazin 聊 agent sandbox。标题是“每个 agent 都需要自己的电脑”。他们讨论了 agent 安全、沙箱快照、状态分叉，还提到一个预测：AI agent 可能引发全球 CPU 短缺。如果你在做 agent 基础设施，这期值得听。

Peter Yang 还分享了一个被低估的用法。用 Claude Code 或 Codex 来合并和编辑 PDF。他说在 Preview 或 Adobe Acrobat 里搞这些是噩梦，直接告诉 AI “裁掉空白区域”就完事了。这个用法确实挺实在。

你最近有没有发现，自己工作里某个“以前很麻烦”的环节，现在 agent 两下就搞定了？省下来的时间，你用来做什么了？
