## 今日摘要
OpenAI 宣布将向关键网络防御机构推出前端安全模型 GPT-5.5-Cyber，标志着前沿模型开始走向特定领域化。Claude Code 被指对提及 OpenClaw 的仓库多收钱或拒接请求，引发社区关注。Andrej Karpathy 在红杉 AI Ascent 活动中详细阐述了 LLM 的能力不均衡性、新计算范式带来的机会，以及对 agent 原生经济的展望。

## 重点话题
- GPT-5.5-Cyber 发布：OpenAI 首个专门面向网络安全防御的前沿模型，初期仅面向关键防御机构。
- Claude Code 对 OpenClaw 收费争议：Anthropic 产品被指根据仓库内容动态定价，Sam Altman 评论为“对齐失败”。
- Karpathy 论 LLM 的新地平线与 jaggedness：解释了为什么 LLM 能力不均匀，以及经济激励如何影响模型训练数据分布。

## 快讯
- OpenClaw 发布 2026.4.29 版本，群聊 agent 体验大幅改进。
- Lenny Rachitsky 表示最近更爱用 Cursor，而非原生 Codex 或 Claude Code。
- Cloudflare 允许 agent 自主注册账户、购买域名和部署应用。
- Aaron Levie 详述了内部 agent 工程师这一新兴岗位的定义与重要性。
