GPT-5.5 的一个专门分支模型昨天深夜揭晓了。
Sam Altman 亲自宣布，GPT-5.5-Cyber 是一个前沿网络安全模型。接下来几天会先推给关键的网络防御机构。他说要和整个生态还有政府合作，找出一套可信的接入方式，目标是快速帮助企业和基础设施做安全加固。
这个模型的定位非常窄。它不是通用升级，不是给所有人用的。Sam 的原话是 critical cyber defenders——承担关键防御职责的那批人。这意味着它的能力可能集中在漏洞发现、攻击路径模拟、或者逆向分析之类的高敏感任务上。如果你不在网络安全一线，这个模型短期内跟你没有直接关系。但它释放的信号是，前沿模型开始被做成特定领域的武器。安全是第一个落点，接下来呢。

另一件值得说的事。Claude Code 怎么识别 OpenClaw，这件事昨天炸了锅。
Theo 先发现的。他说在一个空 repo 里，只要最近的 commit 信息里提到 OpenClaw，Claude Code 要么拒接请求，要么就多收钱。Sam Altman 转发了这条，只回了两个词：alignment failure。这两个词很重。他没有解释，没有调侃，就那么一句话。Peter Steinberger 的反应是 WAT，他转发了之后圈了 OpenAI、NVIDIA、微软、GitHub 等等一堆公司，说自己这几个月学了很多安全生态的东西，感谢这些公司帮 OpenClaw 做公开加固。
一边是 Anthropic 被指在产品里埋了针对特定项目的识别和收费逻辑。另一边是 OpenClaw 在趁机亮出自己的安全合作网络。如果你在用 agent 跑命令行，这条消息值得关注的不是谁对谁错，而是模型供应商会不会开始对某些 agent 收不一样的价。这直接关系到你选底层模型的成本。

说到 Karpathy，他昨晚发了一条被大量收藏的长帖，是他一周前在红杉 AI Ascent 的一场 fireside chat 的内容总结。信息量很大，我们今天多花几分钟把它拆开。

接下来这段我们多说几句。

Karpathy 这次谈了三个主题。第一个，是 LLM 带来的新地平线，不是让旧东西更快，而是做出以前根本不存在的东西。
他举了三个例子。一个是 menugen，一个只靠输入图片、输出图片就能跑通全流程的 App，没有一行传统代码。第二个是 install.md 技能，替代 install.sh 脚本。为什么还要写复杂的 bash 脚本？直接把安装步骤用英语写下来，扔给 LLM，它能针对你的具体环境、做调试、搞定一切。第三个是 LLM 知识库。这件事用传统代码根本做不到，因为计算的对象是来自任意来源、任意格式的非结构化知识。
这三个例子放在一起，指向同一件事。新范式里的机会，藏在那些以前不可能、或者没必要再存在的东西里。不是在 IDE 里把代码写得快一点，而是有些东西根本上就不该再用代码去写。

第二个主题，Karpathy 试图解释 LLM 那种诡异的不均匀能力。
同一个模型，能干净利落地重构十万行代码，转个头又告诉你走到洗车房里洗车。他之前写过，这和域的可验证性有关。这次他把解释往前推了一步：也和经济有关。因为收入和市场体量，决定了前沿实验室选择把什么放进强化学习阶段的训练数据分布里。你落在那条分布线上，就是在高速轨道上飞。落在分布外，就是在丛林里拿砍刀开路。他说自己对这个模型还不完全满意。但对听的人来说，这提供了一个很实际的思考框架。如果你觉得某个任务上 LLM 蠢得不可思议，先问一句：这个事情，有没有被放进那几家大实验室的 RL 训练分布里。

第三个主题，是 agent 原生经济。
他把产品和服务拆成传感器、执行器、逻辑，分别对应软件 1.0、2.0 和 3.0 的计算范式。他还提了一个很远的愿景：未来绝大多数计算都由神经网络直接完成，经典 CPU 只是协处理器。这听起来很远，但他放在这里说，是在给听众一个方向感。当信息被最大限度地做成 LLM 能读懂的结构，当 agent 开始接管越来越多的逻辑层，整个系统的架构会从底层被重写。他反复强调的那个词是 understanding——你可以外包思考，但不能外包理解。他昨天引用了 yacineMTB 的这句话，说最近反复在引。你让它帮你快，没问题。但你得知道自己要什么。

顺带说一句，Karpathy 这场 fireside chat 是由红杉的 Stephanie Zhan 主持的。她提到去年的活动上，Karpathy 造了 vibe coding 这个词。到了今年，他说自己作为程序员，从没感觉这么落后过。vibe coding 抬高了地板，他原话说。agentic engineering 在拉高天花板。

再说几条快讯。

OpenClaw 发了新版本 2026.4.29。Peter Steinberger 说群聊里的 agent 表现重写了，效果好了很多。他还给了两个链接，一个是群聊可见回复的设置说明，一个是 Codex Harness 插件。Lenny 最近在用 Cursor 多于原生 Codex 或 Claude Code，他说差距不大，但刚好够让他留在那边，而且切模型方便。郭宇说 Cloudflare 动作太快了。现在 agent 可以在 Cloudflare 上注册账户、绑域名、拿 API token，等于 agent 可以直接在 CF 上部署东西了。Aaron Levie 发了一条关于内部 agent 工程师的很长的推文，Box 已经在招这类人，角色类似内部 FDE，把 agent 塞进业务流程里。他的核心判断是，这个岗位需要同时懂技术和流程，不是把自动化带给一个岗位，而是把自动化带给一个流程。
你现在的团队里，有没有人已经开始干这个活了？还是说，这个角色还没被人认出来。
