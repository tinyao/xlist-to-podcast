OpenAI 正式宣布成立机器人部门，开始大规模招聘。Sam Altman 昨天在 X 上宣布了这个消息，他说 OpenAI 的世界模拟研究项目在过去一年演变成了 OpenAI Robotics。短期目标是制造能帮助技术工人建设基础设施的机器人，长期愿景是每个人都能拥有一个处理任何事务的个人机器人。这个部门由 Aditya Ramesh 领导，核心方法论是硬件和机器学习研究的协同设计。Sam 列出的招聘方向覆盖了全栈硬件、运维、系统和 ML 工程师，邮件直接发到 robotics-recruiting@openai.com。如果你在机器人领域有积累，这可能是今年最值得关注的机会窗口。

同一时间，OpenAI 还发布了一个生物防御系统 Rosalind。Sam 发了一条推文，附上了 OpenAI 官网的公告链接。公告标题是"用 Rosalind 强化社会韧性"，强调这是帮世界在生物安全领域取得先发优势。目前公开的技术细节不多，但结合 OpenAI 最近在科学领域的频繁布局，这显然不只是做模型，而是在往国家安全和公共健康基础设施渗透。你觉得 AI 公司该不该介入生物防御？这是询问，不是反问——这个边界确实越来越模糊了。

另一件值得说的事，Guillermo Rauch 观察到一个可能改变企业软件格局的现象。Vercel 的 CEO Guillermo 昨天发推说，CEO 和 CTO 们正在疯狂回归编程，这全拜 coding agent 所赐。他说有上市公司的 CEO 私下告诉他，因为 Claude Code 和 Vercel 的组合，他们重新爱上了发布软件。过去那些"梦想客户"的 C 级别高管根本搞不懂基础设施，现在从实习生到 CEO，整个组织都能直观判断哪个技术栈好用。Guillermo 把这称为 coding agent 带来的终极 PLG 化——企业软件的产品驱动增长。烂的、老旧的软件再也藏不住了。你最近有没有发现，公司里非技术岗的领导突然开始聊技术选型了？

说到 Codex，Peter Steinberger 分享了一个有意思的细节。OpenClaw 的创始人发现 Codex 开始自己写 codemod 了。他在一次 TypeScript 大规模迁移中，看到 Codex 自动生成了临时性的代码转换脚本，以前从没见过这种行为。这说明 coding agent 正在从"按指令写代码"进化到"理解工程任务并自主选择工具"。对工程师来说，这意味着你需要开始习惯 agent 不只是帮你写函数，而是帮你做架构迁移决策。

郭宇也提供了一个数据锚点。他说 Codex 的用户数只有 ChatGPT 的 0.6%。ChatGPT 大概 9 亿用户，Codex 大约 500 万。他的判断是：如果你在 Codex 上消耗过 10 亿 token，你属于人类中的极小一部分。一切才刚刚开始。

今天圈子里最值得展开聊的，是一场关于工作强度的观念对撞。

起因是 Harry Stebbings 发了一篇深度报道，讲一家叫 Corgi Insurance 的初创公司。创始人 Nico 睡在办公室，公司要求 7 天工作制，前 30 名员工里有三分之二把公司 logo 纹在身上。两年内估值冲到 26 亿美元。Nico 的原话是："如果你不每周工作 7 天，你就会输。"

这篇报道在圈子里炸开了锅。Peter Yang 直接嘲讽，列了一个"真正想赢"的清单，第一条就是"997 工作制——996 是给失败者的"。他还加了一句："如果你花在 token 上的钱没超过公司全员人力成本，你好意思说自己是 AI native？" 明显是反讽，但反讽背后是真实焦虑——当 agent 可以 24 小时运转，人的工作节奏到底该怎么定？

另一边，Linear 的创始人 Karri Saarinen 发了一篇长文，直接正面反驳。他说这种"更多等于更多"的逻辑是谬误。大公司有成千上万人，如果拼工时就能赢，政府和大型企业永远该是赢家。但现实不是这样。

Karri 的观点很清晰：startup 的杠杆在于解决问题的方式、团队培养和策略，不在于工时。他说 Linear 从来没有这么工作过，所有创始人都有家庭，他自己每天晚上停下来做饭、陪家人。偶尔会有需要冲刺的时候——发布、事故、紧急任务——但如果这种事变成常态，他认为那是公司和领导层的失败。

他最后一句被多人引用："真正的精通不是付出最大的努力，而是用最少的必要努力达成结果。"

Box 的 CEO Aaron Levie 从另一个角度切入。他引用 Apollo 首席经济学家的研究，说目前没有证据表明 AI 导致失业。他在和大型企业的 CIO、CTO 对话中发现，AI 正在创造全新的岗位，或者让企业把效率提升省下来的钱重新投入到销售、市场等之前资金不足的领域。高盛 CEO David Solomon 上周在纽约时报的观点文章也表达了同样的判断。

Levie 的结论是：用 AI 更好地服务客户的公司长期会赢，那些只想省钱的公司最终会更糟。

这三方声音放在一起，其实指向同一个问题：在一个 agent 可以 24 小时运转的时代，人的价值到底在哪里？Corgi 的回答是"拼到极致"。Linear 的回答是"清晰思考比堆时间重要"。Levie 的回答是"把 AI 省下的资源重新投资到增长上"。

对你来说，这意味着三件事。第一，如果你的团队在用 AI 工具后只是砍了人、没有重新配置资源，你可能在走一条短期省钱、长期输掉的路。第二，如果你在招人，别只看候选人愿不愿意加班——看他们能不能在正常节奏里做出高质量决策。第三，如果你自己在用 coding agent，试试把它当成 QA 助手，像 Peter Steinberger 做的那样，每次 commit 都让 agent 模拟用户测试，自动提 PR 修复问题。这是把 agent 的"无限耐力"用对地方的方式。

Greg Isenberg 基于 GPT Realtime 2.0 列了 17 个创业方向。包括实时合同谈判 agent、语音控制交易终端、直播拍卖 agent、法律取证练习 agent、无声销售教练、制造业语音质检员。核心逻辑是：语音模型现在有了 GPT-5 级别的推理能力，可以在你说话的同时并行查询多个数据源、做出判断。六个月前这些都做不到。

swyx 观察到一个趋势：所有做评估和分析的创业公司，今年都在经历一次"代际升级"，从一次性评估转向持续学习平台。他说很多会失败，但品味好的会赢。

郭宇分享了一个实用技巧。他在 Mac Studio 上设了一个 hook，一旦发现 web app 更新，自动同步为新的 Expo mobile app。他说这省了 50% 移动应用开发时间。后果是手里攒了十几个等待提交的 app。
