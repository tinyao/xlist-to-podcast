## 今日摘要
OpenAI 宣布成立一家由 19 家机构联合参与的部署公司，专门帮企业将 agent 落地到生产环境。Box CEO Aaron Levie 深度分析了 agent 部署市场的巨大机会，并透露 Box 已开始招聘 AI 自动化工程师。Karpathy 提出人机交互正在从纯文本向 HTML 乃至交互式视频进化，并给出了实用建议。从大厂部署到个人创业，agent 落地正在催生一批全新的职业角色。

## 重点话题
- Agent 部署催生新职业：OpenAI 成立部署公司、Box 招聘 AI 自动化工程师、Greg Isenberg 列出七个 agent 创业想法，三条线索指向同一个方向——让 agent 在真实业务中跑起来，正在变成一种新的职业技能
