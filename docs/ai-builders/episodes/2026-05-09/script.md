OpenAI 向关键基础设施的防御方推出了一个定制模型，叫 GPT-5.5-Cyber。
Sam Altman 昨天宣布这个消息，说他们希望帮企业保护自己，而且觉得这件事得尽快动手。
具体来说，这个版本目前只开放给少数安全研究员，用于保护电网、医院这类系统。
它跟普通开发者用来扫漏洞的 GPT-5.5 TAC 不是同一个产品。
Sam 引用的推文里强调了“严格限定防御方”。
这个措辞很谨慎——模型能力越强，落到攻击者手里的风险越大。

这事跟 Anthropic 前两天用 Claude 帮 Mozilla 扫漏洞，本质上是一个趋势。
安全领域正在变成模型之间的对抗。
防御方有 GPT-5.5-Cyber，攻击方可能也在用别的模型。
如果你在维护有合规要求的系统，现在可以开始规划怎样把这层防御 AI 嵌进你的安全流水线。

Anthropic 的 Claude Code 团队成员 Thariq，昨天写了一篇文章，在圈子里传了一夜。
标题很直接：HTML is the new markdown。
他自己已经不再手写任何 markdown 文件，全部改成让 Claude Code 直接生成 HTML。
理由很具体。Markdown 做不了的事太多了：没法内嵌交互、没法做响应式布局、表格一复杂就崩。
而 HTML 文件可以在任何浏览器里直接打开，跟 PDF 一样分享，但远比 PDF 灵活。
他还放了一个公开的案例网站，上面全是他用 Claude Code 生成的 HTML 文档，从项目管理看板到个人数据仪表盘都有。

Zara Zhang 看到这篇文章之后，立刻加了一句评论。
她说 HTML 确实在吃掉一切。
她给了一个非常具体的建议：想入门 AI 编程，试着用 HTML 替代你现在的所有文档、Excel、PPT。
Hamel Husain 则开玩笑说，他有点怕有人把这篇文章变成一个 /html 技能包。
这当然是玩笑，但这个笑点的意思是说：模型已经会写 HTML 了，人别再教别人怎么写 HTML 了，直接用模型输出就行。

这对你来说意味着什么？
如果你现在还是把技术方案写成 markdown 丢给同事，不妨试一次直接让它生成一个可以互动的 HTML 原型。
打开浏览器就能看的东西，沟通成本低太多了。

Thariq 那条推文里还提到一个细节。
他以前觉得 HTML 太啰嗦，写起来烦。
但现在有了 agent，你不需要自己写。
你只需要描述你想要什么样的页面，agent 会把标签全写出来。
他甚至开始用 HTML 做内部 Knowledge Base，因为搜索和导航可以自己设计。
这件事表面上是文件格式之争，实际上是信息架构在 agent 时代的演变。

Justine Moore 昨天发了一段只有 6 秒的视频，但信息量很大。
她说现在有大量“塑形”和“减肥”App，靠 AI 生成的“前后对比”视频在社交媒体上带货。
她随便查了几个，每一个都触发了 SynthID 的水印检测。
换句话说，这些展示“惊人效果”的视频，全是 AI 生成的。
视频里的“真人”身材变化，根本没有发生过。

她举了一个具体例子。
一个叫 Her 75 的 App 的推广视频，播放量已经四百万了。
用户看到的是真实的人变瘦了，实际上是一段生成视频。
这跟健康领域的虚假广告是同一个法律地带，但执法速度远远跟不上生成速度。
如果你在做面向用户的 AI 产品，Justine 的这条推文是一个很好的伦理红线提醒。
用 AI 生成素材本身没问题，但把它伪装成真人经历去诱导消费，就是在给自己埋雷。

Aaron Levie 昨天接住了 Gergely Orosz 三天前那个关于“分发是新护城河”的话题。
他延伸了一个更底层的判断：AI 让某件事变容易的同时，这件事对所有人都会变容易。
听起来像一句废话，但后半句才是关键。
如果所有人都能更容易地做同一件事，那竞争会逼着资源流到别的地方去。
Aaron 写了一段很长的分析，把逻辑链拆得很细。

他说，如果 AI 让软件开发变便宜，那么相对的，销售、营销、客户成功的投入就会变高。
因为在这个条件下，谁能离客户更近、谁能让客户跟深，谁就赢。
这不只适用于软件创业。
他举了另一个例子：财务咨询。
如果你用 AI 自动化了分析和洞察，那差异化就会跑到客户 engagement。
他用一句话收了尾：如果所有人都在用同样的技术做同样的事，你得想清楚你凭什么不一样。

这段话是对本周关于“分发是护城河”讨论的一个完整闭环。
我们三天前刚深聊过 Greg Isenberg 那张矩阵，昨天在往期回顾里也在提这个。
但 Aaron 把视角从“竞争现象”拔到了“资源配置规律”。
他说这不是因为我们不够努力，而是技术平权之后，资源会自己去找新的稀缺点。
如果你正在同时做产品和营销，这个逻辑足以重新想一遍你的资源分配比例。
你的时间是有限的。
在写新功能和写案例文章之间，倾斜度可能该变一变了。

郭宇昨天在他的 tuwa 平台上全面上线了 GPT-Realtime-Translate 的同声传译。
他跑完了端到端测试，优势是真正的实时翻译，不需要等 user turn。
弱点是不能自定义语音，模型自己“模仿”语音，偶尔会因为缺乏上下文整合翻错。
但他测试完之后已经全面切换到这个模型了。
如果你正在用 AI 做跨语言通话，这个组合值得试试。
