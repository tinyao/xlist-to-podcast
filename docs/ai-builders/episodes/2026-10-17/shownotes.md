## 今日摘要
Anthropic 把 Code Review 推到了正式版，同时 Claude Slides 也让 slide deck 生成变得简单。Vercel 给 libfx 加了 durability 层，让 agent 在崩溃、重启、超时后仍能恢复执行。Perplexity 发布了 pplx-decider v1.2 和 flash 版本，推理速度最高提升 5 倍。郭宇开源了 sofatap，把 iPhone 变成控制客厅电脑的触控板。Greg Isenberg 总结了 agent 工具的六大垂直化方向，从数据经纪到计算转售都有具体案例支撑。

## 重点话题
- Anthropic Code Review 正式版：Team 和 Enterprise 计划可用，支持 Quick、Standard、Deep 三档深度
- libfx durability：Vercel 给 fx 加了一层耐久性 adapter，做到一行代码获得 agent 持久运行能力
- pplx-decider v1.2：Perplexity 决策模型升级，引入推理感知训练和 latest slug
- sofatap：开源 iPhone 触控板工具，扫码配对 Google TV，适配客厅 vibe coding 场景
- agent 工具垂直化：Greg Isenberg 的六大方向地图，以及 Postiz 的 27.5 万美元 MRR 案例
