## 今日摘要
Instinct 被曝未经许可索引用户邮件且无法删除，引发隐私争议。Grok Bot 向更多 Cursor 用户开放，Greg Isenberg 分享了用 AI agent 团队跑通整个生意的七条实践。Vercel 发布 is-agentic.com，一个测量网站对 AI agent 可读性的工具，并自测拿到满分。Claude Code 团队公开了内部高频使用的 ELI5 解释功能。此外，fx 0.0.5 即将发布，DeepSeek 多模态模型即将到来。

## 重点话题
- Instinct 隐私争议：AI 助手在未经许可的情况下索引和保留用户邮件，且无法删除
- Grok Bot 一人团队实践：Greg Isenberg 分享七条用 AI agent 团队运营生意的最佳实践
- Vercel is-agentic.com：测量网站对 AI agent 可读性的工具，支持 100+ 项检查和修复提示
