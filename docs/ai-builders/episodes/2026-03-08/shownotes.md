## 今日摘要
本期聚焦三个核心信号：Claude Code 发布 /loop 定时任务功能，标志着 AI agent 从单次调用走向持续协作；Karpathy 开源 autoresearch 项目，探索"让 AI 自主做 AI 研究"的可能性；OpenClaw 团队的实践揭示了一个普遍认知盲区——AI coding 工具的能力边界早已超出"写代码"本身。此外，GPT 5.4 口碑持续发酵，Replit CEO 提出"Generalist Automator"新职位概念，也值得关注。

## 重点话题
- Claude Code /loop 功能：AI agent 从 pull 模式转向 push 模式，可持续运行最长三天的定时任务，是 AI 协作形态的重要转变
- Karpathy autoresearch 项目：开源"让 AI agent 自主迭代 LLM 训练代码"的最小化实验框架，人负责定方向，AI 负责执行和优化
- Codex 不只是写代码的工具：Peter Steinberger 用 Codex 分析 Discord 用户数据，引发广泛共鸣，揭示 AI 工具的心理模型局限

## 快讯
- GPT 5.4 获多位业内人士正面评价，a16z 投资人称其"像在和聪明朋友聊天"，OpenAI Kevin Weil 推荐阅读其推理能力分析文章
- Kling 新 Motion Control 功能支持换脸，Justine Moore 实测多角度镜头表现超预期
- Anthropic 伦理研究员 Amanda Askell 让 Claude 为自己写"价值观宪法"，循环本身耐人寻味
- Replit CEO Amjad Masad 提出"Generalist Automator"新职位概念，主张最有想法的员工现在可以绕过工程瓶颈直接落地想法
- 有人为了 24 小时监督 coding agent 开始练习多相睡眠，人机协作的信任边界问题浮出水面
- Peter Steinberger 开源 discrawl，可将 Discord 消息爬取至 SQLite 数据库，他的库已有 4GB、66 万条消息
