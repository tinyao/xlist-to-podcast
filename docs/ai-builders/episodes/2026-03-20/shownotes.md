## 今日摘要
Claude Code 正式支持通过 Telegram 和 Discord 控制，coding agent 开始走出桌面进入手机；Google AI Studio vibe coding 体验正式上线，功能和路线图全部披露；Aaron Levie 与 20+ 企业 AI 负责人深度交流，带回了关于 agent 身份认证和 token 预算的具体观察；郭宇发布第 12 个产品 mails.dev，为 agent 提供邮件基础设施；Apple 对 Replit 和 Vibecode 踩刹车，vibe coding 与 App Store 的摩擦正式开始。

## 重点话题
- **Claude Code Channels**：通过 Telegram 或 Discord 直接控制 Claude Code 会话，agent 从桌面工具变为随时可召唤的存在
- **Google AI Studio 正式落地**：Antigravity agent、一键接数据库、多人协作，以及涵盖 Figma、Google Workspace、Planning mode 的完整路线图
- **Aaron Levie 的企业 AI 田野笔记**：agent 身份认证成为头号安全议题，token 预算正在从 IT 成本变成运营成本，coding 仍是最成熟落地场景
- **mails.dev（郭宇）**：为 AI agent 设计的邮件基础设施，20KB CLI，MIT 开源，支持 x402 协议自动付费，agent 可自助认领邮箱

## 快讯
- Apple 要求 Replit 和 Vibecode 修改功能，App Store 与 AI 代码生成的关系开始变得复杂
- Thariq 的观察被广泛转发："工程师的工作越来越多是在决定对一个问题该花多少算力"
- Cursor 发布 Composer 2：首次自研 continued pretraining，更强质量 + 更低成本
- Vercel Chat SDK：一套代码让 agent 同时运行在所有主流聊天平台
- Lovable 从 app 构建器扩展为"通用型联合创始人"，覆盖数据分析、幻灯片、营销物料
