Artifacts 开始支持公开共享和多人编辑，这对协作意味着什么？开源模型在网关的流量占比一个月里翻了一倍多，谁会感到紧张？Lenny 发布了一份大调查，科技从业者最怕的不是被 AI 替代，那到底是什么？先从最让工程师兴奋的那件事开始。

Claude Code 的 Artifacts 功能迎来了一次关键更新，现在支持公开分享和多人实时编辑。

这是由 Claude Devs 官方账号昨天宣布的，Claude Code 团队成员 Thariq 随后补充了细节。他说，这让 Artifacts 的表达能力大幅增强，可以组合出很多新玩法。

其中一个用法是用 Claude Tag 为项目创建一个仪表板，然后分享出去，让其他人或本地运行的 Claude Code 会话共同编辑。
这就把 Artifacts 从一个单次的预览窗口，变成了团队协作和状态同步的界面。

如果你正在用 Claude Code 管理多会话的复杂项目，这个特性值得立刻试一下。
Thariq 的原话是“one of my favorites”，能让一线开发者说出这种话，通常说明它解决了某个真实的痛点。

另一件值得说的事。Vercel 发布了最新的网关数据，其中提到开源模型的流量占比大幅上升。

Guillermo 转发了这份报告。数据显示，通过 Vercel 网关的 tokens 里，开源模型贡献了 29% 的流量，而四月份这个数字只有 11%。短短三个月，翻了一倍多。

这个变化的背景，是 swyx 昨天列出了一串预计在年底前发布的模型清单：GPT 6、Gemini 3.5 Pro、Grok 5、DeepSeek v4.5、Qwen 4 等等。
他形容这是 LLM 历史上最多极化的前沿格局。

而 Box 的 CEO Aaron Levie 的观点更直接。他说，推动大规模 agent 普及的最佳方式，就是继续降低智能成本。
每降一次，就有更多之前算不过账的场景被打开。

如果你在为下游应用选模型，现在确实到了一个临界点。
开源模型的水平追得很快，而它的成本优势，正在让更多人用脚投票。

昨天晚上，Lenny 发了一份大规模科技从业者调查的核心发现，话题相当扎实。
我注意到它并不是因为数据量大，而是里面有几个反直觉的结论，在圈子里被反复引用。

先说调查本身。Lenny 和研究员 Noam Segal 一起分析了今年的结果，对比了去年的数据。
样本覆盖了不同公司规模、不同职能的科技从业者。

其中最让人意外的发现是：大家最怕的不是被 AI 抢走工作。
排在首位的恐惧是“做更多，拿一样的钱”。
调查里，担心失业的选项排在很靠后。而压倒性的焦虑来自产出标准被 AI 拉高之后，工作强度和预期回报之间的落差。

Noam 管这种现象叫“smiling exhaustion”——一边觉得工作还挺有意思，一边已经被榨得差不多了。

另一个扎心的发现是，有 97.2% 的受访者说 AI 让自己更擅长工作了。
但追问“擅长”具体指什么，答案几乎全是“更快更多”，不是“质量更高”。
甚至有一个叫“cognitive rot”的现象开始被讨论：人们看到模型的第一版输出就直接接受，自己的判断力在慢慢退化。

这份调查还发现，科技圈正在分裂成两半。
50% 的人感觉被 AI 放大了能力，干劲更足。另一半人觉得角色被重新定义，甚至感到不安或边缘化。
设计岗和研究岗的情绪最负面，连续两年最低。
创始人反而是最快乐的一群，无论什么指标都比其他人好。

这些数据对听众有什么启发？我觉得最直接的一点是，别再默认“提效”就等于“好事”。
如果你的团队在疯狂提效之后，出品的质量反而在下降，那确实需要停下来想一想了。
