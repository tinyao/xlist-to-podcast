## 今日摘要
Anthropic 开始系统性地封锁第三方 agent 调用，要求用户自带 API 额度，OpenClaw 等工具率先做出应对。Replit 在更新被苹果阻止的情况下依然重回 App Store 分类第一。OpenAI Codex 团队深度访谈透露了“零文档、设计师写代码”的极度精简运作模式。Anthropic 一年内 ARR 从 10 亿美元激增至 190 亿，仅二月就新增 60 亿。Karpathy 以 Farzapedia 为引，深度阐述了“文件优先于应用”的个人化 AI 理念，掀起关于个人 Wiki 与 Agent 记忆的热议。

- OpenAI Codex 团队内幕：Peter Yang 访谈揭示 10 行 bullet point 代替规格、设计师写代码超过工程师的新职能边界
- Anthropic 指数级增长：Lenny 播客给出每月 60 亿 ARR 的增长数据，为 Anthropic 的战略激进提供了解释
- 个人 Wiki 与文件哲学：Karpathy 通过 Farza 的案例，呼吁用本地通用文件打造可被任意 AI 代理读取的显式个人知识库
