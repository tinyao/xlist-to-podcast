## 今日摘要
今天的核心主题围绕 AI agent 的工作范式转变展开。Karpathy 用 AI agent 自动优化自己的 nanochat 项目，宣告"研究 agent 框架本身"成为新的元竞争；swyx 提出"2026年是 subagent 之年"，主张放弃 multiagent 思维；Claude 每日新增百万用户，Claude Code 推出本地定时任务，AI coding 工具正从"被动调用"走向"主动运行"。商业视角上，Aaron Levie 和 Greg Isenberg 分别从采购决策和产品设计角度，指出垂直 AI 公司的最优切入路径是"替换现有外包合同"和"自动化生产客户真正在乎的成品"。

## 重点话题
- Karpathy 的 agent 自优化实验：AI 自己跑实验、自己合并改动，研究范式从"写代码"转向"设计 agent 工作流"
- Claude 百万日增与 Claude Code 定时任务：AI coding 工具从工具走向持续运行的 agent，OpenAI 同步推 Codex for Open Source
- 垂直 AI 的商业路径：Levie 的"外包替换"框架 + Isenberg 的"拥有成品输出物"策略，给创业者提供清晰路径图
