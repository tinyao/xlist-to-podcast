## 今日摘要
Boris Cherny 提出了 AI 时代工程团队的五个角色原型，彻底突破了传统的岗位边界。Lenny 深度采访了 OpenAI Codex 产品负责人 Andrew Ambrosino，他分享了关于产品流程反转、设计困境和 PM "区域防守"策略的 10 个思考。Cursor 发布了 iOS 应用，让开发者可以在任何地方启动云端 agent。Vercel 一口气推出了 Voice Agent、20 倍扩容的 Functions 和 Next.js 16.3 的性能飞跃。Claude Code 的下一个版本将支持子 agent 后台运行。

## 重点话题
- **Boris Cherny 的未来角色框架**：Claude Code 团队成员 Boris 提出五个跨职能原型——原型师、构建者、扫尾者、增长者、维护者——这是当天圈内讨论最热烈的帖子之一
- **Lenny 对话 Codex 产品负责人 Andrew Ambrosino**：Codex 周活用户突破 500 万，OpenAI 全员使用。Andrew 分享了 10 个关键洞察，包括"区域防守"PM 模式、为什么 AI 做不好设计、以及同一产品只换模型就能从失败变成功的故事

## 快讯
