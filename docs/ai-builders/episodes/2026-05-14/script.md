Codex 开始向企业免费开放两个月的试用期。
Sam Altman 昨天亲自宣布了这件事，推文发出去后迅速在圈子里传开。
他的原话是：Codex 是目前最好的 AI 编程产品，他们想让更多人无门槛地尝试。
具体规则是，从昨天起 30 天内，任何公司只要想从其他工具切换到 Codex，就能获得两个月的免费使用额度。

这条消息的背景值得留意。
过去几周，Anthropic 的 Claude Code 一直在攻城略地，推出了 Agent View 和 Agent SDK 月费额度。
而 Codex 这边，Peter Steinberger 昨天放出了一段演示，让很多人看呆了。
Codex 在调试一个 Telegram 问题时，发现需要新的 token。
它没有停下来问人，而是直接调用了 Peekaboo，远程打开了 Peter Mac 上的 Telegram 桌面应用。
然后它自己找到 BotFather 聊天机器人，完成了 token 申请。
整个过程完全是 agent 自主操作，人类只负责看。

Peter 还展示了另一个更疯狂的场景。
他把一台 Android 手机通过 Tailscale 串流到数据中心的 Mac 上，再用 Codex 去控制那台手机。
结果是，他的 agent 可以帮他叫 Uber 了。
他说了一句很实在的话：Computer Use 太惊人了。
如果你在考虑切换编程工具，Sam 这次给出的免费窗口是一个很低的试错成本。

另一件值得说的事。
Vercel 的 AI Gateway 公布了一组真实的用量数据。
Guillermo Rauch 亲自发了推文总结，说这组数据让我们看到了生产环境中 AI 和 agent 的真实使用情况。
三个关键发现：Google 在生产规模上处于绝对领先，Anthropic 在编程和支出上占主导，OpenAI 自 5.4 版本发布以来增长速度极快。
而开源模型也在持续扩大份额。

Guillermo 的结语是：AI 竞赛比看起来要流动得多。
这组数据的价值在于，它不是调研报告，不是开发者问卷，而是 Vercel AI Gateway 上跑过的真实 token 消耗。
如果你在做模型选型，这比任何 benchmark 都更值得参考。

说到 agent 的自主性，swyx 昨天给了一个很简洁的框架。
他把 agent 的自主程度分成了三级。
第一级是 skill，本质上是预设的提示词模板。
第二级是 plan，人类优化输入，agent 执行。
第三级是 goal，人类只给目标，AI 自己评估输出结果。
这个框架不复杂，但能帮你快速判断一个 agent 产品到底处在哪个阶段。
如果你在评估 agent 工具，用这个三层模型对照一下，能省掉很多被营销话术绕晕的时间。

Greg Isenberg 昨天凌晨发了一篇超长的观察清单，32 条，讲的是 agent 时代最大的机会。
他是 Late Checkout 的 CEO，一直在孵化创业想法，但这次的密度和跨度都是他近期最高的一次。
他在开头说，有些想法让他晚上睡不着觉。
我挑几条最反直觉的来说。

第一条，互联网上正在出现一种全新的买家——AI agent。
Greg 说，想象一下几十亿新客户带着钱来购物，但它们只通过 MCP 协议访问你的服务。
没有 MCP 接口，你就对这群增长最快的买家完全不可见。
这不是一个遥远的趋势。
Stripe 已经悄悄变成了 agent 经济里最重要的公司，因为每个买卖东西的 agent 都需要支付通道。
Greg 说 Stripe 几乎什么都没额外做，就成了 agent 互联网的默认支付轨道。

第二条，agent 正在发展出自己的偏好。
同一个 agent 执行同一任务 100 次，它会形成稳定的行为模式。
没有人系统研究这件事。
但那些形成了"好习惯"的 agent，比没有形成习惯的 agent 更有价值。
Greg 把这叫做一种全新的资产类别。

第三条，agent 市场可能是下一个大平台。
一个医疗行业的招聘 agent，花了 6 个月训练出来的判断力，可以租给地球上所有其他医疗招聘者。
agent 本身变成了产品。
这和往期节目里 Julie Zhuo 说的"把品味蒸馏给 AI"是同一个逻辑，只是应用到了更具体的商业场景。

第四条，最容易被忽视的安全风险在员工的个人笔记本上。
几百万人正在用自己同时上网、收邮件、下载随机文件的电脑跑 agent。
一个被攻破的 Chrome 插件，就能拿走 agent 的 API 密钥、客户数据、完整的工作流。
Greg 说攻击面巨大，而大多数公司 IT 部门对此一无所知。

第五条，有一种新型职业倦怠正在形成。
它不是工作太累，而是每天在人类工作和 agent 工作之间切换 50 次。
审核 agent 输出、纠正它、批准它、再审核。
Greg 说有些创始人告诉他，手动做所有事的时候反而没那么累，至少认知模式是一致的。

第六条，最孤独的岗位是公司里唯一懂 agent 在干什么的人。
你没法跟老板解释，没法把活交给同事，如果你离开，整个自动化系统就崩溃。
你变成了单点故障。
Greg 说，这个人需要一个头衔、一个团队、一个备份计划，但大多数公司还没意识到这件事。

这 32 条观察里，有一条特别值得你对照自己的工作想一想。
Greg 说，现在最被低估的资产是你在房间里跟另一个人对视、好好说话的能力。
AI 能处理越来越多的交易型互动，能做关系型互动的人反而变得极其稀缺。
以前被叫做软技能的东西，正在变成硬技能。
以前花了十年练出来的硬技能，正在变成软技能。
这句话很重，但也很实在。
