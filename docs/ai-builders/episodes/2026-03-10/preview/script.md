好，先从今天最值得深聊的一个话题开始。

Andrej Karpathy，就是那位前特斯拉 AI 总监、OpenAI 联合创始人，他昨天发了一条推文，互动量非常高，转推超过500次，收藏接近2600次。内容是什么呢？他在做一个叫 autoresearch 的实验——让 AI agent 自动调优神经网络训练流程。

他三天前把这个 agent 挂上去，让它对一个12层的小模型跑了大概两天。agent 自主做了将近700次实验，最终筛选出20个有效改进。Karpathy 把这些改进全部叠加之后，测了一下，发现 "Time to GPT-2" 这个基准指标，从2.02小时降到了1.80小时，提升了大约11%。

你可能会说，11%听起来不大。但关键在于，这是在 Karpathy 自己已经手工调优了很长时间之后，agent 又额外找到的提升空间。他自己都说"有点意外"。

agent 找到了什么？举几个例子：它发现 Karpathy 的 QKnorm 没有加缩放乘数，导致 attention 太分散；发现 Value Embeddings 需要正则化但没有加；发现 AdamW 的 beta 参数设置有问题；还调了权重衰减的调度和网络初始化。

这些都是很具体的工程细节，不是什么宏大的理论突破。但 Karpathy 说，这是他第一次完整地看到一个 agent 端到端地走完整个研究迭代流程——提出假设、做实验、看结果、再提出下一个假设。他做这件事已经二十年了，现在第一次看到机器在做同样的事情。

他最后说了一句话，我觉得很值得记住：所有前沿 LLM 实验室都会做这件事，这是"最终 Boss 战"。思路是：起一群 agent，让它们协作调小模型，把最有希望的改进逐步推到更大规模的模型上，人类可选择性地在边缘参与。

他把这个叫做"just engineering"——不是什么神秘的科学突破，就是工程。但他认为它会起作用，而且规模化之后影响会非常大。

我的观察是：这件事真正重要的地方，不在于那11%的性能提升，而在于它打开了一个新的工作模式。以前调模型是研究员最核心的手艺，现在这个手艺本身开始被自动化了。Karpathy 还提到他下一步要研究多个 agent 并行协作，进一步解锁并行度。这条路一旦跑通，AI 研究的速度会是什么量级，真的很难想象。


说完 Karpathy 的实验，我们来看另一个今天刷屏的消息，而且这个和大多数工程师的日常工作直接相关。

Anthropic 昨天给 Claude Code 推出了一个新功能，叫 Code Review。简单说，就是当你开一个 Pull Request 的时候，Claude 会自动派一组 agent 去做深度代码审查，专门找 bug。

这个功能的发布推文来自 Boris Cherny，他是 Claude Code 的工程师，他说了一个很具体的数字：Anthropic 内部工程师今年的代码产出翻了200%，而 code review 之前是最大的瓶颈。

另一位 Claude Code 的工程师 Thariq 说，这是"那种你用了之后不知道自己之前是怎么活过来的"功能。Anthropic 的 Claude Relations 负责人 Alex Albert 也转发说，这个功能在他们内部工程和研究团队里收到了他认识的顶级工程师们少有的高度评价。

我想在这里稍微展开说一下背景。Code review 是软件工程里一个既重要又容易被忽视的环节。它重要，是因为这是最后一道人工质量关；它容易被忽视，是因为它费时间、费精力，而且很多时候大家都在赶进度。现在 Claude Code 把这个环节变成了"PR 一开，agent 自动扑上去找 bug"，这个工作流的改变是很实质性的。

值得注意的是，这里用的是"一组 agent"而不是单个模型。多 agent 并行做 review，覆盖面更广，发现的问题类型也更多样。这和 Karpathy 说的 agent swarm 思路是一致的——越来越多的任务开始用 agent 集群而不是单个模型来处理。

对于工程师来说，这个功能现在就可以用，值得去试试。


好，我们来聊第三个话题，稍微换个角度，从工具聊到生态。

今天有几条推文都在讨论一件事：AI 工具的设计哲学正在发生一个根本性的转变。

a16z 的合伙人 Justine Moore 发现 GPT 5.4 在审阅 slides 方面"好得令人震惊"——她直接上传 PDF，告诉模型受众是谁，然后要求帮忙。模型不仅给出了逐页的修改建议，还指出了整体叙事结构的问题。她说那种感觉就像是找了一个领域专家给你做深度拆解。

与此同时，Cursor 的设计师 Ryo Lu 转发了一个叫 Veeso 的 AI 设计工具，说"工具来自最接近问题的人"。还有 Riley Brown 发了一个视频，介绍一个叫 Paper 的工具，他把它形容成"给 AI Agent 用的 Figma"，Claude Code 和 OpenClaw 可以直接在里面创建设计，然后一键转成 React 应用。

这几条信息放在一起，我觉得有一个共同的信号：AI 工具正在从"帮你做某件事"转向"给 agent 用的基础设施"。

Zara Zhang 有一条推文说得很直接：大多数 AI 产品在努力把模型框在某个模板里，但 Claude Code 和 OpenClaw 展示了相反的思路——给模型工具，给它上下文，然后放开它。她说"魔法发生在你去掉限制的时候，而不是加上限制的时候"。

这个观察我觉得挺有意思的。我们现在看到越来越多的工具，它们的核心设计不是"用户界面"，而是"agent 接口"——怎么让 agent 更容易操作这个工具，怎么让工具的状态对 agent 可读可写。这可能是接下来一两年工具设计最重要的一个趋势。


下面我们快速过几条快讯。

首先说一个很有意思的开源项目。Peter Steinberger，就是那位自称"ClawFather"的 OpenClaw 重度用户，今天发布了 gogcli 0.12.0。这是一个把 Google 全家桶接入终端的命令行工具，这次更新加了 Google Workspace Admin、文档编辑、Markdown 导出、日历别名、Sheets 大升级等功能。这条推文收藏超过1000次，说明有不少人在用终端操作 Google 服务的需求。如果你在工作流里大量用 Google 服务，可以去看看。

另外，Peter 还在玩一个很有趣的东西：他用 AI 来检测并屏蔽 AI 水军账号。他设置了一个定时任务，自动识别那些只发 AI 生成垃圾内容的账号然后屏蔽掉。他把这个叫做"用 AI 对抗 AI"。这条推文引发了很多讨论，回复超过135条，说明大家对 AI 生成内容污染社交媒体这个问题都很有感触。

顺带一提，Google Labs 把 Pomelli 扩展到了全球170多个国家和地区。这条推文的互动量很高，收藏接近2800次，说明这个产品在全球有相当多的期待用户。如果你之前因为地区限制没用上，现在可以去试试了。

快速说一条来自 NotebookLM 的更新：NotebookLM 现在支持上传 ePub 格式文件了。这是用户呼声很高的功能，现在你可以把公版书、电子书直接导入，让 NotebookLM 帮你分析和对话。Google Labs 的 VP Josh Woodward 专门转发了这条，可见 Google 对这个功能还是挺重视的。

还有一条值得一提的信号。swyx 发了一条观点：如果你现在能在 AI 工程领域做出一个类别领先的开源项目，市场的收购价大概是每个 AI 工程师1000万到1亿美元。他说你不需要想清楚商业模式，不需要 GTM，不需要融资，只需要"build things clankers want"——做那些真正在用 AI 做事的人需要的东西。这条推文收藏超过1100次，说明很多人在认真思考这条路。

另外，Lenny Rachitsky 整理了 a16z 发布的消费者 AI Top 100 榜单的一些亮点。几个让人意外的发现：Perplexity 的排名比大家预期的高；removebg 是第16名最受欢迎的 AI 工具；Google AI Studio 的排名超过了 Lovable；还有三款 AI 聊天伴侣产品进入了前20名。这个榜单挺值得看的，它反映的是真实用户在用什么，而不是媒体在报道什么。

最后一条快讯，来自 Replit 的 CEO Amjad Masad 发了一个神秘预告，说"我们在做一些令人兴奋的东西"，配了一双眼睛的表情。Replit 官方账号也发了一个"我们在为你做菜"的视频。具体是什么还不知道，但鉴于最近 vibe coding 这个赛道竞争很激烈，Replit 的新动作值得关注。


好，今天最后说一条来自 Lenny Rachitsky 播客的内容，我觉得很值得单独提一下，哪怕它不是纯 AI 话题。

Lenny 采访了 Applied Intuition 的 CEO Qasar Younis。这家公司估值超过150亿美元，年收入接近10亿美元，客户包括全球前20大汽车制造商中的18家，以及美国国防部。但绝大多数人没听说过这家公司。

Qasar 有一个观点我觉得对 AI 行业的从业者很有参考价值：他说未来5到10年真正的 AI 革命会发生在物理世界，而不是软件。大家现在盯着 ChatGPT、Claude、coding agent，但真正的影响会来自自动驾驶、农业机器人、矿山设备。他的理由很具体：美国农民的平均年龄在50多岁，长途卡车司机岗位招不到人，这些劳动力缺口 AI 不是在"抢"工作，而是在"填"空缺。

另外他有一个关于安静建设的观点也挺有意思：Applied Intuition 早期的核心价值观之一是"最好的工作是安静独自完成的"。他在播客、社交媒体上几乎没有存在感，但公司做得极其扎实。他说每一分钟花在内容上，就是少了一分钟花在客户和产品上。当然他也补充说，这个策略之所以对他有效，是因为他在圈子里已经有足够的人脉基础；对于没有这个基础的新创始人，可见度可能是必要的。

这个访谈很长，但 Lenny 整理的10条 takeaway 非常值得读。我把链接放在 shownotes 里了。
