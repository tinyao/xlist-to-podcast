## 今日摘要
Anthropic 宣布从今天中午起，Claude 订阅将不再覆盖 OpenClaw 等第三方工具的用量，用户需额外购买折扣套餐或改用 API。Lenny 与 Simon Willison 的深度对谈在圈内引发强烈共鸣，Simon 坦言同时操控四个 coding agents 到上午 11 点就认知耗尽，并分享了“暗工厂”、红/绿 TDD 等一线工程模式。Cursor 设计师 Ryo Lu 发表“玻璃 vs 黑箱”宣言，强调 AI 工具应保持透明可控而非让人放弃思考。

## 重点话题
- Anthropic 订阅政策突变：Claude 订阅不再覆盖第三方工具，OpenClaw 用户需切换到 API 或购买额外套餐
- Simon Willison 深度访谈：2025 年 11 月是 AI 编码的拐点，中年工程师最危险，“暗工厂”模式正在实验，认知负荷是真实瓶颈
- Cursor 的设计哲学：Ryo Lu 提出“玻璃”理念，认为 AI 工具越强大越应该透明，用户应始终在驾驶位
