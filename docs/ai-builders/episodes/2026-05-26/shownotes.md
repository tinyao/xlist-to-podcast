## 今日摘要
Goldman Sachs CEO 明确反击 AI 就业悲观论，Aaron Levie 详解需求升级逻辑。Lenny 与 Dan Shipper 对赌十项未来预言：工作界面将内嵌到 Codex 中、PM 与设计师成为 hero、SaaS 不灭反兴、公司只需要一个超级 agent。Greg Isenberg 发布了一份极其详细、可直接执行的垂直 AI agent 创业手册。OpenClaw 继续清理依赖，体积从 140MB 压缩至 2MB。

## 重点话题
- **Lenny 与 Dan Shipper 的对赌十年预言：** 工作将发生在 Codex 内部、自动化需要人类监控、PM 和设计师是赢家、SaaS 依然值得买入、每个公司只需要一个 Slack 超级 agent。
- **Greg Isenberg 的 Agent 创业手册：** 从寻找无聊行业的痛苦工作流，到用 Hermes/Obsidian 搭建 agent 栈，再到按结果定价和通过记忆复利建立护城河的完整执行手册。

## 快讯
- **OpenClaw 大幅瘦身：** Peter Steinberger 用 Rust 编译的 WebAssembly 模块替代传统依赖，体积骤降至 2MB。

- **House of David 与 AI 制片：** Justine Moore 访谈揭示这部 5000 万观众的剧集离不开 AI，她预测未来所有影视制作都将走向混合模式。
