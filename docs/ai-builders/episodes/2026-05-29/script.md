Claude Opus 4.8 昨天正式发布，主打更强的编码、推理和诚实度。

Anthropic 的 Boris Cherny 给出核心数据：SWE-bench Pro 从 64.3 跳到了 69.2，价格不变。快速模式速度提升约 2.5 倍，同时成本降到了之前的三分之一。Box 的 CEO Aaron Levie 也在第一时间分享了企业测试结果——报告起草准确率从 Opus 4.7 的 77% 提升到 87%，法律合同审查能抓出更多关键条款，财务数据分析领先近 8 个百分点。

模型自己更愿意承认“我不确定”，甚至会主动指出自己刚生成的代码里有 bug，而不是假装一切正常。如果你今天还在用 4.7 做日常编码，现在就应该切到 4.8，交互式任务用 fast 模式，长任务丢给普通模式或者 xhigh，体验会完全不同。

另一件值得说的事，也来自 Anthropic——Claude Code 动态工作流上线了，目前是研究预览。

Claude Code 团队的 cat 介绍，只要在提示词里用到“workflow”这个词，Claude 就会自动生成一个编排方案，然后派出一大群并行子 agent 去执行。她亲身用这套机制梳理了公司上百个 A/B 测试 flag，判断哪些可以下线，之前按顺序跑会很慢，现在不到 10 分钟完成。Boris Cherny 说得更直接：动态工作流就是留给大型迁移、全仓库重构、批量 bug 修复这一类任务用的。

它消耗的 token 非常多，甚至能让同一份工作的 token 账单翻好几倍。但这个功能的目标很明确——把需要全组工程师埋头干一个季度的活儿，压缩到几天或几周。我们今天会在深聊里细说这个工作流的原理和代价，先继续看其他消息。

Vercel CLI 以实验性原生二进制形式发布了。

Vercel 的 CEO Guillermo Rauch 解释，现在 CLI 是 agent 云的关键入口——每天都有用户通过 OpenClaw、Claude Code 或者 Codex 被直接引导到 Vercel。新版本的优势很具体：体积缩小约 80%，启动快得多，而且能够自更新，不再依赖外部的 Node.js 运行时。

Guillermo 还提到一个有趣的背景，他们几年前就开发过 pkg 这个项目，想把 Node 应用打包成单个可执行文件，但当时 Git 和 Web 端爆发，CLI 需求还不大。现在情况完全反过来了——agent 时代，CLI 成了部署链路的咽喉。如果你在 CI 或者 agent 环境中使用 Vercel，今天就可以把 CLI 切换到这个原生版本，省掉一整套运行时依赖。

Visa 宣布投资 Replit，并合作研发 agentic 支付。

Replit CEO Amjad Masad 透露，Visa 内部已经有超过 1000 名员工在使用 Replit，这次合作将让 agent 能够安全、合规地处理资金转移。长久以来，agent 在“能做任何事”和“不能替用户花钱”之间有一道硬边界，这次合作相当于开始拆这道墙。对正在探索 agent to agent 支付或自动化付费流程的团队来说，这是一个值得追踪的基础设施变化。

Codex 这次更新了浏览器能力，让很多人觉得“真正的浏览器可能正在退场”。

AI 创作者、Chorus 的创始人 Riley Brown 详细描述了他的体验：Codex 内嵌的浏览器现在可以保持登录状态了，比如他打开 Notion，agent 能直接往里面写文档、发链接，用户也可以在右侧面板手动编辑，两边实时同步。这意味着你不再需要从浏览器切到编辑器、再切回 Slack，一整个任务的上下文全都在 Codex 的一个线程里闭环。

Riley 的预测很直接，未来半年内，这种 agent 内置浏览器的形态会取代独立浏览器，成为桌面电脑上的主要工作界面。如果你还没试过这种工作流，今天就找一个需要频繁在 Notion、Figma 和代码之间跳转的任务，放进 Codex 线程里试一次。

接下来这段我们多说几句。

昨天一起来的除了 Opus 4.8，还有 Claude Code 的动态工作流。这个功能背后的机制，远比“并行跑 agent”这个说法要复杂得多。你在提示词里写上“workflow”，Claude 就会先写出一份编排脚本，然后按这个脚本同时派发任务给几十甚至几百个子 agent，每个 agent 独立执行后还要互相校验，甚至会有对抗性质的 agent 专门去攻击前一个 agent 的输出，直到结果收敛才汇总给你。

Claude Code 团队的 cat 用梳理 A/B 测试标志的例子展示了它的效率——10 分钟处理完过去要手动排查很久的事情。Boris Cherny 也强调，这套机制就是为那些“以后再说”的大型重构和迁移设计的，团队可能因为风险大而推迟一整个季度，现在可以把工作交给 agent，让它在夜间或周末持续跑几天。

Greg Isenberg 的观察更形象：这些 agent 会自己争论，就像一支资深工程团队在凌晨 3 点还在改代码，永远不会累。但他也提醒，token 账单会暴涨——Anthropic 官方说得也很坦白，这就是一个“token 密集型”功能。

不过，换个角度想想。如果一次代码库迁移原本要占用三名工程师三个月，现在花 500 美元 token 费、一周内完成，这可能是整个软件预算里最划算的一笔开支。你最近有没有那种一直被搁置的大任务？比如升级框架、清理死代码、或者全仓库的类型安全改造。试着把它交给动态工作流，但记得一定要设定好执行边界和成本上限，先从小规模试起，看看你的进度条能在多少小时内走完。
