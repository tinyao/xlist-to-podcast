## 今日摘要
Cognition 完成超 10 亿美元融资，估值 260 亿，swyx 分析其作为独立 agent 实验室的完整壁垒。OpenAI 基金会承诺 2.5 亿美元研究 AI 经济影响，Sam Altman 强调提升生活质量和个体自由。Justine Moore 展示视频 agent 仅凭一条 Zillow 链接自动生成房产宣传片，预示物理空间广告将被彻底改变。Guillermo Rauch 借 GitHub 故障事件，尖锐指出软件基础设施在 agent 时代"仍然极其困难"。

## 重点话题
- **Cognition 的 agent 实验室壁垒**：swyx 拆解 Cognition 如何在模型多样性、工具调用、特定领域 RLFT 和完整 agent SDLC 上建立长期护城河，而非依赖单一模型或产品。
- **GitHub 故障与 Agent 幻觉**：Guillermo Rauch 指出，即便拥有顶级团队和模型，一句 prompt 也无法解决复杂生产系统的基础设施问题，agent 能找低垂果实，但理解系统仍需人类。
