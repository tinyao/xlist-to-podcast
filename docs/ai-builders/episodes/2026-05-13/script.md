Krea 2 正式发布，这是一个从零开始训练的全新图像基础模型。
a16z 的合伙人 Justine Moore 昨天连续发了好几条推文，分享她的体验。
她说自己玩了一整周，被这个模型的审美彻底震撼了。
最核心的卖点不是生成速度或者分辨率，而是“美学多样性和风格控制”。

Krea 2 有一个叫“情绪板”的功能，是 Justine 最喜欢的部分。
你可以上传自己的图片，或者从公开的作品里挑选，训练一个专属的风格板。
生成图片时，能像调音量一样，实时控制风格影响的强度。
Justine 说她现在已经建了 10 个不同的情绪板，每个都能稳定输出一种独特的视觉风格。

她的原话是：“让图像模型重新变得有艺术感。”
这句话的背景是，过去一年 AI 生成的图片越来越精致，但风格也越来越趋同。
Krea 2 想解决的就是这个问题——不是做更逼真的图，是做更有态度的图。
如果你在做品牌设计、游戏美术或者内容创作，这个工具值得上手试一下。

另一件值得说的事。
Greg Isenberg 昨天放出了一套完整的课程，教人怎么用 agent 接单赚钱。
他是 Late Checkout 的 CEO，一直在孵化创业想法，这次直接把自己的打法全部公开了。
课程的核心框架很清晰：你卖的不是 token，不是模型，而是一个“数字员工”。
客户按月付费，不需要知道背后是 GPT 5.5 还是 GLM 5.1。

Greg 给了十条具体建议，其中几条特别实在。
第一条，不要急着切垂直赛道。先同时试营销公司、律所、保险、制造、房地产，看哪个行业的需求拉你走。
第二条，所有老板的痛点都一样——邮件太多、会议太多、待办太多。先把这些通用问题解决掉，再叠加行业专属技能。
第三条，用 agent 来搭建 agent。让 Claude Code 或 Codex 自己去虚拟机里安装配置 agent 框架，你只做验收。

他推荐的模型组合是 GPT 5.5 做主力，因为工具调用效率高、不浪费 token。
便宜任务用 ZAI 的 GLM 5.1，是目前最好的开源选项。
整套栈包括 Hermes Agent 做 agent 外壳、Orgo 提供云端沙箱、Composio 一键接入上千个应用的认证、Agent Mail 给每个 agent 分配独立邮箱。
Greg 说如果你能搭起这套东西，你就拥有了一项 99% 的老板都不会的技能，他们愿意为此付每月五千美元。

这个数字值得留意。
五千美元一个月，不是卖软件，是卖服务。
而且 Greg 强调，获客靠内容——如果有人跳上销售电话时已经知道你是谁、你卖什么，那就是最理想的状态。
如果你在考虑用 agent 做一门小生意，这套课程值得花 47 分钟看完。Shownotes 里有链接。

Claude Code 的 Agent View 功能昨天正式上线 research preview。
这是 Anthropic 的 Boris Cherny 和 cat 同时推荐的新功能。
用法很简单：在终端里跑 claude agents，就能看到一个所有会话的控制面板。
从任何一个 CLI 会话按左箭头，就能把它注册到面板里。
cat 的建议是，在你的根代码目录里跑这个命令，统一管理所有 agent 会话。

Boris 说这是从“一个 agent”升级到“多个 agent”的最佳方式，不用再在终端标签页之间来回切。
如果你同时在跑多个开发任务，这个功能能省掉大量上下文切换的麻烦。
不过，这个功能昨天在往期节目里已经提过，今天就不展开了。

Boris 本人昨天还分享了另一段经历，挺值得说。
他用 Claude Cowork 订了一堆出差机票和酒店。
Opus 4.7 一次性完成了全部预订——8 张机票、5 家酒店，零差错。
他说自己只是在 Cowork 的指令里写了出行偏好，然后就让 agent 自己去浏览器里操作。
整个过程他都在 Claude Code 里写代码，根本没管。
Boris 的原话是：“再也不用手动订机票了。”

这跟两天前我们聊过的“Codex 自己去赚 5 美元”是同一条线。
agent 正在从帮工程师写代码，扩展到帮任何人处理真实世界里的复杂任务。
订机票这件事听起来简单，但它涉及多个网站、多种支付方式、日期和舱位偏好。
能一次性跑通，说明 agent 处理多步骤、跨平台任务的能力又上了一个台阶。

过去 24 小时，有两条线同时指向了同一个方向。
第一条是 Julie Zhuo 昨天发的长文，讨论怎么把人的品味教给 AI。
第二条是 Greg Isenberg 的 agent 生意经，以及 Zara Zhang 对 AI 产品定位的吐槽。
这两条线看起来不相关，但放在一起，你会发现一个正在被重新定义的东西——专业判断力的价值。

先说 Julie。
她是 Sundial 的创始人，之前在 Facebook 做设计副总裁，写过《The Making of a Manager》。
她说自己最近在带 Sundial 的分析师团队，做了一件非常 humbling 的事。
就是把优秀分析师脑子里的判断，写成 AI 能理解的指令。

举个例子。
“一个真正好的分析师，看到这个指标变动时，脑子里在想什么？”
“这条新闻里，什么是有意义的信号，什么是噪音？”
“怎么判断一个产品改动，是真的带来了影响，还是随机波动？”
这些问题，人类专家凭直觉就能回答。
但要把它们写成 AI 能稳定执行的规则，极其困难。

Julie 描述了整个过程。
你写一套指令，AI 没抓住重点。
你加更多上下文，AI 反而更困惑。
你精简回去，AI 又变得太模糊。
换一种表达方式，效果好一点，但不稳定——周一能用，周二就翻车。
她说，从 70% 的质量做到 95%，不是靠三四个大改进。
是几百个微小的判断，一层一层叠上去。

她的结论是：这个差距，就是“品味”的量化。
是你做了几千次判断之后积累下来的东西，你自己甚至意识不到你在做这些判断。
直到你坐下来，试图把它们写出来，才发现根本写不清楚。
“擅长做一件事”和“能说清楚你为什么擅长”，是两种完全不同的能力。

Julie 说现在做 AI 产品有两个瓶颈。
第一，你能不能先看到“更好”长什么样。
第二，即使你能看到，你能不能把它翻译成 AI 能理解和系统化的指令。
第二条，正在变成一门新的手艺——把艺术蒸馏成规则的艺术。
而能做好这件事的人，就是那些正在打造 standout 产品的人。

Zara Zhang 昨天的几条推文，从反面印证了同一个问题。
她收到大量 AI 新产品的推广私信，发现它们的定位和文案全部长得一模一样。
“一个能连接所有应用的 personal AI agent。”
“一个全托管、永远在线的 AI agent。”
“一个 AI 原生的工程系统，跨 CLI、VS Code、桌面端。”
她说这些产品没有一个能激发好奇心，看完只想说：“我还不如直接用 Claude。”

Zara 还发现了一个细节：AI 在设计网页时，特别爱用斜体字。
她说这已经变成了 AI 设计的“破绽”，就像 AI 写作爱用破折号一样。
她干脆在系统提示里加了一句：“禁止斜体和 Instrument Serif 字体。”
这件事很小，但背后是同一个逻辑——AI 能生成东西，但它不知道什么是“有品味的克制”。

把 Julie 和 Zara 的观察放在一起，你会发现一个正在成型的职业壁垒。
Greg Isenberg 教人用 agent 接单，门槛低到一个人加一套工具就能跑。
但 Julie 说，把一件事从 70 分做到 95 分，需要几百个微小的判断。
这两件事并不矛盾。
Greg 解决的是“怎么让 agent 跑起来”。
Julie 解决的是“怎么让 agent 跑得好”。

对听众来说，这个判断有一个很直接的启发。
如果你现在的工作里有一部分是“做判断”——审合同、看数据、定设计方向、写策略——试着把其中一条判断写下来，交给 AI 去执行。
不是为了省时间，是为了感受一下 Julie 说的那个过程。
你会发现，你以为自己能说清楚的东西，其实说不清楚。
而能说清楚的那部分，就是你的专业壁垒。
这种“蒸馏品味”的能力，正在变成 AI 时代最稀缺的手艺。
