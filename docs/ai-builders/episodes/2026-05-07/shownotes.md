## 今日摘要
Anthropic 与 SpaceX 达成算力合作，Claude Code 额度翻倍并取消高峰限制；Greg Isenberg 给出 AI 原生创业方向的 2x2 矩阵，指出高复杂度、高重复度流程是 agent 的主战场；Peter Yang 对市面上主流个人 agent 工具做了深度横评，结论是这场仗还没人打赢；Zara Zhang 提醒开发者工具正在错失“非开发者”用户群体。

## 重点话题
- **Anthropic 算力剧变**：与 SpaceX 达成合作，一个月内 300+ MW 新增容量及 22 万块 GPU 上线，Claude Code Pro/Max 峰值限制取消、额度翻倍
- **Greg Isenberg 的 2x2 矩阵**：高复杂度且高重复频次的流程（保险、招聘、合规）才是 AI 原生公司的真正金矿
- **个人 agent 横评**：OpenClaw 最灵活但易崩，Hermes 较可靠，Claude Code 有 98% 可用率，Codex 缺移动端，Gemini 缺基础文档编辑
