## 今日摘要
Claude Opus 4.7 上线，Anthropic 团队密集推出 auto mode、xhigh effort、focus mode 等全新工作流，要求开发者从 pair programming 转向委托式协作。OpenAI Codex 加入电脑操作能力，并发布首个生命科学前沿模型 GPT-Rosalind。Discourse 用 AI 扫描月更，公布 50 个 CVE 修复，为开源安全提供了与闭源不同的路线。Vercel Workflows 正式 GA，Guillermo Rauch 称其为代际级发布。

## 重点话题
- Claude Opus 4.7 + 新工作流：auto mode、effort 控制、focus mode、自我验证，如何从“逐行审”变成“委托后走开”
- Codex 电脑操作 + GPT-Rosalind：Mac 端并行操作应用不加干扰，同时首次推出生命科学垂类前沿模型
- 开源安全路线之争：Discourse 坚持开源，用 GPT-5.4 xhigh 扫描出 50 个 CVE，Peter Steinberger 称为风向标
- Vercel Workflows GA：面向 agent 和后端的持久化执行模型，自称 Next.js 对前端的意义
