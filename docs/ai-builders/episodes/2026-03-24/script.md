昨天所有推文里，Thariq 那条的收藏量遥遥领先，说的是：Claude Code Desktop 现在可以控制你的鼠标、键盘和屏幕了。今天是 2026 年 3 月 24 日，欢迎收听 AI Builders Daily。

这个功能的官方名字叫 computer use。在 Claude Code Desktop 里，Claude 现在可以直接在操作系统层面工作——鼠标点击、键盘输入、截屏看状态，任何应用程序它都能上手。

配合这个功能最好用的工具，是 Felix Rieseberg 做的 Dispatch。逻辑很简单：你不在电脑前，Claude 替你在电脑上工作，你从手机上远程发指令。Thariq 在发布 computer use 时直接引用了 Felix 的推文，等于给这个搭配方式背书了。

computer use 这个能力，Anthropic 很早就在 API 层面开放过。但现在它落进了 Claude Code Desktop 这个日常工具里，不需要自己搭架构，开箱即用，意义不一样。

这条消息发出后，Peter Yang 在评论区发了一个简单的问题：你们各自把 Claude Code 和 OpenClaw 用来做什么？冒出来一百多条回复。他自己给了一个诚实的对比：Claude Code 的远程控制目前还不够稳定，也没有语音回复，当手机上的个人助手体验差了一些；OpenClaw 偶尔会随机忘事，但语音和权限直通让它在手机场景更顺手。这不是谁好谁坏的问题，是两个工具各自的真实边界。

说到 OpenClaw，Peter Steinberger 昨天发布了新的 beta 版本。但他那天被更多人转发讨论的，是另一件事——他分享了一张截图：一名用户发邮件来，要求"因为 AI 犯了错误"退款。这张截图拿到了将近六千个点赞，在昨天所有内容里互动量排第一，比任何产品发布都高。

为什么这么多人共鸣？因为它触了一个大家都开始感受到、但还没说清楚的东西：当我们开始用真实的钱购买 agent 的服务，"AI 犯错了，该谁负责"就不再是一个学术问题，而是一封可能出现在你邮箱里的邮件。这类事情会越来越频繁，而行业规则还没准备好。

接下来说昨天互动量最高的两条 AI 内容，一条关于广告，一条关于学习。放在一起，它们在说同一件事。

Greg Isenberg 发了一个短视频，演示用 Claude Code 在三十分钟内批量创建并上线一百多条 Facebook 广告——从广告模板到发布，完整流程，全程在 Claude Code 里完成。这条视频的收藏数超过三千一百，是昨天所有内容里最高的数字，甩开第二名一大截。

三十分钟、一百多条广告。如果你接触过广告投放，你知道手工做这件事意味着什么。Claude Code 在这个场景里不是辅助工程师写代码的工具，它是广告团队的操作员。做营销的人在发现它，不是程序员。

另一条是 Zara Zhang 发布的一个 Claude Code skill，名字叫 codebase to course，可以把任意代码仓库生成一套互动式教学课程：有可视化，有平实的解释，还有测验。她的出发点很直接：我用 vibe coding 建了很多东西，但根本不知道代码背后是怎么运行的。这个 skill 专门设计给这类人——先建，再懂。

收藏量接近一千六百。一个学习工具能有这个数字，说明它戳中了一个比较普遍但没人说出来的不安：我用 AI 生成了代码，但我真的理解它吗？如果出了问题，我能修吗？

FirstMark 的 VC Matt Turck 昨天顺手说了一句话：以后很难向年轻人解释，曾经有一段时间，有了想法的人要花几年去找一个"技术联合创始人"。语气不是感慨，是陈述历史的口吻。

接下来两条性质完全不同的新闻，但都值得停一下。

Sam Altman 昨天宣布，他从 Helion 的董事会辞职了。

Helion 是一家核聚变能源公司，Sam 从 2015 年就在董事会，算是十年老支持者。他解释辞职原因很直接：OpenAI 和 Helion 正在探索"大规模合作"，他同时在两边有治理职责，在谈判中会造成冲突。辞职不是关系变坏，是为了让合作能更顺畅地推进。他特别补了一句，自己对 Helion 未来的进展"相当有信心"，只是退出治理角色，财务权益保留。

这里面有一个逻辑值得认真想。AI 训练的电力消耗是一个越来越真实的工程问题，不是遥远的将来，是现在每天都在发生的事。OpenAI 开始认真布局能源来源，和核聚变公司探索大规模合作，这件事的体量和影响还没有被充分讨论过。

同一天，还有另一个人才流向。Dreamer 团队——David Singleton 带着整个团队——整体加入了 Meta Superintelligence Labs。

Dreamer 大约一个月前才上线 beta，是一个让普通人用英语"编程"的 personal agent 平台：你用对话描述你想要什么，它帮你搭出来，不需要写代码。从 beta 上线到整体并入 Meta，不到两个月。

Meta Superintelligence Labs 这个名字不是摆设。这是 Zuckerberg 公开押注 AGI 方向的主要战场，Dreamer 团队进去，意味着 Meta 在 personal AI software 这条线上有了一支有完整产品经验的团队。

swyx 看到这个消息，跑来开玩笑说他发现了一个规律：在 Latent Space Podcast 上出现过的人，最后好像都被砸钱了。当然是调侃，但 Dreamer 的速度是真实的。

几条快讯。

Justine Moore 昨天发了一句话，传得挺快：「我从来没学会写代码，先是太难了，后来是太简单了。」一千两百多个点赞。这句话有意思的地方不在于调侃，而是它精准描述了一个消失的窗口期：我们以为"学会写代码"是一件要花很长时间的事，然后这件事本身不再重要了，而且这个转变快到大多数人还没反应过来。

Lenny Rachitsky 发布了一份读者调查：AI 如何改变了大家对工作的感受？核心结论是：多数人觉得有了 AI 工作体验更好了，但同时对自己岗位的安全感也在下降。生产力提高了，工作量却没少。有一种「带着孩子般的好奇感，同时又被信息轰炸搞得很疲惫」的混合感受，正在成为很多人工作日的底色。

Factory 的 Missions 功能昨天向所有用户开放了，定位是长任务 agent——从头搭应用、代码迁移、AI research，都在目标范围内。CEO Matan Grinberg 说这是他见过的最自然的长任务 agent 实现，在等用户来验证这个判断。

swyx 重新分享了一篇关于 Devin 的文章，带了一个数字：今年 Devin 每个月的用量都在增长超过 50%，而且连续几个月，连 Cognition 内部都感到意外。Claude Code 拿走了大部分的公众注意力，但 Devin 在企业场景里，正在安静地加速。

郭宇的 vibelab 上线了直播回放功能——视频流和终端操作记录同时保存，以后的 vibe coding 直播都可以看重播。另外，他看到 Tailscale 发布了 Aperture，一个支持反向代理所有 API Key 的中央网关，直接在推文里喊话："这不就是我做的 nkmc.ai 吗？思路一模一样。" 他的反应不是沮丧，而是认为大公司同时在做同一件事是一个方向正确的信号。

今天这几件事，有一个线索可以把它们串起来。

Claude Code 接管了鼠标和键盘；有人用它三十分钟发了百条广告；有人用它读懂自己的代码；有人在认真问 AI 犯错了该不该退款。Sam 在能源和 AI 之间搭桥；Dreamer 团队两个月内完成了一次快速整合。

Justine Moore 那句话，说的其实不只是编程：太难了，然后是太简单了。很多我们以为需要花时间学会、花时间找人的事，正在以我们来不及感受到的速度变成另一件事。

今天有一件可以马上去试的事：Zara Zhang 的 codebase-to-course，在 GitHub 上，把你最近用 AI 生成的代码仓库拉进去，看看 Claude 怎么向你解释它。就算不打算学，看一遍也值。
