## 今日摘要

Claude Code Desktop 正式支持鼠标键盘屏幕控制，同时一封要求 AI 犯错退款的邮件截图在推特上引发近六千点赞，折射出用户对 agent 责任归属的新期待。Greg Isenberg 演示用 Claude Code 三十分钟上线百条广告，Zara Zhang 的 codebase-to-course skill 引爆转发——两者共同说明 Claude Code 的核心用户早已超出程序员范围。Sam Altman 从核聚变公司 Helion 辞去董事职务，以推进 OpenAI 与 Helion 的大规模能源合作；Dreamer 整队并入 Meta Superintelligence Labs，从 beta 上线到整合不到两个月。

## 重点话题

- **Claude Code Desktop 接管鼠标键盘**：computer use 功能正式落地，配合 Dispatch 工具可实现远程控制；Peter Yang 发起的 Claude Code vs OpenClaw 对比引发百条真实用户反馈
- **退款邮件走红**：OpenClaw 用户要求因"AI 犯错"退款的截图拿到近六千点赞，折射 agent 责任归属正在成为真实议题
- **Claude Code 走进广告部门和课堂**：Greg Isenberg 演示三十分钟上线百条 Facebook 广告；Zara Zhang 发布 codebase-to-course，帮助 vibe coder 理解自己生成的代码
- **Sam Altman 从 Helion 辞职**：为 OpenAI 与这家核聚变公司探索大规模合作让路，AI 能源布局开始浮出水面
- **Dreamer 整队并入 Meta**：personal AI software 团队从上线到并入 Meta Superintelligence Labs 不到两个月
