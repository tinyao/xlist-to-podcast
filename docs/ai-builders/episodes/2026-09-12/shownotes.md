## 今日摘要
Claude Code 正式推出插件 eval 功能，让开发者能测试自定义插件是否真的有效。Replit 收购了完全在自己平台上成长起来的公司 Test 13，这家两人团队 18 个月创收超 70 万美元。Anthropic 的 Boris Cherny 公开了他对 AI 生成代码质量标准的邮件回复，引发了一场关于“AI 写的代码该不该比人写的更严格”的热烈讨论。OpenAI Agents API 被比作“agent 的 AWS 时刻”，而 Box 则推出了让企业 agent 直接挂载云端文档的 Box Mount。

- Claude Code 插件 eval：让 agent 插件可测试、可评估，解决“模型升级后插件还管用吗”的痛点
- Replit 收购 Test 13：AI 编程工具催生新型商业模式的典型案例，两人团队 18 个月 70 万美元
- Boris Cherny 的代码质量标准：AI 生成的生产代码应该比人写的更严格，引发工程师圈激烈讨论
- OpenAI Agents API 生态影响：被比作 AWS 时刻，agent 基础设施层正在成型
