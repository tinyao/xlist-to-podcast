Sam Altman 说 Codex 正在经历一个“咕噜时刻”，这个说法背后是一连串的功能爆发。Airtable 的 CEO 透露自己用 30 个并行 agent 来写代码，而且白领劳动力总量才是 agent 的真正目标，这是多大的市场？郭宇决定把自己所有产品的订阅制全部砍掉，只留按需付费，为什么？先从最让人睡不着的那件事说起。

Codex 昨天迎来了一波密集的功能展示和生态联动，Sam Altman 本人连发数条推文，语气很兴奋。
他一开始说，感觉 Codex 正在经历一个 ChatGPT 时刻。随后又更正为“我是指咕噜时刻”。
这个说法是在回应社区观察到的一个行为——Codex 在处理长任务时，即使 token 配额耗尽，也会继续把任务跑完。Sam Altman 转发了这个观察，说他喜欢团队做这样的事。

同一时间，OpenClaw 的负责人 Peter Steinberger 披露了一个更具体的 Agent 流水线。他现在在每次代码提交到主分支时，会启动一个 Codex 实例做自动审查。如果发现 bug，系统会再拉起一个新的 Codex 实例自动提交修复 PR。之后还会再启动一个审查 agent 检查这个修复，整个过程最多循环五轮。他晒出的记录显示，这个系统上线十分钟就发现了代码中的问题。Steinberger 说这还不是最终形态，后续还要把 Codex Review 集成到他的 clawsweeper 工具里。

对听众来说，这套流水线给出的是一个可复用的范式：CI 系统不再只是跑测试，而是可以直接挂载具备审查和修复能力的 agent。如果你在用 Codex 或类似工具，现在就可以思考一个问题：你的 CI 管道里，哪个环节最需要这种自动闭环的审查-修复循环？

另一件值得说的事。Airtable 的 CEO Howie Liu 昨天和 Greg Isenberg 做了一期深度播客，信息量非常大。
Howie Liu 透露了几个具体的数字和行为。他本人现在用 30 个 Claude Code 实例并行工作，每个实例挂载一个浏览器，完全自主运行。这些 agent 实例会互相审查对方的 PR。他最近一次给董事会写的战略备忘录，也是用 AI agent 完成的，花费了 150 美元的 token 成本，耗时却只有原来的十分之一。他最好的投资人反馈说，这是他写过最好的备忘录。

Howie Liu 还正式推出了 HyperAgent，定位是一个可视化的 agent 构建器。他的原话是，HyperAgent 对 agent 的意义，就像 iPhone 对计算的意义——能力本身已经在，但可及性改变了一切。为了推广这个产品，他通过 Greg 的频道给前一千位用户提供一千美元的免费额度。

顺带说一句，Greg Isenberg 自己也在推文里给出了一个非常直白的判断。他说 AI agents 在大多数行业的渗透率现在还不到百分之十，即便在软件工程领域号称百分之五十，那也高估了，因为大部分开发者还停留在“tab 自动补全”的阶段。

这件事对听众的启发很具体。如果你是创业者或 team lead，Howie Liu 演示的是一种未来型企业高管的操作方式——不是把 AI 当辅助，而是把整个软件生产流程交给 agent 集群。而他的 HyperAgent 则提供了一个产品方向：agent 的工具化机会正从前端交互，转向后端编排和管理。

换个方向。郭宇昨天宣布了一个相当激进的决定。
他要把自己所有产品的订阅方案全部取消，已经付费的用户会返还对应的消费额度。以后他所有的 vibe 产品都不再设置 Pro 等分级方案，所有功能对所有人免费开放，唯一保留的盈利模式是按需付费。他这几周会优先改造 tuwa ai 来适配新的费用计划。

郭宇同时分享了两个产品的关键数据。wanman 是他所有产品中次日留存最高的，超过百分之五十。tuwa 是 DAU 最高的，他估计会成为他第一款 DAU 过万的 vibe 产品。

不设置付费墙、只留按需付费，这对独立开发者来说是一个高风险、高自信的商业信号。如果你也在思考自己的产品如何定价，郭宇这个动作提供了一个观察样本——但要先看他后续公布的具体按需费率。

Replit 昨天连发两个产品动作。CEO Amjad Masad 宣布 Replit Agent 现在具备了应用监控能力，可以在生产环境中观察应用、排查问题并协助修复。换句话说，agent 不仅要帮你写代码，还要帮你运维。另一件事，Replit 为教育用户推出了专属方案，教师免费，学生半价，现有 1800 万学生用户在 Replit 上构建。

说到 Google 这边，AI Studio 昨天新支持了多聊天线程，同一个 app 里可以开多个对话，同时集成了 Search Grounding，可以在构建过程中拉取新上下文。Gemini App 也上线了文件生成和导出功能，现在可以直接输出 Google Docs、Sheets、Slides，以及 Word 和 Excel 格式的文件。Google Labs VP Josh Woodward 说这些功能已经在所有端口全球上线。

接下来这段我们多说几句。
今天值得展开聊的，是 Howie Liu 和 Greg Isenberg 那期播客。它几乎是对 agent 商用形态做了一次全景式的推演，量化锚点非常密集。

起因是这样的。Greg Isenberg 直接问了一个问题：AI agents 是不是有一万亿美元的市场机会。Howie Liu 的回答比他问得还要大——他说这远不止一万亿，这是整个白领劳动力的 GDP，价值数十万亿。

然后 Howie Liu 用一连串的具体行为，展示了他自己是怎么把这段话活成工作流的。他描述的画面不是 CEO 在用 AI 提效，而是 CEO 本人变成了一支 agent 集群的指挥者。30 个在跑的 Claude Code 实例，互相看 PR，自己用 agent 写战略文件。他甚至用一个非常反直觉的用词来描述写董事会备忘录这件事：耗时是十分之一，成本是一百五十美元，但质量是最好的。

Greg 这边补充的视角也很有意思。他观察到大部分人根本没真正用过 agent，他们拿 agent 当聊天机器人使，问谁会赢得下次选举，而不是扔给它一个真正的多小时任务。他的建议是，你必须花一整个周末沉浸进去，用才能信。

这两人的话放在一起看，会发现一个共同指出的矛盾。agent 的能力已经明显领先于人的使用模式。Howie Liu 的操作方式说明，agent 可以做完整的端到端工程流水线。Greg Isenberg 的观察说明，大多数人才刚离开“随问随答”的阶段。这两者之间的落差，就是现阶段的时间窗口。

如果把这个思考落回到你自己的工作上。你可以问自己一个问题：你现在每天打开 agent 工具，是在问它一个个独立的问题，还是在给它一个可以运行几小时的闭环任务。后者的占比，可能直接决定了你和最前沿实践之间的距离。

OpenAI 的 Kevin Weil 转发了一组关于放射科医生的数据。过去十年，AI 曾被预测会替代放射科医生，但现实是他们的收入涨到了年薪五十万美元以上，岗位还在增长。他说了一句很关键的话：放射科医生的工作不是看 X 光片，是治愈病人。AI 让看片更快，他们就能治疗更多人。
