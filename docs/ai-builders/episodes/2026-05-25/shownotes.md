## 今日摘要
Dan Shipper 在 Lenny 播客中给出了六条反直觉的年度预测，核心论点是 AI 不会替代人，而是让旧能力变廉价后迫使人类往上走。Codex 与 Claude Code 的竞争路线进一步分化——一个拼端到端能力，一个守设计品质。Aaron Levie 指出 CEO 最容易产生 AI 幻觉，因为他们离最后落地的那一公里太远。此外，AI 视频创作进入可观看时代，开发者开始用 agent 替代 GitHub 作为代码仓库的核心。

## 重点话题
- Dan Shipper 六条年度预测：AI 不是自动化谎言，SaaS 会大涨，大规模失业不会发生
- Codex 与 Claude Code 路线之争：模型进步 vs 设计品质，选工具要看核心需求
- CEO 的 AI 幻觉：为什么最顶层的人最容易误判 AI 落地难度
