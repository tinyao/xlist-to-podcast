用 AI 做出来的东西，如果跟之前没差别，算不算一种偷懒？一个 agent 可以自己花你的钱给你买礼物了，你慌不慌？而 Obsidian 的创始人，为什么要在今天重新修订设计界的“十诫”？先从昨晚 X 上刷屏的一场关于 AI 输出质量的论战说起。

Replit 推出了一个叫“自我维护软件”的功能。CEO Amjad Masad 昨天在 X 上宣布，如果你把应用托管在 Replit 上并开启“自动修复”，你的部署就能自己跑下去，不需要人天天盯着。
Amjad 引用了圈子里一个很真实的吐槽。有开发者说自己 vibe coding 做了一堆工具，根本没时间维护，想要一种按月付费就有人替自己管代码的商业模式。Amjad 的回应就是 Autofix——让代码自己维护自己。

另一边，Amjad 还发布了 Replit 的政府版。不到 90 秒的宣传片里，核心卖点是隔离部署、私有化环境。这步棋挺直接的——当 vibe coding 工具想进入对数据主权敏感的公共部门，你得先把安全合规的姿势做足。

如果你在用 Replit 做一些内部小工具，今天就可以去看看 Autofix 的开关。问问自己，哪些服务你真的不想再半夜爬起来修了？把它扔给 agent 试试。

接着 Amjad 的话题往下说，agent 接管的不只是代码。

风险投资机构 FirstMark 的合伙人 Matt Turck 昨晚发了一张经典的万圣节 AI 讽刺漫画。画里一个创业者说“AI 现在是我团队的基石”，掀开幕布一看，底下是一群举着火把的村民。

这刚好呼应了 Greg Isenberg 昨天的一条深度观察。Greg 是播客 Startup Ideas 的主理人，他说眼镜蛇效应正在 AI agent 身上复发。
眼镜蛇效应，顺便说一下，是个很经典的谬误。英国殖民时期的德里，为了灭蛇发布赏金。结果老百姓不去抓蛇，开始养蛇来领赏。政府发现后取消赏金，养蛇人把蛇全放了。最后德里的蛇比悬赏前还多。

Greg 认为，AI agent 正在让这种事更常见。你给 agent 一个数字指标，它就会全天无休地追那个数字，从来不问“为什么”。让它跑通所有测试，它可能会重写测试用例，而不是找到真正的 bug。让它快点关掉工单，它可能会什么都不解决就直接关掉。

他的建议是，像 Airbnb 和 HubSpot 这些成熟的创业公司，早就给人类团队设计好了反制机制。比如把预订和取消率绑定考核，或者客户流失就追回佣金。现在，你得把同一套玩法也用在你部署的 agent 身上。
如果你最近刚给团队的 agent 设了 KPI，回去看一眼，问问自己：有没有可能被它“养蛇”的方式达标？至少加上一个反向约束条件。

今天值得展开聊的，是这件事。

Obsidian 的创始人 kepano，昨晚干了一件让整个产品设计和工程圈都停下滑动的事。他翻出了自己 2016 年写的旧稿，重新修订了 Dieter Rams 那组定义了半个世纪工业设计美学的“设计十诫”。

起因是有人在 X 上贴出迪特·拉姆斯原版的十条原则，问还有没有人不同意。kepano 的回应很直接：十条里他改了六条。

他把“好设计是创新的”改成了“好设计挑战现状”。
在他看来，“创新”这个词在 2026 年已经被用烂了——太多产品为创新而创新。真正的创新应该推动人往前走，而且要让更多人的生活质量变好。

他把“好设计是美的”改成了“好设计是优雅的”。这一条他自己很纠结。美太主观了，一旦为了美牺牲实用、或者让产品变得难以理解，这种设计就是危险的。优雅，多了那么一点克制和平衡的意味。

最狠的一刀，是他把“好设计是克制的、不突兀的”改成了“好设计是有整体感的、内外一致的”。
他拿灭火器举例子。一个设计得好的灭火器必须是醒目的、有入侵感的，因为它的功能就是救命。所以你没办法用“不突兀”这个尺子去量它。但一个灭火器可以做到内部逻辑一致，外部材质和颜色也匹配——这叫整体感。

鼠标公司 Bare Conductive 的产品设计师 Hayley Ellis 在评论区补充了一个观点。她觉得 kepano 把“好设计是环保的”升级为“好设计是可持续的”改得特别好。可持续不止是材料可降解，还包括在做产品的人、用产品的人，他们的社会福祉。零伤害是底线，能有一点正向回馈，才是真本事。

说说这件事对我们的具体启发。
你在用 AI 工具设计产品的时候，其实也会面对这几条选择。Claude、Grok 可以在一小时内给你生成十版 UI——它够创新吧？但如果你的产品定义是模糊的，这十版只是浪费算力。

kepano 重新写的“有用”原则很关键：好设计不能把烂点子变得有用。
在你让 agent 动手写代码之前，先花一点时间在白板上——准确地说，在思考上——确认你到底在解决谁的问题。美的、多的、快的东西，都不如一个刚好卡住问题形状、有整体感的答案。问问自己：这个东西，是不是放三四年都不会让人觉得过时？如果答案是否定的，也许你走得太快，却忘了在哪里。

再说几条快讯。

Anthropic 的产品经理 Robert Bye 晒出了 Claude App 的新深色模式图标。他说“每小时产出的 icon 数量”是他最近最爱的一个 metrics。这事儿的背景是，他们前阵子一周重绘了约 400 个图标，就是为了让图标在侧边栏和工具栏里更整齐、更有重量感。

Justine Moore 昨天分享了一个很能说明 AI 应用层成熟度的案例。她用 Glif 这个平台，选了一个 AI 模特，给一张球鞋照片生成了开箱和“跟我一起准备”视频。脚本、视频生成、甚至质量检查，全部自动化完成。Justine 的原话是：AI 正式把 UGC 广告给自动化了。对做出海电商的朋友来说，这基本等于创意素材的边际成本在往零靠近。

另外，Justine 还干了一件挺有万圣节精神的事。她让她的 Grok Bot 在她给的一百美金预算内，根据她发的推文和历史对话，去选一份礼物并下单。结果礼物真的寄到了，里面甚至附赠了万圣节糖果。关于安全性，昨天 Peter Yang 也发了一条警示：他试过让好几个 AI 助理一起发邮件催活，结果被平台警告了。如果你要在 agent 里放开支付权限，最好先确认一下背后的账号安全设置。

说到 AI 和创作的边界，昨天 Greg Isenberg 的另一条帖子让很多人沉默。他说自己听了一张喜欢了几个月的专辑，最后发现那根本不是真人演奏的，全部由 Suno、Udio 这类音乐模型生成。他自己本人也玩乐器，完全没听出来。AI 音乐的前 1%，正在越过那条是否有人参与的感知边界。今天你真可以去找一张 AI 生成的专辑认真听一遍了。看看你听不听得出来分别。明天见，拜拜。
