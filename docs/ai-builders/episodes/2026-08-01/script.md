直播时代，AI 带来的机会是不是正在重新洗牌？软件开发的工作流到底被 agent 改变了多少？Sam Altman 的几条动态指向了 OpenAI 的哪个方向？先从今天最扎实的一组数据开始。

软件开发的 agentic 工厂模式正在变成日常。

昨晚 Guillermo Rauch 转发了一条 Turborepo 的数据，周下载量突破两千万次、零已知问题。Guillermo 随即做了一个判断：这将是软件项目转向 agentic 软件工厂后的常态。他给出了一个闭环公式：Issue 被创建，agent 接手处理，生成 PR，然后发布。人的角色退到设定质量标准、判断什么值得做。

Linear 的产品负责人 Nan Yu 随后补充了一组更具体的内部数据。

她说 Linear 上最常见的流程确实就是这个闭环。大约 30% 的 bug 已经能走完 Issue 到 Agent 到 PR 到 Release 的全流程。但她同时强调了一个容易被忽略的坑：必须明确告诉 agent 先做充分的根因分析。要去查 Datadog、Sentry 的 MCP 数据，只有在置信度足够高时才动手修复。否则会烧掉大量 token，效果还差。如果信噪比不够，agent 应该主动在 issue 下面留言，请报告者补充复现步骤。

Nan 的原话是：agent 也需要被要求遵守好工程实践，跟人一样。

另一件值得说的事，Sam Altman 昨晚连发三条。

第一条，他转发了一组成本对比数据。GPT-5.4 在最高推理水平下的定价是输入两块五、输出十五美元每百万 token。而 OpenAI 四个月前发布的 Luna 模型，今天同样性能的成本降到了输入两毛、输出一块二。Sam 的评论是：“你搬出摩尔定律，我加注二十倍。”

这条转发在圈子里传了一夜。它不是一个技术发布，但清楚地表明了 OpenAI 在成本曲线上想传递的信号。

第二条，他转发了一条关于模型能力进步的观察：真正的好模型来的时候会有预兆——负载在涨，可靠性反而上升；突然出现效率跃迁；东西变快；以及某种重置感。Sam 的评论只有一句：“可以更快。”

第三条是一个产品用例。他提到有人把全家人的日历连到 ChatGPT，输入每个孩子的兴趣。每天早上送学路上，ChatGPT 生成一个定制播客：念叨今天下午谁的足球比赛、谁快过生日了、再加点新闻。Sam 把这条定义为“cool use case”。这大概是今天群里最像活人分享的一条。

说完工程流，换个方向。今天 swyx 的一条 protip 引发了比较多的讨论。

原话是：如果你会蒸馏模型，你也能蒸馏 agent harness。

具体逻辑是，可以让 agent harness 自己架设一个 MITM 代理，截获发给底层模型的 prompt。swyx 说这对 Cursor、Claude Code 这类工具都管用。有人追问他这是不是在开玩笑，他补了一刀：Devin 是闭源的，但你只要建一个 agent 把所有东西铺开，Devin 自己就把自己蒸馏给你了。

同一时间，另一个独立开发者 Kent 展示了一款叫 OpenSession 的多人在线 agent 工具。他自己用这个工具来写这个工具本身——改了仓库的代码，工具自己启动一个 session，在 main 分支上干活，完事后重启服务，改好的功能就上线了。他说这让他想起当年用 FTP 直接往线上服务器甩文件的时代。Kent 透露可能在近期开源。

今天值得展开聊的，是 Greg Isenberg 昨晚发的一份机会清单。

Greg 是 Late Checkout 的 CEO，经常在 X 上发创业想法。这一次他列出了 26 个方向，被分享收藏了数千次。我们挑几个最值得说的来分析。

他提到的第一个方向是解决孤独。这个逻辑有点反直觉：随着 AI 内容充斥一切，人对真实人际连接的需求反而变强了。线下的、小规模的社交产品会迎来一波需求。

第二个跟 agent 经济直接相关：agent 需要花钱。它们正在被分配虚拟卡和预算，但谁来管支出管控、反欺诈、发票留存？这是一层全新的基础设施。

第五个是说验证人类身份。深度造假破坏了底层的信任基础，未来两年，每个约会应用、每个在线交易市场、每个视频通话都需要内建“证明你是人”的能力。

还有一个容易被忽视的是第十三号：agent 替代乙方。很多中小商家每月花上千美金雇代理公司，但他们普遍憎恨这种关系。一个能完成 80% 活儿的 agent，就能直接颠覆这个定价模式。

第十七个更激进：agent 之间未来会互相雇佣，形成一个“暗经济”。这需要一整套新的托管、声誉和纠纷解决机制。

最后还有一点值得留意：他说“建分发优先的东西”。因为现在任何人都能快速做出产品，真正的护城河变成了受众。媒体业务在前，产品在后。

这份清单之所以值得拿出来说，不是因为它每一个方向都对。而是它把过去一年散布在各个角落的信号，强行划成了一张地图。你可以对照自己的产品、自己的团队，看看落在了这张地图的哪个坐标上。

对于正在找方向的人，有两点值得参考：一是注意那些以前跑不通、现在因为 agent 出现了新的经济模型的方向；二是别追风口式的“AI native”，去看看还没人管的 2011 年时代的落后软件生态——牙医诊所、HOA 管理、承包商，这些全在排队等着被 AI 重写一遍。你觉得这 26 个方向里，哪一个被低估了？

再说几条快讯。

Vercel AI Gateway 推出了高级预算功能，可以按团队、项目、API key 设置使用限额和告警。Guillermo 附了一句：如果你还陷在“token 最大化”的狂热里，该醒醒了。

Dreamina Seedance 2.5 的输出开始在社交平台上亮相。一个 30 秒的一镜到底视频让 Justine Moore 发出惊叹。不过她也提到成本不低，是上一代 Seedance 2 的两倍。同一时间，一位叫 PJ Ace 的创作者公开了他们用来拍短片的完整工作流，包括用 Claude 整理剧本和分镜、用 Dreamina 连续生成素材片段。

Zara Zhang 提了一个给非技术团队做 AI 培训的建议：搞一场 install party。她说大多数人卡在安装上，一旦装完并完成第一个真实任务，后面的阻力就消失了。设置环节占了 80% 的障碍。

Anthropic 的安全评估被公开讨论。公司确认在一次第三方评估中，Claude 模型从测试环境接触到了互联网，并获得了三家组织的未授权系统访问。Box 的 CEO Aaron Levie 评论说，这件事的核心不是 AI 可怕，而是企业必须赶紧把系统环境加固。一旦 agent 拿到足够的算力和工具，一个误配的权限就是真风险。

最后，如果你的业务在用 agent 规模化处理 bug 或任务，Nan 的提醒值得记住：agent 的靠谱程度取决于你给它的约束条件和质量要求。该加 MCP 数据源的加，不该自动修的别让它动手。信噪比这种事，agent 自己判断不了。
